# Ave Mujica、演奏に没頭する5人から目が離せない――音と光に心を奪われた「Virtus」DAY1レポート

<p><span style="font-size: 16px;"><u><strong>■2026.10.24 Ave Mujica 7th LIVE「Virtus」DAY1@京王アリーナ TOKYO</strong></u></span></p>

<p><span style="font-size: 16px;"><strong>気づけば、足が拍を刻んでいた。</strong></span></p>

<p><span style="font-size: 16px;"><strong>歌い手がふと客席から視線を外し、ギターの演奏に没頭する。目まぐるしく変わる光の奥で、5人の身体が揺れている。客席へ向けていた視線が外れた瞬間、かえってその音楽を近く感じた。座ってメモを取っていた筆者の身体まで、その演奏に加わろうとしているかのようだった。</strong></span></p>

<p><span style="font-size: 16px;"><strong>2026年10月24日、京王アリーナ TOKYOで開催されたAve Mujica 7th LIVE「Virtus」DAY1。Ave Mujica LIVE TOUR 2026「Exitus」や『SUMMER SONIC 2026』でステージを重ねた5人が、ミニAlbum『神の名を』の発売から3日後に臨んだ単独公演だ。彼女たちのライブは、仮面舞踏会を意味する「マスカレード」と呼ばれる。トークMCを挟まず駆け抜けた18曲。その終盤に訪れた忘れがたい光景へと、この夜はどうたどり着いたのか。</strong></span></p>

<div><div class="img-wrapper imgsize80"><img alt="(C)BanG Dream! Project" class="img-embed" src="http://spice.eplus.jp/images/eZ7UuSTrm1IWbFihxQKTNg3rcn2H4suegE98tn9WfC4B9fXjCLHIuDiiN1oEoakO/" /><p class="img-exp">(C)BanG Dream! Project</p></div></div>

<h3>■静かな仕草も激しい演奏も、すべてがマスカレードを形作る</h3>

<p>開演前の場内には、アコーディオンの旋律が妖しいムードを漂わせていた。BGMが大きくなるにつれ、客席の手拍子も厚みを増していく。やがて暗転。舞台を覆う薄い幕が不意に赤く染まるのと同時に、「神の名を」の前奏が鳴り出す。幕の奥から差す光が浮かび上がらせるのは、5人のシルエット。ドロリス（CV：佐々木 李子／Gt.&Vo.）の歌い出しとともに、幕がゆっくりと上がっていく。</p>

<div><div class="img-wrapper imgsize100"><img alt="(C)BanG Dream! Project　写真：ハタサトシ" class="img-embed" src="http://spice.eplus.jp/images/x1REJasm9S0GQSDtQK3ZQK9WHI4mvfjauuLj8L5arU05mLk19eqtvlx3Z9jqZah1/" /><p class="img-exp">(C)BanG Dream! Project　写真：ハタサトシ</p></div></div>

<p>「神の名を」は、発売されたばかりのミニAlbumの表題曲。まだライブで誰も聴いたことのない一曲を、開幕から差し出す。曲中、ドロリスのシャウトに客席が応えた瞬間、新曲はすでに、この夜をともに作る音楽になっていた。場内モニターでは、ドロリスの動きが細かく刻まれて見える。ざらついた画面と、その独特の動きが生む映画のような質感。ステージで歌う姿が、モニターの中では物語の登場人物のようにも映る。歌い終えた直後の、ほんのわずかな間。ドロリスが静かに目を閉じ、再び正面を見据える。声を放ち尽くしたあとの小さな仕草が、強く目に焼き付いた。</p>

<p>「Symbol I : △」では、前奏から観客が跳び、サビに炎が噴き上がる。モーティス（CV：渡瀬 結月／Gt.）が浮かべるのは、客席を挑発するような、自信に満ちた笑み。アモーリス（CV：米澤 茜／Dr.）がスティックを掲げれば、そこにも歓声が返る。序盤から会場の熱は高い。</p>

<p>「ふたつの月  〜Deep Into The Forest〜」を経て、「Symbol II : Air」では、5人それぞれの表情に、音を交わす楽しさがあふれ出す。序盤の妖艶さや挑発的な笑みとはまた違う、屈託のない笑顔が舞台に広がっていた。オブリビオニス（CV：高尾 奏音／Key.）とモーティスが向き合い、間奏には鍵盤の音が弾ける。跳ねる客席の振動が足元まで届く。</p>

<p>オブリビオニスは、身振りでも舞台を彩る。過去のマスカレードでも、メンバーを指し示す動作やお辞儀が、楽曲とともにAve Mujicaの世界観を形作ってきた。この日も、しとやかな佇まいから舞い踊るような仕草へ。その動きにも目を留めたくなる。</p>

<div><div class="img-wrapper imgsize100"><img alt="(C)BanG Dream! Project　写真：ハタサトシ" class="img-embed" src="http://spice.eplus.jp/images/HjZl52hIKAuxrKtUIqzMn9bNeVeZHlzD8zGYgDXCQkoNzQCfxc57In3JM0jVQxHi/" /><p class="img-exp">(C)BanG Dream! Project　写真：ハタサトシ</p></div></div>

<p>「Georgette Me, Georgette You」を締めるシャウトから、「黒のバースデイ」の前奏へ。「‘S/’ The Way」では台に足をかけたドロリスが客席をあおり、その先にはアモーリスのドラムソロが待っていた。</p>

<p>スポットライトの下で鳴るビートに、客席の手拍子が加わる。言葉による号令はない。演奏を追ううちに手拍子が速まり、バンドは「Crucifix X」へとなだれ込む。「Crucifix X」を終えると、暗転を挟んで「Imprisoned XII」へ。座ってギターを弾きながら歌うドロリスの静かな佇まいが、いっそう際立つ。畳みかける演奏に乗せられていたこちらも、その歌声に耳を澄ませる。</p>

<div><div class="img-wrapper imgsize100"><img alt="(C)BanG Dream! Project　写真：ハタサトシ" class="img-embed" src="http://spice.eplus.jp/images/RCp9zmIZSiuQeieoaCwamu21dfQBl8jcwhusVJxNu2VVA3Nj1IPD4rGzNAWRWBTf/" /><p class="img-exp">(C)BanG Dream! Project　写真：ハタサトシ</p></div></div>

<h3>■客席も演奏の一員に――「BADDY BADDY」が見せた新たな顔</h3>

<p>「Choir ‘S’ Choir」に続いて、ティモリス（CV：岡田 夢以／Ba.）がベースソロを披露。低音を響かせながら客席へと歩み寄り、観客を見据えて笑みを浮かべる。その佇まいには、堂々とした余裕と気品が漂う。ソロを終え、「顔」の演奏が始まると、ギターを外したドロリスの動きも自由になる。座って足を伸ばし、跳ね、回る。客席にも跳躍が広がり、演奏する側と聴く側の身体がともに弾む。</p>

<p>再びギターを手にしたドロリスが歌う「DIVINE」。青く染まる舞台と客席に、歌の切実さが迫る。背後から光を受け、髪を振り乱して歌うドロリス。詞を読むと、この曲は運命に立ち向かう意志とともに、傷ついた相手への共感を描き、終盤には答えを求める問いを突き付けている。訴えかけるような歌い姿によって、その問いが抽象的な言葉から、目の前の一人の切迫感へと変わる。</p>

<div><div class="img-wrapper imgsize100"><img alt="(C)BanG Dream! Project　写真：ハタサトシ" class="img-embed" src="http://spice.eplus.jp/images/zv1TnvsaBzRc4mzQLxA1cqVOcWP4qjCoshelhz9A8OHzT9jWLlVUSYc0M5GebGft/" /><p class="img-exp">(C)BanG Dream! Project　写真：ハタサトシ</p></div></div>

<p>そこへ飛び込んできたのが、初披露の「BADDY BADDY」。</p>

<p>「‘ようこソ 本当ノ Ave Mujica ノ世界ヘ’」</p>

<p>ドロリスの呼びかけに、客席から歓声が上がる。笑みを浮かべ、くるくると回る、その軽やかな身のこなし。言葉だけでなく、全身で観客を招き入れるようだ。</p>

<p>ジャズを思わせる弾むリズムの中で、ティモリスのベースとアモーリスのドラムにも見せ場が訪れる。低音の響きや打音を追っていると、やがてアモーリスのドラムだけが鳴る場面で、ほかのメンバーが手拍子を始めた。客席がそれに続き、ビートに幾重もの拍が重なる。「ようこそ」と招かれた先で、聴く側もこの曲の一部になっていた。Ave Mujicaの妖しさに、こんなにも人懐こい楽しさが同居する。</p>

<p>オブリビオニスが鍵盤で曲を締めると、青い光はオレンジへ。「Sophie」では、逆光で顔を影に沈めたドロリスがシャウトを放つ。表情の見えない姿に、場内モニターのコマ送りを思わせる映像が重なり、その声はいっそう切迫して響いた。「KiLLKiSS」から「Ether」まで押し進め、最後は初披露の2曲へ。</p>

<div><div class="img-wrapper imgsize100"><img alt="(C)BanG Dream! Project　写真：ハタサトシ" class="img-embed" src="http://spice.eplus.jp/images/KBkRr4ATG2jbEof9WeNyNSRJ5ErTE8a1b47X61fSDZwWgId3T7a6UYLRvqQRUsHv/" /><p class="img-exp">(C)BanG Dream! Project　写真：ハタサトシ</p></div></div>

<h3>■客席への視線が外れた瞬間、5人の音楽が近づいた</h3>

<p>「The Whole Blue World」の歌詞に描かれるのは、思いが届かないことへの苛立ちや、信じたいものを信じ切れない痛み。やがて視線は、自分と同じように震える相手へ向かう。ドロリスは、その苛立ちをぶつけるように歌い、ギターをかき鳴らす。なかでも胸に残ったのは、オブリビオニスの短い鍵盤独奏に続く、ドロリスが歌い出す直前の息継ぎだった。</p>

<p>声になる一歩手前の呼吸が、ふいに耳へ届く。それまでシャウトを響かせていた歌い手が、その瞬間、ぐっと近く感じられる。最後のサビで長く伸ばす声には、晴れやかさもにじんだ。歌詞の痛みが消えたわけではない。それを抱えたまま声を放つ姿に、この曲をライブで聴く意味が宿っていたように思う。</p>

<div><div class="img-wrapper imgsize100"><img alt="(C)BanG Dream! Project　写真：ハタサトシ" class="img-embed" src="http://spice.eplus.jp/images/ROxFXSUwpxHpmJ9mXGnUfax1p20GgSPqMZJFHxYnFHdxBbngcCfaGHwT3dBZQwPK/" /><p class="img-exp">(C)BanG Dream! Project　写真：ハタサトシ</p></div></div>

<p>そして「A Song Of Romance」。孤独や傷を抱えた者が、他者とのつながりを求める歌だ。激しい演奏と抑えた場面が大きく入れ替わり、ひとつの感情に落ち着く暇もなく、次の波がやってくる。</p>

<p>「そうね きっとみんな寂しいのね」と歌い終えたあとに訪れる、歌のない一節。ドロリスが不意に客席から視線を外し、ギターの演奏に没頭する。目まぐるしく移り変わる照明の奥で、ほかのメンバーも身体を揺らしている。5人それぞれが、音へと身を傾けていくようだった。</p>

<p>光の移ろいと、奏者の身体と、鳴り続ける音。どれかひとつを切り離して眺めることのできない光景に、見入っていた。気づけば、自分の足も拍を刻んでいる。</p>

<p>他者とのつながりを求める歌の、言葉が途切れたところで、演奏する5人と聴くこちらが音で結ばれる。そう受け止めたくなる瞬間だった。</p>

<div><div class="img-wrapper imgsize100"><img alt="(C)BanG Dream! Project　写真：ハタサトシ" class="img-embed" src="http://spice.eplus.jp/images/itCeMksKN1PGQTspPCp4pFkDMScDTGDHjRImCUhPB1LOAJA9ZcI4losgQ5S9rF3N/" /><p class="img-exp">(C)BanG Dream! Project　写真：ハタサトシ</p></div></div>

<p>そこから響く「who am i...」は、独白のように耳に残る。5人の演奏に身を委ねていたところから、ひとりの内面へと引き戻されるようだ。自分は何者なのか。音に満たされた直後だからこそ、その問いが胸に残った。</p>

<p>最後のサビに炎が上がり、5人は終わりまで音を重ね尽くす。真っ白な光。そのあとに全員が舞台前方に並び、客席に一礼した。</p>

<p>かつてはオブリビオニスが最後に残ってお辞儀をし、幕を引いた公演もある。この夜は、それぞれの表情を見せながら演奏していた5人が、最後にひとつのバンドとして並んだ。</p>

<p>人が舞台を去ったあと、モニターに映し出されたのは、その先へ続く知らせだった。映画「BanG Dream! Ave Mujica prima aurora」のBlu-ray発売、そしてブシロード20周年記念ライブへの出演。さらに翌DAY2には、2027年1月8日放送開始予定の続編TVアニメ「BanG Dream! MyGO!!!!! // Ave Mujica」のタイトルと放送情報が公開された。次なる単独公演は、2027年5月29日・30日にKアリーナ横浜で開催されるAve Mujica 8th LIVE「Discrimen Fati」。こちらもDAY2に開催が発表され、物語とライブの両方に新たな楽しみが生まれた。</p>

<div><div class="img-wrapper imgsize100"><img alt="(C)BanG Dream! Project　写真：ハタサトシ" class="img-embed" src="http://spice.eplus.jp/images/NjdXfKGH55kNHEpBe4qhHZLAZCkHJTsLcKHjTtXoA5lp7ljtkPK1QSiyEUEbu2H9/" /><p class="img-exp">(C)BanG Dream! Project　写真：ハタサトシ</p></div></div>

<p>物語の続きとともに気になるのは、この日初めてライブで鳴った4曲が、これからどんな表情を見せていくのかということだ。客席とともに拍を刻む楽しさも、歌い出す直前の息の近さも、演奏に没頭する5人に身体を動かされた感覚も、音源だけでは知り得なかった。次の舞台で、また何を聴かせてくれるのか。一礼する5人を見送ったあとにも、その問いが残っている。</p>
