# TVアニメ『アルカナディア』島﨑信長・稲垣好らキャスト発表！天真爛漫なディアーズたちを描くティザーPV解禁

<p>8月29日、東京・品川にて開催されたアルカナディアづくしのイベント『アルカナディア エンゲージフェス2026』のステージにて、TVアニメ『アルカナディア」』のティザーPVが解禁された。</p>

<div><div class="youtube"></div></div>

<p><br />
無気力に生きている主人公が「ディアーズ」と呼ばれる未知の生命体であるルミティアたちと出会い、周囲が賑やかに、彩り豊かに変わっていく様子が躍動感たっぷりに描かれている。</p>

<div><div class="img-wrapper imgsize100"><img alt="(C)KOTOBUKIYA / ARCANADEA Project" class="img-embed" src="http://spice.eplus.jp/images/m3CNYbhB9s5AW8ZU5YQzxuebIMRm718M6Yr0u543HMhni097BI17lyUrzpZ6zCHY/" /><p class="img-exp">(C)KOTOBUKIYA / ARCANADEA Project</p></div></div>

<p>そしてTVアニメ『アルカナディア』トークステージにて、本作主人公である空閑翔吾役に島﨑信長が、浅黄香穂役に稲垣 好が出演することが発表された。また、ステージ中盤、登壇者である神﨑桃伽が演じるギィもアニメ出演することが緊急発表された。さらに、ギィのマスター・桐乃上凛役として菅野真衣の出演も発表。これにあわせて、かねてよりキャスト続投発表のあったルミティア、ヴェルルッタ、ユクモのキャラクター設定も公開された。</p>

<h3>◆空閑翔吾（くが・しょうご）　CV：島﨑信長</h3>

<div><div class="img-wrapper imgsize100"><img alt="(C)KOTOBUKIYA / ARCANADEA Project" class="img-embed" src="http://spice.eplus.jp/images/sB59wfxpEmp2tjo4eF4H2DHYB4GS0ePn2Vx3qeLyZiFlEXRzT7cRG88xUZXs4h6Z/" /><p class="img-exp">(C)KOTOBUKIYA / ARCANADEA Project</p></div></div>

<p>キャラクター解説：大学三年生。かつてVRMMO『アルカナディア』で名を馳せた腕利きのプレイヤーだが、現在はどこか無気力な日々を送っている。ルミティアとの出会いをきっかけに、止まっていた時間が少しずつ動き出す。</p>

<h3>◆ルミティア　CV：本渡 楓</h3>

<div><div class="img-wrapper imgsize100"><img alt="(C)KOTOBUKIYA / ARCANADEA Project" class="img-embed" src="http://spice.eplus.jp/images/yze5qV7IWmW6UICfMA5CAQ5iiaegjhd0M2ZEWVVkSfdUZIlGGdMSJokpDeqBsDVg/" /><p class="img-exp">(C)KOTOBUKIYA / ARCANADEA Project</p></div></div>

<p>キャラクター解説：空から降ってきた、天族のディアーズ。記憶を失っているが、空閑を「マスター」と慕い、いつも一生懸命。初めて触れる人間の世界に目を輝かせながら、空閑と絆を深めていく。</p>

<h3>◆浅黄香穂（あさぎ・かほ）　CV：稲垣 好</h3>

<div><div class="img-wrapper imgsize100"><img alt="(C)KOTOBUKIYA / ARCANADEA Project" class="img-embed" src="http://spice.eplus.jp/images/jdDhspHJ78sC1oozmIXDgovo8gzmDrZ6jyAzA3Nzl2HdiQjoy9gDjTyHf8rD3XxD/" /><p class="img-exp">(C)KOTOBUKIYA / ARCANADEA Project</p></div></div>

<p>キャラクター解説：空閑と同じくディアマスターとして活動する大学一年生。ヴェルルッタとユクモのマスターで、真面目で気配り上手な性格。個性豊かなディアーズたちに振り回されながらも、仲間を支えるしっかり者。</p>

<h3>◆ヴェルルッタ　CV：岡咲美保</h3>

<div><div class="img-wrapper imgsize100"><img alt="(C)KOTOBUKIYA / ARCANADEA Project" class="img-embed" src="http://spice.eplus.jp/images/PLGCpMkRA4sLj05et5Fcxf76dI3XdH7irmB7XTbZhiHiz7xJtMz18g6Sd3ZMtC49/" /><p class="img-exp">(C)KOTOBUKIYA / ARCANADEA Project</p></div></div>

<p>キャラクター解説：香穂をマスターとする魔族のディアーズで、魔族最強の七人「七魔槍」の一柱。自信家でいたずら好きな一方、香穂とユクモを引っ張っていくようなリーダーシップを発揮する一面も持つ。</p>

<h3>◆ユクモ　CV：日高里菜</h3>

<div><div class="img-wrapper imgsize100"><img alt="(C)KOTOBUKIYA / ARCANADEA Project" class="img-embed" src="http://spice.eplus.jp/images/bzKOjlg3KtX9aVjLSt5DYD1VMuUzUL7Un1it4FhPjZQdlBADRbXe997Qe452RAzn/" /><p class="img-exp">(C)KOTOBUKIYA / ARCANADEA Project</p></div></div>

<p>キャラクター解説：香穂をマスターとする獣人族のディアーズ。心優しく、少し控えめでおっとり。ヴェルルッタに振り回されがちではあるが、仲間の役に立ちたいという想いは人一倍強い。</p>

<h3>◆ギィ　CV：神﨑桃伽</h3>

<div><div class="img-wrapper imgsize100"><img alt="(C)KOTOBUKIYA / ARCANADEA Project" class="img-embed" src="http://spice.eplus.jp/images/GXJbCF1lsXU7v4OHRMrFrmqLi1H2EKJB3R5F4CduRAasn5lMmKx378AbkUUmKqgI/" /><p class="img-exp">(C)KOTOBUKIYA / ARCANADEA Project</p></div></div>

<p>キャラクター解説：凛をマスターとする獣人族のディアーズ。マイペースでかわいいものが大好き。気に入った相手を「眷属」にしたがるなど、どこまでも自由だが、実はディアーズトップクラスの攻撃力。</p>

<h3>◆桐乃上凛（きりのえ・りん）　CV：菅野真衣</h3>

<div><div class="img-wrapper imgsize100"><img alt="(C)KOTOBUKIYA / ARCANADEA Project" class="img-embed" src="http://spice.eplus.jp/images/SxqORtO41M1EmsTTOXumU5YMPrzzQ65IcQcESzXa7x0H3rse5zxn6cPRLAsgJYTy/" /><p class="img-exp">(C)KOTOBUKIYA / ARCANADEA Project</p></div></div>

<p>キャラクター解説：ギィのディアマスター。アイドルとしても活動中。明るく人懐っこい性格で、空閑のことを独特の呼び方で呼ぶ。自由奔放なギィに振り回されつつも、強い絆で結ばれている。</p>

<div><div class="img-wrapper imgsize80"><img alt="島﨑信長" class="img-embed" src="http://spice.eplus.jp/images/JH8OVSm5tK3YoP6oprw6XRnYOcUikfjUSROKX0Qex7KUcImbWS6PHf3BMPeeKAND/" /><p class="img-exp">島﨑信長</p></div></div>

<p><strong>＜空閑翔吾役：島﨑信長 コメント＞</strong><br />
Q1.ご自身のキャラクターについて教えてください<br />
<strong>空閑翔吾くんは、過去の出来事をきっかけに感情の起伏が小さくなってしまった大学生です。決して感情がないわけではないのですが、そんな彼が、とても感情表現豊かなディアーズ・ルミティアと出会うことで何が起こっていくのか。ボーイミーツガールというか、ガールミーツボーイというか、そんな要素もこのアニメの大きな見どころのひとつだと思っています。</strong></p>

<p>Q2.ファンの皆様に向けて、本作への意気込みやメッセージを！<br />
<strong>空閑とルミティアが出会い、エンゲージしたところから、二人の関係性がどのように深まり、どう成長し、変化していくのか。そして、その出会いによって周囲の人々や世界がどのように動いていくのか。その先に何が待っているのかまで、ぜひ楽しみにしていただきたいです。<br />
アフレコも毎回とても楽しく、本渡 楓さんが演じるルミティアにはいつも助けてもらっています。空閑は感情の起伏が少ないキャラクターなので、ルミティアが豊かな感情をぶつけてくれることで、空閑自身の感情の幅も少しずつ広がっていくように感じています。<br />
そして、皆さんが大好きなディアーズたちは、アニメでもとても可愛らしく、魅力的に描かれています。ほかにも個性豊かなキャラクターがたくさん登場しますので、TVアニメ『アルカナディア』を、ぜひ楽しみにお待ちください！</strong></p>

<strong>浅黄香穂ちゃんは、ユクモとヴェルルッタのディアマスターであり、主人公・空閑翔吾くんにとっては、年下ながら“ディアマスターの先輩”にあたる存在です。作中では空閑くんにアドバイスをしたり、さまざまなことを説明したりと、しっかり者のお姉さんのような役割を担っています。一方で、ヴェルルッタに振り回されて慌ててしまったり、おちゃめな一面もあったりするので、そんなギャップも楽しんでいただけたらと思います。</strong></p>

<p>Q2.ファンの皆様に向けて、本作への意気込みやメッセージを！<br />
<strong>TVアニメ『アルカナディア』はオリジナルストーリーということもあり、かなり自由に、楽しくお芝居をさせていただいています。メインキャラクターはもちろん、敵となるキャラクターや、何気ないガヤの一つひとつまで、キャストの皆さんがとても面白いお芝居をされているので、ぜひ注目していただきたいです。「えっ!?」と驚くような重要なキャラクターも登場しますので、そちらも楽しみにしていてください。<br />

そんな制作陣、キャスト陣の温かい空気も作品を通して皆さんに伝わるのではないかと思っています。放送をぜひ楽しみにお待ちください！</strong></p>
