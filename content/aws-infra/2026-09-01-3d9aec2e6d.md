# Amazon DocumentDB now supports direct major version upgrades to version 8.0

<p>Amazon DocumentDB (with MongoDB compatibility) now supports in-place major version upgrades (MVU) directly from engine versions 3.6 and 4.0 to version 8.0. This upgrade capability removes the need for intermediate version upgrades and allows you to upgrade your version 3.6 or 4.0 clusters while preserving existing data, configurations, and cluster settings.</p> 
<p>Upgrading to version 8.0 provides access to the latest security patches, performance improvements, and new developer capabilities. Major version upgrades from DocumentDB 3.6 and 4.0 to 8.0 are available in all AWS regions where these versions are currently supported.</p> 
<p>To learn more about upgrading to Amazon DocumentDB 8.0, including detailed guidance on version differences and upgrade paths, visit the <a href="https://docs.aws.amazon.com/documentdb/latest/devguide/docdb-mvu.html#mvu-36-to-50-differences">Amazon DocumentDB MVU documentation</a>, review <a href="https://docs.aws.amazon.com/documentdb/latest/devguide/docdb-version-support-dates.html">version support dates</a>, and explore the full list of new capabilities on the <a href="https://aws.amazon.com/about-aws/whats-new/2025/11/documentdb-8-o/">Amazon DocumentDB 8.0 announcement page</a>.</p>
