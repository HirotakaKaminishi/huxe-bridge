# Amazon RDS for MySQL supports MySQL 9.7 in Amazon RDS Database Preview Environment

<p><a href="https://aws.amazon.com/rds/mysql/" rel="noopener noreferrer" target="_blank">Amazon RDS for MySQL</a> now supports version community MySQL 9.7 in the <a href="https://aws.amazon.com/rds/databasepreview/" rel="noopener noreferrer" target="_blank">Amazon RDS Database Preview Environment</a>, allowing you to evaluate the latest Release on Amazon RDS for MySQL. This preview environment provides a sandbox where you can test applications and explore new MySQL 9.7 capabilities before they become generally available.<br /> <br /> MySQL 9.7 is the latest Long-Term Support release for community MySQL. MySQL Long-Term Support releases include bug fixes, security patches, as well as new features. Please refer to the <a href="https://dev.mysql.com/doc/refman/9.7/en/mysql-nutshell.html" rel="noopener noreferrer" target="_blank">MySQL 9.7 release notes</a> for more details about this release.<br /> <br /> Amazon RDS Database Preview Environment database instances are retained for a maximum of 60 days and are automatically deleted after the retention period. Amazon RDS database snapshots created in the preview environment can only be used to create or restore database instances within the preview environment. Amazon RDS Database Preview Environment database instances are <a href="https://aws.amazon.com/rds/mysql/pricing/" rel="noopener noreferrer" target="_blank">priced the same as production RDS instances created in the US East (Ohio) Region</a>. For further information, see <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/CHAP_Previewenvironment.html" rel="noopener noreferrer" target="_blank">Working with the Database Preview Environment</a>.</p>
