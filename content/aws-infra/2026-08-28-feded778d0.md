# Amazon EVS now supports i7i.metal-48xl Amazon EC2 instance type

<p>Today, we're announcing that Amazon Elastic VMware Service (Amazon EVS) now supports the i7i.metal-48xl Amazon Elastic Cloud Compute (Amazon EC2) bare-metal instance type, offering a higher core-count option with a newer generation processor to help you realize cost-performance benefits for your VMware-based workloads on AWS.</p> 
<p>With this release, you now have more options for running your virtual machines (VMs) on Amazon EVS environments and growing your cloud presence at your own pace, as your business demands. Powered by 5th generation Intel Xeon Scalable processors, i7i instances offer the best compute and storage performance for x86-based storage optimized instances in Amazon EC2, delivering up to 23% better compute performance and more than 10% better price performance over i4i instances. The i7i.metal-48xl's larger memory and storage footprint allows you to run more VMs to vertically scale your operation with less EVS hosts - and take further advantage of the latest VMware Cloud Foundation (VCF) 9.x features such as <a href="https://aws.amazon.com/blogs/migration-and-modernization/increase-your-cluster-density-with-memory-tiering-in-amazon-elastic-vmware-service/">memory tiering</a> and new automations such as the <a href="https://github.com/aws/solutions-for-amazon-evs/tree/main/Deploy/EVS-Deployment-Orchestrator">Amazon EVS Deployment Orchestrator</a> to simplify onboarding.</p> 
<p>This latest release is available in AWS Regions where Amazon EVS and Amazon EC2 i7i are both available. See <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">Amazon EVS regional availability</a> and <a href="https://docs.aws.amazon.com/ec2/latest/instancetypes/ec2-instance-regions.html">Amazon EC2 i7i regional availability</a>.</p> 
<p>Learn more about Amazon EVS by visiting the <a href="https://aws.amazon.com/evs/">product detail page</a> and the <a href="https://docs.aws.amazon.com/evs/latest/userguide/what-is-evs.html">user guide</a>.</p>
