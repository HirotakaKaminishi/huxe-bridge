# Amazon MWAA now supports Apache Airflow version 2.11.2

<p>Amazon Managed Workflows for Apache Airflow (MWAA) now supports Apache Airflow version 2.11.2. Amazon MWAA is a managed service that runs Apache Airflow at scale without the operational overhead of managing the underlying infrastructure. Apache Airflow 2.11.2 is a maintenance release that includes security improvements, bug fixes, and dependency upgrades.<br /> <br /> This release upgrades core dependencies with security patches and stability improvements to the Airflow webserver and task execution layers. It also includes fixes to task lifecycle management for queued tasks, enhanced secrets masking in logs, UI corrections in the Task Instances list view, and provider package updates for S3 and CloudWatch log delivery.<br /> <br /> You can create a new Apache Airflow 2.11.2 environment on Amazon MWAA or upgrade your existing environments with a few clicks in the AWS Management Console in all currently available Amazon MWAA regions. To learn more, visit the <a href="https://docs.aws.amazon.com/mwaa/latest/userguide/what-is-mwaa.html">Amazon MWAA documentation</a>, review the <a href="https://airflow.apache.org/docs/apache-airflow/2.11.2/release_notes.html#airflow-2-11-2-2026-03-14">Apache Airflow 2.11.2 release notes</a>, and explore the <a href="https://docs.aws.amazon.com/mwaa/latest/userguide/airflow-versions.html">list of available Airflow versions on MWAA</a>.</p>
