# Amazon Route 53 Domains now supports self-service restore for expired and deleted domains

<p>Amazon Route 53 Domains now lets you restore an expired or recently deleted domain yourself, using the Amazon Route 53 console, AWS CLI, or AWS SDKs. Previously, restoring a domain required a request to AWS Support. Now you can recover a domain lost to a missed renewal, an expired payment method, or an accidental deletion, and restore the website, email, and applications that depend on it.</p> 
<p>To restore a domain, you enter the domain name, review the restoration price, accept the charge, and submit the request. Route 53 works with the top-level domain (TLD) registry to reactivate the registration and return the domain to your AWS account. Most TLD registries support restoration, and each registry sets how long after expiration or deletion a domain can still be restored. Restoring a domain typically costs more than registering or renewing one.</p> 
<p>To learn more, see <a href="https://docs.aws.amazon.com/Route53/latest/DeveloperGuide/domain-restore-expired.html" rel="noopener noreferrer" target="_blank">Restoring an expired or deleted domain</a> in the Route 53 Developer Guide, or visit the <a href="https://aws.amazon.com/route53/domains/" target="_blank">Amazon Route 53 Domains page</a>. For a complete list of supported TLDs, see the <a href="https://docs.aws.amazon.com/Route53/latest/DeveloperGuide/registrar-tld-list.html" rel="noopener noreferrer" target="_blank">Route 53 TLD list</a>. For pricing, visit the Route 53 <a href="https://aws.amazon.com/route53/pricing/" target="_blank">pricing page</a>.</p>
