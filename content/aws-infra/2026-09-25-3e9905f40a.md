# AWS Elastic Disaster Recovery now supports AWS Graviton-based source servers

<p>AWS Elastic Disaster Recovery (AWS DRS) now supports disaster recovery for AWS Graviton-based (arm64) source servers. You can now protect and recover your Graviton workloads with the same simple, reliable DRS experience you already use for x86 workloads.</p>
<p>As more workloads move to Graviton for its price-performance benefits, they need the same disaster recovery coverage as the rest of your environment. DRS now automatically detects arm64 source servers and recovers them onto Graviton instances, preserving your workload's architecture end to end. Recovery works the same way it does for your other servers, with nothing extra to configure.</p>
<p>This capability is available in all AWS Regions where AWS DRS is offered, at no additional cost. To learn more, visit the <a href="https://docs.aws.amazon.com/drs/">AWS Elastic Disaster Recovery User Guide</a>.</p>
