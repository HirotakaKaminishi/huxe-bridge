# AWS Sign-In introduces configurable Sign-in duration of up to 90 days

<p>AWS Sign-In now enables developers and AI agents to stay authenticated for up to 90 days without frequent sign-ins or consent prompts. With this launch, administrators can configure <b>Sign-in duration</b>, which controls how long an OAuth Sign-in session remains active, for individual IAM users and roles.</p> 
<p>This capability reduces authentication interruptions for long-running workflows and provides a more secure alternative to static access keys by using short-lived, renewable credentials. Existing session duration limits remain unchanged unless administrators explicitly configure longer durations.</p> 
<p>Sign-In Duration supports AWS CLI (aws login), AWS MCP Server, and other OAuth-enabled applications. It does not affect AWS Management Console sessions. Customers can configure the setting using the IAM console, AWS CLI, or IAM API in all AWS commercial Regions.</p> 
<p><b>To learn more</b>, see the <a href="https://docs.aws.amazon.com/signin/latest/userguide/oauth-sign-in-session-management.html">AWS Sign-In session management User Guide</a>, <a href="https://docs.aws.amazon.com/IAM/latest/UserGuide/id_roles_update-role-settings.html#id_roles_update-signin-duration">Configure Sign-In duration on Role User Guid</a>e, <a href="https://docs.aws.amazon.com/signin/latest/userguide/reference-signin-condition-keys.html#reference-signin-condition-keys-oauth">Condition Key User Guide</a></p>
