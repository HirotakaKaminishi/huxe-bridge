# AWS Security Hub CSPM now supports centralized configuration with AWS Organizations declarative policies

<p><a href="https://aws.amazon.com/security-hub/cspm/">AWS Security Hub CSPM</a> now supports AWS Organizations declarative policies. You can use them to enable Security Hub CSPM across all accounts and Regions in your organization and to define which security standards and controls are enabled.</p>
<p>Policies can apply broadly to every account and Region, or target specific account and Region combinations. Declarative policies help keep each account's configuration aligned with its attached policy, which helps prevent configuration drift. You can also apply them automatically to new accounts, so each account starts with a baseline configuration as soon as it's created.</p>
<p>Declarative policies are now the recommended way to manage Security Hub CSPM across an organization. They align with how other security services, such as Amazon GuardDuty, Amazon Inspector, and AWS Security Hub allow customers to manage configuration of the service. They also provide more flexibility, such as configuring Region-specific settings. You can continue to use central configuration until you're ready to migrate. When you are, use the migration process in the Security Hub CSPM console. It converts your existing central configuration policies into declarative policies and applies them to the appropriate accounts and regions.</p>
<p>Declarative policies for Security Hub CSPM are available in all commercial, AWS GovCloud (US), and China Regions. To get started, see <a href="https://docs.aws.amazon.com/securityhub/latest/userguide/orgs-policies-and-central-config.html#orgs-policies-import-tool" target="_blank">Migrating central configuration policies</a>. To learn more, see <a href="https://docs.aws.amazon.com/securityhub/latest/userguide/accounts-orgs-policies.html" target="_blank">Declarative policies</a> in the AWS Security Hub CSPM User Guide and <a href="https://docs.aws.amazon.com/organizations/latest/userguide/orgs_manage_policies_security_hub_cspm.html" target="_blank">Security Hub CSPM policies</a> in the AWS Organizations User Guide. To receive notifications about new Security Hub CSPM features and controls, subscribe to the <a href="https://docs.aws.amazon.com/securityhub/latest/userguide/securityhub-announcements.html" target="_blank">Security Hub SNS topic</a>. You can also <a href="https://aws.amazon.com/security-hub/cspm/pricing/">try Security Hub CSPM at no cost for 30 days</a> with the AWS Free Tier offering.</p>
