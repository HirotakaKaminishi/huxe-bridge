# AWS Glue Data Catalog now supports Apache Iceberg table optimization in the US West (N. California) Region

<p>AWS Glue Data Catalog now supports automatic table optimization for Apache Iceberg tables in the US West (N. California) Region. Apache Iceberg is an open table format that delivers fast query performance over large tables in data lakes. With this launch, you can enable table optimization for individual tables or for all tables in your Data Catalog.</p> 
<p>Apache Iceberg tables accumulate small files, snapshots, and unreferenced files with every write, which slows queries and increases storage costs over time. Table optimization continuously monitors your tables to compact small files in the background, remove snapshots that are past your retention settings, and delete unreferenced files that are no longer needed. You can monitor each run from the AWS Glue console, Amazon CloudWatch metrics, and logs.</p> 
<p>You can enable table optimization using the AWS Glue console, AWS CLI, or AWS SDKs. For the full list of Regions where table optimization is available, see <a href="https://docs.aws.amazon.com/glue/latest/dg/regions-optimizers.html">Supported Regions for table optimizers</a>. To learn more, see <a href="https://docs.aws.amazon.com/glue/latest/dg/table-optimizers.html">Optimizing Iceberg tables</a> in the AWS Glue Developer Guide. To get started, visit the <a href="https://aws.amazon.com/glue/">AWS Glue product page</a>.</p>
