# Apache Airflow UI available in Amazon MWAA Serverless

<p>Amazon MWAA Serverless provides the native Apache Airflow UI for your workflows. You can browse workflows, inspect workflow runs and task instances, read task logs, view a workflow's source and versions, and start a workflow run. The UI uses the permissions of the IAM identity that opens it and shows only what that identity can read, so read-only access is possible. AWS CloudTrail records the calls the UI makes under your identity.</p>
<p>You can open the Airflow UI from the Amazon MWAA console, the AWS CLI, or the API. Teams already familiar with Airflow can use the interface they know to work with their workflows.</p>
<p>This feature is available in all AWS Regions where Amazon MWAA Serverless is available. For more information, see the <a href="https://docs.aws.amazon.com/mwaa/latest/mwaa-serverless-userguide/what-is-mwaa-serverless.html#regions" target="_blank">AWS Region table</a>.</p>
<p>To get started, see <a href="https://docs.aws.amazon.com/mwaa/latest/mwaa-serverless-userguide/workflows-airflow-ui.html" target="_blank">Access the Airflow UI</a>. Apache Airflow is a trademark of the <a href="https://www.apache.org/" target="_blank">Apache Software Foundation</a>.</p>
