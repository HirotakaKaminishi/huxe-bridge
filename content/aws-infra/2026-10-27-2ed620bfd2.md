# Amazon Connect Customer expands testing and simulation to validate flow action outcomes

<p>Amazon Connect Customer now enables you to validate the outcomes of your customer experience flow actions during testing and simulation. In addition to confirming that an action started, you can now verify the data it returns when it completes, such as a Lambda function response, an Amazon Lex resolved intent, or the variables set by an Agentic CX block. When a test fails, you can pinpoint the exact action that returned an unexpected result instead of tracing it back from a downstream step, so you can resolve issues faster and launch flow changes with greater confidence.</p> 
<p>To learn more about this feature, see <a href="https://docs.aws.amazon.com/connect/latest/adminguide/testing-simulation-observe-block.html">testing and simulation</a> in the Connect Customer administrator guide. For a complete list of testing and simulation capabilities available by AWS Region, refer to <a href="https://docs.aws.amazon.com/connect/latest/adminguide/regions.html">Availability of Connect Customer features by Region</a>. To learn more about Amazon Connect Customer, an agentic AI solution that helps enterprises deliver exceptional customer experiences, visit the <a href="https://aws.amazon.com/products/connect/customer/">Amazon Connect Customer website</a>.</p>
