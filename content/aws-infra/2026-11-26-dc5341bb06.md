# Amazon OpenSearch Service optimised engine now publishes data to Amazon S3 Tables

<p>The optimized engine for observability in Amazon OpenSearch Service now lets customers who send observability data directly to OpenSearch publish that data to Amazon S3 Tables. These customers can search and analyze data in OpenSearch, but reusing it with other analytics and AI tools often requires a parallel ingestion or custom export pipeline. This integration provides an open-table reuse path without changing how data enters OpenSearch.</p> 
<p>Publish policies make selected indexes available as Apache Iceberg tables in your AWS account. Engineers and AI agents can query the same observability data with Amazon EMR Serverless, DuckDB, and other Iceberg-compatible tools without adding query load to OpenSearch. They can reuse it for historical investigations, cross-dataset analysis, audits, and long-term trend analysis while retaining it at lower cost.</p> 
<p>This feature is available at no additional charge on the new engine for observability with OpenSearch 3.9 in the following AWS Regions: US East (N. Virginia), US East (Ohio), US West (Oregon), Canada (Central), Asia Pacific (Mumbai), Asia Pacific (Singapore), Asia Pacific (Sydney), Asia Pacific (Tokyo), Europe (Frankfurt), Europe (Ireland), Europe (London), and Europe (Spain). Amazon S3 Tables storage and the services you use to query the data incur standard charges. To get started, add a publish policy to your <a href="https://docs.aws.amazon.com/opensearch-service/latest/developerguide/optimized-log-analytics.html">optimized domain</a> and see Publish indexes to Amazon S3 Tables in the <a href="https://docs.aws.amazon.com/opensearch-service/latest/developerguide/publishing-indices-s3-tables.html">documentation</a>.</p>
