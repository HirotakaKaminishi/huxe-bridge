# Amazon RDS now supports AMD-based M8a instances

<p>Amazon RDS for PostgreSQL, MySQL, and MariaDB now support M8a database instances powered by 5th generation AMD EPYC processors, expanding the choice available for your database workloads. Each vCPU in M8a database instances corresponds to a physical CPU core, which delivers consistent per-core performance. For workloads with high I/O requirements, M8a instances provide up to 75 Gbps of network bandwidth and 60 Gbps of Amazon EBS bandwidth. All instances are built on the AWS Nitro System using sixth-generation Nitro Cards.</p>
<p>M8a database instances are available in US East (N. Virginia, Ohio), US West (Oregon), Asia Pacific (Mumbai, Tokyo, Hyderabad) and Europe (Ireland, Frankfurt, Spain) regions. You can get started with M8a database instances through the <a href="https://console.aws.amazon.com/rds/home?refid=35100cff-4aaa-46ac-bc1d-71576bef47be" rel="noopener noreferrer" target="_blank"><u>Amazon RDS Management Console</u></a> or by using the <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/USER_CreateDBInstance.html" rel="noopener noreferrer" target="_blank"><u>AWS Command Line Interface</u></a> (CLI). For the specific engine versions that support these instance classes, see the <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/Concepts.DBInstanceClass.Support.html?refid=35100cff-4aaa-46ac-bc1d-71576bef47be" rel="noopener noreferrer" target="_blank"><u>RDS</u></a> documentation. For pricing , see the <a href="https://aws.amazon.com/rds/pricing/" rel="noopener noreferrer" target="_blank"><u>Amazon RDS pricing page</u></a>.</p>
