# Amazon ElastiCache now supports Graviton4-based M8g, R8g, and C8gn nodes

<p>Amazon ElastiCache now supports Graviton4-based M8g, R8g, and C8gn node families for Valkey and Memcached. Graviton4-based nodes provide up to 47% higher throughput, up to 43% lower P99 latency, and up to 31% better price-performance for on-demand pricing over Graviton3-based nodes of equivalent sizes on Amazon ElastiCache for Valkey, depending on node family, size, and workload configuration.</p> 
<p>Graviton4-based nodes also offer more memory per node compared to equivalent Graviton3-based nodes. As an example, an m8g.8xlarge provides 124.65 GiB versus 103.68 GiB on m7g.8xlarge, up to 20% more memory at the same node size. C8gn nodes offer up to 200 Gbps of network bandwidth, enabling you to scale performance and throughput while optimizing the cost of running network-intensive workloads.</p> 
<p>M8g, R8g, and C8gn nodes are available in sizes from large to 16xlarge in over 30 AWS Regions, including the AWS GovCloud (US) Regions and the China Regions. For complete information on pricing and regional availability, please refer to the <a href="https://aws.amazon.com/elasticache/pricing/" rel="noopener noreferrer" target="_blank">Amazon ElastiCache pricing page</a>. To get started, create a new cluster or modify an existing cluster using the <a href="https://console.aws.amazon.com/elasticache/" rel="noopener noreferrer" target="_blank">AWS Management Console</a>, AWS SDK, or AWS CLI. To work with ElastiCache using AI coding agents, see <a href="https://docs.aws.amazon.com/AmazonElastiCache/latest/dg/AgentTools.html" rel="noopener noreferrer" target="_blank">Agent tools for ElastiCache</a>. To learn more, see <a href="https://docs.aws.amazon.com/AmazonElastiCache/latest/dg/CacheNodes.SupportedTypes.html" rel="noopener noreferrer" target="_blank">Supported node types</a> in the <i>Amazon ElastiCache User Guide</i>.</p>
