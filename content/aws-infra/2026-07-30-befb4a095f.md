# Amazon OpenSearch Service now supports OpenSearch version 3.7

<p>You can now run OpenSearch version 3.7 on Amazon OpenSearch Service. OpenSearch 3.7 introduces improvements in vector search performance, search relevance, and Query Insights.</p> 
<p>With this launch, <a href="https://docs.opensearch.org/latest/vector-search/optimizing-storage/faiss-scalar-quantization/#1-bit-quantization" target="_blank">1-bit scalar quantization</a> on the Faiss and Lucene engines compresses vectors, reducing the storage and memory required by vector workloads while maintaining search accuracy. You can now retrieve vectors faster using <a href="https://docs.opensearch.org/latest/vector-search/performance-tuning-search/#retrieve-vectors-using-doc-values/" target="_blank">doc values</a> instead of document source, with no reindexing required. <a href="https://docs.opensearch.org/latest/search-plugins/search-relevance/using-search-relevance-workbench/" target="_blank">Search Relevance Workbench</a> adds new evaluation metrics, CSV judgment uploads, and expanded hybrid search optimization, helping you measure and improve search quality.</p> 
<p>This launch also introduces new Query Insights capabilities, including automated query recommendations, a finished-queries cache for observing recently completed queries, and the option to export top query data to Amazon S3, helping you identify expensive queries and analyze trends over time.</p> 
<p>For information on upgrading to OpenSearch 3.7, please see the <a href="https://docs.aws.amazon.com/opensearch-service/latest/developerguide/version-migration.html" target="_blank">documentation</a>. OpenSearch 3.7 is now available in all AWS Regions where Amazon OpenSearch Service is available.</p>
