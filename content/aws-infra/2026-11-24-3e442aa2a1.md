# Amazon RDS for SQL Server now supports up to 500 databases per instance

<p><a href="https://aws.amazon.com/rds/sqlserver/" target="_blank">Amazon Relational Database Service (Amazon RDS) for SQL Server</a> now supports up to 500 databases per DB instance, up from the previous limit of 100. This higher density helps software as a service (SaaS) providers, multi-tenant applications, and other customers who run many databases on a DB instance. Previously, these customers had to spread their databases across several DB instances.</p> 
<p>You can use this feature to consolidate databases on fewer DB instances. This simplifies management, reduces the number of DB instances to monitor and patch, and lowers license and infrastructure costs. The 500-database limit applies to DB instances with 4 or more vCPUs (xlarge and larger, excluding burstable instance classes) on all SQL Server versions that Amazon RDS supports. It's available for Single-AZ deployments of Enterprise, Enterprise Developer, Standard, Standard Developer, and Web editions, and for Multi-AZ deployments of Enterprise, Enterprise Developer (using Always On Availability Groups), and Web edition.. Multi-AZ deployments using Database Mirroring, Multi-AZ deployments of Standard Edition, and smaller instances keep their current limits.</p> 
<p>This feature is available in all AWS Regions where Amazon RDS for SQL Server is available. To learn more, see <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/CHAP_SQLServer.html" target="_blank">Amazon RDS for Microsoft SQL Server User Guide</a>. For pricing details, see <a href="https://aws.amazon.com/rds/sqlserver/pricing/" target="_blank">Amazon RDS for SQL Server Pricing</a>.</p>
