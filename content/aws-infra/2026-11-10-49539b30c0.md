# Amazon ElastiCache Serverless now supports vector, full-text and hybrid searches plus aggregations

<p><a href="https://aws.amazon.com/elasticache/" rel="noopener noreferrer" target="_blank">Amazon ElastiCache</a> Serverless for Valkey now supports vector, full-text, and hybrid search, along with aggregations. Applications searching live data often face a hard trade-off between latency and recall, along with delays before updates become searchable. With search on ElastiCache Serverless, applications can search data with latency as low as microseconds at up to 99% recall for vector search, while serving billions of queries per day. Updates are searchable in as little as microseconds, as soon as writes complete.</p> 
<p>Search on ElastiCache Serverless is ideal for latency-sensitive applications with unpredictable traffic and for teams that want to get started with search quickly. You can combine search types in a single query, tune recall as needed, and analyze results with server-side aggregations. Developers can give every agent, session, or task its own datastore for memory and context retrieval, so agents can experiment, fail, and retry without touching production or each other. Each datastore is ready in seconds, reachable over a <a href="https://docs.aws.amazon.com/AmazonElastiCache/latest/dg/Endpoints.html" rel="noopener noreferrer" target="_blank">public endpoint</a> with no network setup, and billed only for what it uses, with zero infrastructure to manage. Applications can also power product discovery, recommendation systems, and retrieval-augmented generation (RAG).</p> 
<p>Search is available on ElastiCache Serverless for Valkey in all commercial AWS Regions, AWS GovCloud (US) Regions, and the AWS European Sovereign Cloud Region on ElastiCache version 9 for Valkey. Valkey is the most permissive open source and vendor-neutral alternative to Redis and the recommended engine for ElastiCache. To get started, create a new serverless cache or upgrade an existing one to Valkey 9 using the AWS Management Console, AWS SDK, or AWS CLI. To learn more, see the <a href="https://docs.aws.amazon.com/AmazonElastiCache/latest/dg/search.html" rel="noopener noreferrer" target="_blank">ElastiCache documentation</a>. For pricing, see the <a href="https://aws.amazon.com/elasticache/pricing/" rel="noopener noreferrer" target="_blank">ElastiCache pricing page</a>.</p>
