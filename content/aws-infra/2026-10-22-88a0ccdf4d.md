# AWS Service Reference Information now supports global condition keys, service names, and data plane classification

<p>AWS is expanding programmatic service reference information to help you automate IAM policy management and keep your policies aligned with the latest service updates. The service reference now includes all aws:-prefixed global condition keys in a single machine-readable file, a ServiceName field mapping service identifiers to human-readable names, and an IsDataPlane property identifying which actions are data plane operations.</p> 
<p>You can automate retrieval of this information to eliminate manual effort, and incorporate it directly into your existing policy management tools and processes. This feature is available at no additional cost. To get started, refer to the <a></a><a href="https://docs.aws.amazon.com/service-authorization/latest/reference/service-reference.html">documentation on programmatic service reference information</a>.</p>
