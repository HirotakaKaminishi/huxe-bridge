# Amazon Cognito now available as a skill in the Agent Toolkit for AWS

<p>Amazon Cognito is now available as a core skill (aws-auth) in the <a href="https://aws.amazon.com/products/developer-tools/agent-toolkit-for-aws/">Agent Toolkit for AWS</a>. AI coding agents using the toolkit can now set up, configure, secure, and troubleshoot Amazon Cognito using best-practice workflows, helping developers implement secure sign-in flows for users, AI agents, and microservices faster.</p> 
<p> </p> 
<p>The Amazon Cognito (aws-auth) skill covers user pool and app client configuration, managed login and OAuth 2.0 flows, token management, JWT authorizers, passkey/WebAuthn enrollment, threat protection, Lambda trigger wiring, and identity pools. When paired with the <a href="https://docs.aws.amazon.com/agent-toolkit/latest/userguide/mcp-server.html">AWS MCP Server</a>, agents execute AWS CLI commands with IAM-based guardrails and CloudTrail audit logging. The skill also works standalone via the AWS CLI.</p> 
<p> </p> 
<p>The Amazon Cognito (aws-auth) skill is available as part of the Agent Toolkit for AWS. To get started, see the <a href="https://github.com/aws/agent-toolkit-for-aws/tree/main/skills/core-skills/aws-auth">Amazon Cognito aws-auth skill on GitHub</a> or browse the <a href="https://docs.aws.amazon.com/agent-toolkit/latest/userguide/quick-start.html">Agent Toolkit Quick Start guide</a>. For more information about Amazon Cognito, see the <a href="https://docs.aws.amazon.com/cognito/latest/developerguide/what-is-amazon-cognito.html">Amazon Cognito Developer Guide</a>.</p>
