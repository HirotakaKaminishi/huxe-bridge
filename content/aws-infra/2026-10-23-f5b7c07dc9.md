# Amazon OpenSearch Serverless now supports a 5-second default refresh interval

<p>Starting today, Amazon OpenSearch Serverless reduces the default refresh interval to 5 seconds for both search and vector collections. The refresh interval controls how quickly newly ingested documents become available for search. By lowering the default from 10 seconds to 5 seconds, newly written data becomes searchable faster, giving applications quicker read-after-write visibility automatically, with no configuration changes and no action required on your part.</p> 
<p>This improvement applies to the next generation of Amazon OpenSearch Serverless and takes effect by default on both search and vector collections. Faster refresh is valuable for workloads that continuously ingest data and need near real-time retrieval, including full-text search over frequently updated content as well as vector use cases such as retrieval-augmented generation (RAG), semantic search, and recommendation and personalization systems. This means applications and AI agents can retrieve and act on the most recently ingested data sooner, improving the relevance and accuracy of search results and RAG responses for datasets that change frequently.</p> 
<p>The 5-second default refresh interval is available in all <a href="https://docs.aws.amazon.com/general/latest/gr/opensearch-service.html" rel="noopener noreferrer" target="_blank">24 regions</a> where Amazon OpenSearch Serverless is available today. To learn more, see the Amazon OpenSearch Serverless <a href="https://docs.aws.amazon.com/opensearch-service/latest/developerguide/serverless.html" rel="noopener noreferrer" target="_blank">documentation</a>.</p>
