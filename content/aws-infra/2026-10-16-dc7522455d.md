# AWS End User Messaging now offers managed OTP verification end-to-end

<p>Today, AWS End User Messaging announces end-to-end managed one-time passcode (OTP) verification in Notify. You get a working OTP solution in under five minutes, including AWS phone numbers and code verification, without setting up a phone number, registering with carriers, or managing how messages are delivered. Before, you generated the passcode yourself and passed it to Notify to send, and you built and maintained the logic to create, store, and expire codes. Now Notify generates the code, delivers it, and verifies the code the recipient enters, so you ship a complete verification flow and skip that work entirely. You can deliver codes over text, voice, and now WhatsApp.
 <br />
 <br />
 You set the rules once in a notify code configuration: the code type, length, how long it stays valid, and how many attempts a recipient gets, along with your templates for each channel. From then on, one call sends a code to a recipient on the channel you choose, and another checks the code they enter.
 <br />
 <br />
 Notify is available in all commercial AWS Regions where AWS End User Messaging is available.
 <br />
 <br />
 To learn more and get started, see the AWS End User Messaging <a href="https://docs.aws.amazon.com/end-user-messaging/latest/userguide/nx-notify.html">User Guide.</a></p>
