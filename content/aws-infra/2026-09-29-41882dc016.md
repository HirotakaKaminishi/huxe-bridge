# Amazon EC2 Future-dated Capacity Reservations Now Supports Postponing Start Dates

<p>Amazon EC2 Future-dated Capacity Reservations let you secure capacity up to 120 days in advance by specifying the capacity you need, the start date, and a commitment duration. If your plans change before delivery, you can now postpone your start date to match your new timeline.</p>
<p>When you postpone your start date, EC2 presents a quote that shows the new start date and the required commitment duration. The commitment duration can increase, depending on when you postpone the start date. After you review and accept the quote, EC2 updates your reservation with the new start date.</p>
<p>This feature is available to all Future-dated Capacity Reservation customers. Refer to the <a href="https://builder.aws.com/build/capabilities/explore">AWS Capabilities by Region</a> website for the feature's regional availability. For more details, refer to the <a href="https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/capacity-reservations-modify.html">Capacity Reservation user guide</a>.</p>
