# Amazon RDS for PostgreSQL now supports post-quantum TLS key exchange

<p>Starting today, <a href="https://aws.amazon.com/rds/postgresql/" rel="noopener noreferrer" target="_blank">Amazon RDS for PostgreSQL</a> introduces support for post-quantum TLS (PQ-TLS) key exchange, providing you with post-quantum cryptography options for encrypting your data in-transit.</p>
<p>RDS for PostgreSQL versions 18 and higher support modification of the ssl_groups parameter. You can <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/PostgreSQL.Concepts.General.SSL.html#PostgreSQL.Concepts.General.SSL.Groups" rel="noopener noreferrer" target="_blank">select cryptographic groups</a> from the RDS for PostgreSQL allow list to align with your organization's security standards.</p>
<p>Amazon RDS for PostgreSQL makes it simple to set up, operate, and scale PostgreSQL deployments in the cloud. Create or update a fully managed Amazon RDS database in the <a href="https://console.aws.amazon.com/rds/" rel="noopener noreferrer" target="_blank">Amazon RDS Management Console</a> or by using the AWS Command Line Interface (AWS CLI).</p>
