# Amazon EKS and Amazon EKS Distro now support Kubernetes version 1.37

<p>Kubernetes version 1.37 introduced several new features and bug fixes, and AWS is excited to announce that you can now use <a href="https://aws.amazon.com/eks/" rel="noopener noreferrer" target="_blank">Amazon Elastic Kubernetes Service</a> (EKS) and <a href="https://aws.amazon.com/eks/eks-distro/" rel="noopener noreferrer" target="_blank">Amazon EKS Distro</a> to run Kubernetes version 1.37. Starting today, you can create new EKS clusters using version 1.37 and upgrade existing clusters to version 1.37 using the EKS console, the eksctl command line interface, or through an infrastructure-as-code tool.</p>
<p>Kubernetes version 1.37 introduces several key improvements, promoting the Metrics API to general availability as <i>metrics.k8s.io/v1</i>. This API provides Pod and node CPU and memory usage for the Horizontal Pod Autoscaler and <i>kubectl top</i>. Dynamic Resource Allocation (DRA) device taints and tolerations also graduate to general availability, letting DRA drivers and administrators taint devices such as GPUs so the scheduler avoids them unless tolerated. Horizontal Pod Autoscaler scale-to-zero graduates to beta and is enabled by default, allowing autoscalers with <i>minReplicas: 0</i> that use object or external metrics to scale workloads to zero Pods when idle and back up when demand returns. To learn more about Kubernetes version 1.37, see our <a href="https://docs.aws.amazon.com/eks/latest/userguide/kubernetes-versions-standard.html" rel="noopener noreferrer" target="_blank">documentation</a> and the Kubernetes project <a href="https://github.com/kubernetes/kubernetes/blob/master/CHANGELOG/CHANGELOG-1.37.md" rel="noopener noreferrer" target="_blank">release notes.</a></p>
<p>EKS now supports Kubernetes version 1.37 in all the AWS Regions where EKS is available, including the AWS GovCloud (US) Regions.</p>
<p>You can learn more about the Kubernetes versions available on EKS and instructions to update your cluster to version 1.37 by visiting EKS documentation. You can use <a href="https://docs.aws.amazon.com/eks/latest/userguide/cluster-insights.html" rel="noopener noreferrer" target="_blank">EKS cluster insights</a> to check if there are any issues that can impact your Kubernetes cluster upgrades. EKS Distro builds of Kubernetes version 1.37 are available through ECR Public Gallery and GitHub. Learn more about the EKS version lifecycle policies in the <a href="https://docs.aws.amazon.com/eks/latest/userguide/kubernetes-versions.html" rel="noopener noreferrer" target="_blank">documentation</a>.</p>
