# Web Search on Amazon Bedrock AgentCore expands to AWS GovCloud and 3 Regions

<p>Web Search on Amazon Bedrock AgentCore is now available in four additional AWS Regions: US East (Ohio), US West (Oregon), Asia Pacific (Sydney), and AWS GovCloud (US-West). Web Search is a fully managed tool that provides AI agents with current grounding from the web, enabling more accurate and up-to-date responses for tasks such as research, summarization, and question answering.</p>
<p>With this expansion, customers can build agents that retrieve web information closer to their applications and end users with lower latency. Customers with government workloads can now use Web Search in the AWS GovCloud (US-West) Region to meet compliance and data residency requirements. </p>
<p>To learn more about Web Search on Amazon Bedrock AgentCore, see the <a href="https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/gateway-target-connector-web-search-tool.html">Web Search tool documentation</a>. To learn about pricing, visit <a href="https://aws.amazon.com/bedrock/agentcore/pricing/">Amazon Bedrock AgentCore pricing</a>. For Region availability, visit <a href="https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/agentcore-regions.html">Supported AWS Regions</a>.</p>
