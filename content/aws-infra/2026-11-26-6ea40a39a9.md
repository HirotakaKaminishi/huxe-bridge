# Amazon EC2 M9gd instances are now available in Asia Pacific (Seoul)

<p>Starting today, Amazon Elastic Compute Cloud (Amazon EC2) M9gd instances are available in the Asia Pacific (Seoul) region. These instances are powered by AWS Graviton5 processors, the fifth generation of custom-designed CPUs, which deliver the best price performance for a broad range of workloads running on Amazon EC2.</p> 
<p><a href="https://aws.amazon.com/ec2/instance-types/m9g/">M9gd instances</a> deliver up to 25% better compute performance than AWS Graviton4-based M8gd instances. They are up to 30% faster for databases, up to 35% faster for web applications, and up to 35% faster for machine learning. These instances are built on the sixth-generation <a href="https://aws.amazon.com/ec2/nitro/">AWS Nitro System</a> and are the first to feature the <a href="https://aws.amazon.com/blogs/compute/aws-nitro-isolation-engine-formally-verifying-the-hypervisor-in-the-aws-nitro-system/">Nitro Isolation Engine</a>. The Isolation Engine uses formal verification to provide mathematical assurance that customer workloads are isolated from each other and from AWS operators, pioneering a new standard for mathematically proven cloud security.</p> 
<p>M9gd instances serve a broad range of general-purpose workloads, including application servers, microservices, gaming, caching, and containers. They also deliver the performance needed for agentic AI use cases like real-time reasoning, code generation, and multi-step orchestration. M9gd instances also offer local NVMe-based SSD block-level storage for workloads that need high-speed, low-latency local storage for scratch space, temporary files, and caches.</p> 
<p>M9gd instances are available for purchase in this region via Savings Plans, On-Demand, Spot Instances, Dedicated Instances, or Dedicated Hosts. <a href="https://aws.amazon.com/ec2/graviton/level-up-with-graviton/">Level up your compute with AWS Graviton</a> and <a href="https://aws.amazon.com/ec2/instance-types/m9g/">get started with M9gd today</a>.</p>
