# Web Search on Amazon Bedrock now supports domain filtering and user location controls

<p>Web Search on Amazon Bedrock now supports two new controls that give you more precision over the results that ground a model's response: domain filtering and user location. Both are configured directly on the web_search tool in your existing OpenAI Responses API request.</p> 
<p>With domain filtering, you can restrict Web Search results to a set of domains you choose. Using the filters parameter, you specify up to 100 allowed_domains to limit results to trusted sources, or up to 100 blocked_domains to exclude sources you don't want. This is useful when you want responses grounded only in specific sites, or when you need to keep certain domains out of results.</p> 
<p>With user location, you can optionally specify location parameters so that Web Search can return results relevant to that geography. This helps with location-dependent questions, such as regional availability or local services.</p> 
<p>Domain filtering and user location are available in all AWS Regions where Web Search is supported: US East (N. Virginia), US East (Ohio), US West (Oregon), and AWS GovCloud (US-West). To get started, see the Web Search section in the <a href="https://docs.aws.amazon.com/bedrock/latest/userguide/web-search.html">Amazon Bedrock User Guide</a>. For pricing, see the <a href="https://aws.amazon.com/bedrock/pricing/">Amazon Bedrock pricing page</a>.</p>
