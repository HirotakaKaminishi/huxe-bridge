# AWS Lambda durable functions are now available in AWS GovCloud (US) Regions

<p>AWS Lambda durable functions are now available in the AWS GovCloud (US-West) and AWS GovCloud (US-East) Regions. Lambda durable functions enable developers to build reliable multi-step applications and AI workflows within the Lambda developer experience.</p>
<p>Lambda durable functions extend the Lambda programming model with new primitives in your event handler, such as "step" and "wait", allowing you to checkpoint progress, automatically recover from failures, and pause executions without incurring compute charges for on-demand functions. With availability in the AWS GovCloud (US) Regions, government customers and regulated industries can orchestrate complex processes such as order workflows, user onboarding, and AI-assisted tasks while meeting stringent compliance and security requirements.</p>
<p>You can activate durable functions for new Python (versions 3.13 and 3.14), Node.js (versions 22 and 24), Go (versions 1.24 or later), .Net (version 2.2), or Java (17+) based Lambda functions using the AWS Lambda API, AWS Management Console, or AWS SDK. You can also use infrastructure as code tools such as AWS CloudFormation, AWS Serverless Application Model (AWS SAM), and the AWS Cloud Development Kit (AWS CDK).</p>
<p>For more information on durable functions, visit the <a href="https://aws.amazon.com/lambda/lambda-durable-functions/">AWS Lambda durable functions product page</a> or the <a href="https://docs.aws.amazon.com/lambda/latest/dg/">AWS Lambda Developer Guide</a>. To learn about pricing, visit <a href="https://aws.amazon.com/lambda/pricing/">AWS Lambda pricing</a>. For region availability, visit the <a href="https://builder.aws.com/build/capabilities">AWS Capabilities by Region page</a>. </p>
