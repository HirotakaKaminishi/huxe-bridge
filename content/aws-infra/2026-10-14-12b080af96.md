# Amazon DCV releases version 2026.0 with RHEL 10 support and new clients

<p>Amazon DCV 2026.0 is now available, adding support for RHEL 10, Rocky Linux 10, CentOS 10, and Ubuntu 26.04 along with a new macOS client and updated Windows and Linux clients. Amazon DCV is a high-performance remote display protocol that enables customers to securely access remote desktops and application sessions across Windows, Linux, and macOS.</p>
<p>Amazon DCV 2026.0 includes the following key features and improvements:</p>
<ul>
 <li>
  <p>Support for RHEL 10, Rocky Linux 10, CentOS 10, and Ubuntu 26.04, with Linux hosts and sessions running on the modern Wayland display server</p>
 </li>
 <li>
  <p>A new macOS client with gamepad support, and updated Windows and Linux clients</p>
 </li>
 <li>
  <p>URL redirection on Windows hosts, so configured links opened in a remote session launch in the local browser on the client device</p>
 </li>
 <li>
  <p>Printer preferences redirection on Windows, giving remote sessions access to client-side printer settings</p>
 </li>
 <li>
  <p>Performance improvements, including H.264 frame slice support and slice-based multithreaded decoding on the Linux and macOS clients for lower latency</p>
 </li>
 <li>
  <p>Support for new macOS server versions on Amazon EC2</p>
 </li>
</ul>
<p>For more information about the new features and enhancements in Amazon DCV 2026.0, see the <a href="https://docs.aws.amazon.com/dcv/latest/adminguide/doc-history-release-notes.html" rel="noopener noreferrer" target="_blank">release notes</a> or visit the <a href="https://aws.amazon.com/hpc/dcv/" rel="noopener noreferrer" target="_blank">Amazon DCV webpage</a> to learn more and get started.</p>
