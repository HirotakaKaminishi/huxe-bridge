# Amazon RDS for MySQL 26.10 is now available in Amazon RDS Database Preview Environment

<p>Starting today, <a href="https://aws.amazon.com/rds/mysql/" rel="noopener noreferrer" target="_blank">Amazon RDS for MySQL</a> 26.10 is available in the <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/create-db-instance-in-preview-environment.html" rel="noopener noreferrer" target="_blank">Amazon RDS Database Preview Environment</a>, allowing you to evaluate the pre-release of MySQL 26.10 on Amazon RDS for MySQL.</p> 
<p>MySQL 26.10 includes bug fixes, security patches, and some improvements to READ COMMITTED workload performance and purge lag warnings in the error log. On busy READ COMMITTED workloads, NUMA systems performance could be impacted as each read view that closed required a global mutex. Read-view objects can now be reused which eliminates the global mutex on closure. The error log now reports warnings when the history-list length (HLL) crosses innodb_max_purge_lag and when purge lag begins delaying DML, so you can detect purge backlogs before they affect performance. To learn more, please refer to the <a href="https://dev.mysql.com/doc/refman/26.10/en/mysql-nutshell.html" rel="noopener noreferrer" target="_blank">MySQL 26.10 release notes</a>.</p> 
<p>Amazon RDS Database Preview Environment database instances are retained for a maximum period of 60 days and are automatically deleted after the retention period. Amazon RDS database snapshots that are created in the Preview Environment can only be used to create or restore database instances within the Preview Environment. Amazon RDS Database Preview Environment database instances are priced as per the <a href="https://aws.amazon.com/rds/mysql/pricing/" rel="noopener noreferrer" target="_blank">pricing</a> in the US East (Ohio) Region.</p>
