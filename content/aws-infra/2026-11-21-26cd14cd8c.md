# Amazon CloudWatch EKS Container Insights now offers built-in monitoring for open source Kubernetes tools

<p>Today, Amazon CloudWatch announces built-in monitoring for open source tools running on your Amazon EKS clusters, including Karpenter, KEDA, vLLM, KServe, SGLang, Ray and Knative Serving. You get dashboards for the tools you already use without running Prometheus or Grafana yourself.</p> 
<p>Monitoring starts automatically when you enable OTel Container Insights. For your AI inference workloads, you can see queued requests, time to first token, and KV cache usage for each model server. For autoscaling, you can see which scalers are failing and how long your scale loop takes. CloudWatch tags every metric with its pod, workload, and node, so you can trace a slow model server to the node it runs on.</p> 
<p>These EKS solutions are available in version 8.0.0 and later of the add-on and Helm chart, in all AWS Regions where CloudWatch supports OpenTelemetry metrics. Metrics are charged at the Amazon EKS OpenTelemetry ingestion rate of $0.08 per GB. For details, see Amazon CloudWatch <a href="https://aws.amazon.com/cloudwatch/pricing/" title="CloudWatch EKS insights pricing">insights pricing</a>. </p> 
<p>To get started, see Solutions in the Amazon CloudWatch <a href="https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/container-insights-eks-otel.html" title="CloudWatch EKS OTel Container Insights">User Guide.</a></p>
