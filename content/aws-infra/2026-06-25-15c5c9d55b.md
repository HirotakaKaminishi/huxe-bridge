# Amazon RDS now supports the latest GDR updates for Microsoft SQL Server

<p><a href="https://aws.amazon.com/rds/sqlserver/" rel="noopener noreferrer" target="_blank">Amazon Relational Database Service (Amazon RDS) for SQL Server </a>now supports the latest General Distribution Release (GDR) updates for Microsoft SQL Server. This release includes support for Microsoft SQL Server 2016 SP3+GDR <a href="https://support.microsoft.com/help/5084821" rel="noopener noreferrer" target="_blank">KB5084821</a> (RDS version 13.00.6485.1.v1), SQL Server 2017 CU31+GDR <a href="https://support.microsoft.com/help/5084818" rel="noopener noreferrer" target="_blank">KB5084818</a> (RDS version 14.00.3525.1.v1), SQL Server 2019 CU32+GDR <a href="https://support.microsoft.com/help/5084816" rel="noopener noreferrer" target="_blank">KB5084816</a> (RDS version 15.00.4465.1.v1) and SQL Server 2022 CU24+GDR <a href="https://support.microsoft.com/help/5083252" rel="noopener noreferrer" target="_blank">KB5083252</a> (RDS version 16.00.4250.1.v1).<br /> <br /> The GDR updates address vulnerabilities described in CVE-2026-32167 and CVE-2026-32176. For additional information on the improvements and fixes included in these updates, see Microsoft documentation for KB5084821, KB5084818, KB5084816, KB5083252. We recommend that you upgrade your Amazon RDS for SQL Server instances to apply these updates using Amazon RDS Management Console, or by using the AWS SDK or CLI. You can learn more about upgrading your database instance in the <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/USER_UpgradeDBInstance.SQLServer.html" rel="noopener noreferrer" target="_blank">Amazon RDS SQL Server User Guide for upgrading your RDS Microsoft SQL Server DB engine</a>.</p>
