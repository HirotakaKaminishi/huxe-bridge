# Amazon CloudFront Functions now supports logging to CloudFront access logs

<p>You can now write custom data directly into CloudFront access logs using a new helper method available from within CloudFront Functions. CloudFront Functions run lightweight JavaScript at the edge for tasks like URL rewrites, header manipulation, and request routing. Previously, you could only emit log data to Amazon CloudWatch Logs as a separate log file from your CloudFront access logs. With this launch, you no longer need to correlate function decisions with CloudFront access log data across separate logging systems.</p> 
<p>You can call <i>cf.logCustomData() </i>from viewer request or viewer response functions to log values such as A/B test variant assignments, authentication outcomes, or routing decisions directly into the CloudFront access log record for that request. This works with both CloudFront real time log configurations and standard logging (v2), so you can analyze function behavior and request outcomes in a single query. The existing <i>console.log()</i> functionality remains available and the two methods can be used together in the same function.</p> 
<p>Amazon CloudFront Functions custom log data is available today in all CloudFront edge locations. There is no additional charge for using <i>cf.logCustomData().</i> Standard CloudFront Functions invocation pricing and access log delivery charges apply. To get started, visit <a href="https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/general-helper-methods.html#log-custom-data-method" rel="noopener noreferrer" target="_blank">CloudFront Functions helper methods</a>.</p>
