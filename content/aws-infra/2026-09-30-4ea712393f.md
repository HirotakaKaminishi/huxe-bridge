# Amazon Connect Customer now lets business users manage more reference data to adjust contact center configurations in real time

<p>Amazon Connect Customer now lets administrators store more of the reference data that drives their contact center configurations. Administrators can now use data tables to hold up to 20,000 values per table for defining configurations such as operating hours, escalation rules, AI agent prompts or queue assignments that drive contact flows. Administrators can now also export tables, edit hundreds of records, move tables between Connect Customer instances, or load reference data from external systems using tools and sources such as Excel and DynamoDB. Business teams can keep this data current themselves, adjusting their contact center configurations as conditions change without depending on technical resources.</p>
<p>This feature is available in all AWS commercial and AWS GovCloud (US-West) <a href="https://docs.aws.amazon.com/connect/latest/adminguide/regions.html#amazonconnect_region" rel="noopener noreferrer" target="_blank">regions</a> where Amazon Connect Customer is offered. To learn more, see <a href="https://docs.aws.amazon.com/connect/latest/adminguide/data-tables.html" rel="noopener noreferrer" target="_blank">Create and configure data tables</a> in the Amazon Connect Administrator Guide. To learn more about Amazon Connect, visit the <a href="https://aws.amazon.com/products/connect/customer/" rel="noopener noreferrer" target="_blank">Amazon Connect Customer website </a>.</p>
