# Amazon SES simplifies sending emails over SMTP using Mail Manager

<p>Amazon Simple Email Service (SES) now offers a simplified console experience for sending emails over SMTP using Mail Manager. Mail Manager is a capability within SES for managing email flow, but configuring its resources individually to set up SMTP sending requires multiple steps. The new guided setup creates and configures these resources automatically, so developers can get started in just a few clicks.</p> 
<p>The guided setup gives developers a working SMTP endpoint and downloadable credentials they can plug into any application or framework that supports SMTP. This is ideal for teams building applications that send email notifications, password resets, or transactional messages and need a fast path to a production-ready SMTP configuration.</p> 
<p>This experience is available in all <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">AWS Regions</a> where <a href="https://aws.amazon.com/ses/">Amazon SES</a> is available.</p> 
<p>To learn more, visit the <a href="https://console.aws.amazon.com/ses/">Amazon SES console</a> or refer to the <a href="https://docs.aws.amazon.com/ses/latest/dg/smtp-credentials-mail-manager.html">documentation</a>.</p>
