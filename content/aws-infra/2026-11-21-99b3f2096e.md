# AWS Lambda now publishes Event Function state change events to Amazon EventBridge

<p><a href="https://aws.amazon.com/lambda/" rel="noopener noreferrer" target="_blank">AWS Lambda</a> now publishes Event Function state change events to <a href="https://aws.amazon.com/eventbridge/" rel="noopener noreferrer" target="_blank">Amazon EventBridge</a>. Lambda emits an event each time an Event Function version changes state because of a customer action, such as creating, updating, publishing, or deleting a function. These events help platform and DevOps teams to trigger automation as soon as a function becomes ready to invoke, an update finishes, or an operation fails, without polling the <a href="https://docs.aws.amazon.com/lambda/latest/api/API_GetFunction.html" rel="noopener noreferrer" target="_blank">GetFunction</a> API.</p> 
<p>Customers use Lambda Event Functions to build APIs, event processing workloads, multi-step workflows, and data pipelines. As organizations grow to thousands of functions, platform teams need to know when a function changes state so they can take the next step. For example, a deployment pipeline can run integration tests and then shift alias traffic once a new version becomes active. Until now, these tools had to poll the GetFunction API to track state changes. Polling consumed API quota, slowed down pipelines, and required custom retry logic, which added operational overhead. With this launch, you can create <a href="https://docs.aws.amazon.com/eventbridge/latest/userguide/eb-rules.html" rel="noopener noreferrer" target="_blank">EventBridge rules</a> that match on fields such as the function ARN, detail type, or state, and route matched events to targets such as <a href="https://aws.amazon.com/step-functions/" rel="noopener noreferrer" target="_blank">AWS Step Functions</a>, AWS Lambda, <a href="https://aws.amazon.com/sns/" rel="noopener noreferrer" target="_blank">Amazon SNS</a>, or <a href="https://aws.amazon.com/sqs/" rel="noopener noreferrer" target="_blank">Amazon SQS</a>. This helps you build reliable, event-driven deployment pipelines across all of your functions, without writing or maintaining custom polling logic.</p> 
<p>This feature is available in all commercial <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/" target="_blank">AWS Regions</a>. You can create rules by using the EventBridge console, AWS Command Line Interface (AWS CLI), AWS SDKs, AWS CloudFormation, AWS Cloud Development Kit (AWS CDK), or AWS Serverless Application Model (AWS SAM). Lambda publishes these events automatically at no additional cost. Standard pricing applies to the targets that your EventBridge rules invoke. To learn more, see the <a href="https://docs.aws.amazon.com/lambda/latest/dg/monitoring-eventbridge-function-state.html" rel="noopener noreferrer" target="_blank">AWS Lambda Developer Guide</a> and the <a href="https://docs.aws.amazon.com/eventbridge/latest/userguide/eb-what-is.html" target="_blank">Amazon EventBridge User Guide.</a></p>
