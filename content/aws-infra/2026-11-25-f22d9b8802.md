# Amazon Connect Customer dashboards now support grouping historical metrics by time interval

<p>Amazon Connect Customer analytics dashboards now support grouping historical metrics by time interval on trailing widgets, giving contact center managers granular control over how performance data is visualized over time. Trailing widgets now display data grouped by 15-minute, 30-minute, one-hour, daily, and weekly intervals. For example, a workforce manager investigating a spike in average handle time can switch from a daily view to 15-minute intervals to pinpoint the exact period the spike occurred, then zoom out to a weekly view to confirm whether it reflects a broader trend.</p> 
<p>Time interval grouping on dashboards is available in all AWS <a href="https://docs.aws.amazon.com/connect/latest/adminguide/regions.html#amazonconnect_region">regions</a> where Amazon Connect Customer is offered. To learn more, see the <a href="https://docs.aws.amazon.com/connect/latest/adminguide/dashboard-customize-widgets.html#configure-groupings">Amazon Connect Customer Administrator Guide.</a>  To learn more about Amazon Connect Customer, visit the <a href="https://aws.amazon.com/connect/">Amazon Connect Customer website</a>.</p>
