# AWS Transform now accelerates migration deals for Migration Acceleration Program (MAP) benefits

<p>AWS Partners can now expedite Migration Acceleration Program (MAP) deals, from qualification to incentive payout, with an end-to-end agentic workflow in AWS Transform. Partners can manage the full MAP lifecycle without leaving AWS Transform, including deal qualification, funding approvals, agreement execution, migration planning and execution, resource tagging, and incentive disbursement.</p>
<p>Previously, Partners had to switch between separate systems for opportunity discovery, assessments, deal qualification, funding approvals, agreement execution, resource tagging, and incentive disbursement. This fragmentation, along with manual handoffs between steps, led to longer qualification cycles.</p>
<p>Now, with the agentic MAP experience in AWS Transform, Partners connect their AWS Partner Central account and invite customers into the same engagement. Partners start by scoping customer environments with the built-in agentic discovery tool, or by importing data from RVTools or AWS-validated ISV tools listed in AWS Marketplace. AWS Transform then combines this discovery data with opportunity details from APN Customer Engagements (ACE) to automatically qualify Partner-initiated opportunities in a guided flow, so Partners get eligibility decisions sooner and close deals faster. As the migration progresses, MAP resource tags are applied automatically, and Partner cash and customer credits are disbursed based on actual usage data. Throughout, customers get shared, real-time visibility into migration projects alongside their Partner.</p>
<p>AWS Transform with integrated MAP is now available in all <a href="https://docs.aws.amazon.com/transform/latest/userguide/regions.html" target="_blank">AWS Regions where AWS Transform is supported</a>. To learn more, visit the <a href="https://aws.amazon.com/migration-acceleration-program/">AWS Migration Acceleration Program (MAP)</a> page. Partners can get started with the <a href="https://us-east-1.console.aws.amazon.com/partnercentral/content/guidedetails/6955b492-4e51-4de6-9da9-c92f2e2920f8?region=us-east-1" target="_blank">AWS Partner Central user guide</a> (login required) or by contacting their Partner Development Manager. Customers can contact their AWS account team or AWS Partner.</p>
