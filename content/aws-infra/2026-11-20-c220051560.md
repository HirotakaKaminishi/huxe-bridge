# AWS Marketplace now supports agentic payments with AgentCore

<p>AWS Marketplace now supports agentic payments over the x402 protocol, so AI agents can discover and buy select products and pay per request in US dollars through AgentCore payments, part of Amazon Bedrock AgentCore. Agents often need paid APIs, data, or content mid-task, but access usually requires a person to sign up, add a payment method, and create an API key. With agentic payments, customers skip that per-seller setup, and charges settle on their existing AWS bill with no crypto wallet required.</p> 
<p>Customers enable the AWS Marketplace payment connector in AgentCore payments, then they or their agents find listings through the AWS Marketplace connector in AgentCore Gateway. For example, a research agent can buy a single web search, or a coding agent can call a paid guardrail service. Customers can set spending limits, approved sellers, and guardrails before agents transact, Private Marketplace policies still apply, and transactions appear in AWS CloudTrail and AWS Cost Explorer.</p> 
<p>AWS Marketplace sellers can charge AI agents per request without building a sign-up flow or billing system. They register with AWS Marketplace, configure agentic payments for their listings, and integrate the <a href="https://github.com/aws/fiat-extension-for-x402/blob/main/docs/sdk-guide.md">AWS Marketplace x402 SDK</a>. AWS Marketplace collects customer payments and pays sellers through their AWS Marketplace seller disbursements, like other AWS Marketplace transactions.</p> 
<p>The capability is available in all AWS Regions where AgentCore payments is available. To learn more, see <a href="https://aws.amazon.com/marketplace/solutions/ai-agents-and-tools?ams%23interactive-card-vertical%23pattern-data-843993407.filters=((id:GLOBAL%23local-tags-aws-marketplace-agentic-ai-x402-support.and,value:(x402-support)))">AWS Marketplace</a> and the <a href="https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/payments-process-payment.html" rel="noopener noreferrer" target="_blank">Amazon Bedrock AgentCore Developer Guide</a>. To list as a seller, see the <a href="https://docs.aws.amazon.com/marketplace/latest/userguide/agentic-commerce-products.html" rel="noopener noreferrer" target="_blank">AWS Marketplace Seller Guide.</a></p>
