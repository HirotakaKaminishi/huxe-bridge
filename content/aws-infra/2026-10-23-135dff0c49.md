# Amazon SageMaker AI announces training session APIs for serverless model customization

<p>Amazon SageMaker AI serverless model customization now supports training session APIs, giving customers full control over their post-training algorithm without provisioning or managing GPU infrastructure. Managed techniques, including SFT, DPO, and other reinforcement learning methods, let customers pick a technique and a model and have SageMaker AI run the training. With training session APIs, teams get to write the training loop, whether that's reproducing SFT or DPO on their own terms or implementing a custom loss, a new RL reward signal, a data curriculum, or an algorithm straight from the latest research. Operations such as forward_backward(), optim_step(), and sample() become API calls against a live, stateful session, so customers compose whatever training procedure their technique requires while SageMaker AI handles GPU allocation, model and LoRA loading, distributed execution, fault recovery, checkpoint storage, and security.<br /> <br /> Customers can call these operations directly from their own Python code to drive reinforcement learning, supervised fine-tuning, or custom training objectives against a live session, with checkpointing and resume built in. Billing is per token processed, so local computation like reward scoring isn't billed as GPU time. SageMaker AI is also releasing the <a href="https://github.com/aws/sagemaker-training-sessions-cookbook">SageMaker training sessions cookbook</a>, a set of ready-to-run SFT and RL recipes customers can use as blueprints for their own training loops.<a href="https://docs.aws.amazon.com/sagemaker/latest/dg/customizing-models-training-sessions.html"></a></p> 
<p>Training session APIs are generally available today in US East (N. Virginia), US West (Oregon), and Asia Pacific (Mumbai). To get started, install the SageMaker Python SDK and clone the cookbook, or launch a notebook in SageMaker Studio and connect a coding agent. To learn more, visit the <a href="https://docs.aws.amazon.com/sagemaker/latest/dg/customizing-models-training-sessions.html">documentation </a>and the <a href="https://aws.amazon.com/sagemaker/ai/model-customization/">Amazon SageMaker AI webpage.</a></p>
