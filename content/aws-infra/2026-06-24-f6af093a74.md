# Amazon CloudWatch now supports tags on dashboards

<p><a href="https://aws.amazon.com/cloudwatch" rel="noopener noreferrer" target="_blank">A<i><b></b></i>mazon CloudWatch</a> now supports tagging for CloudWatch dashboards, enabling you to organize, categorize, and control access to your dashboards using tags. Tags are key-value pairs that help you identify and manage AWS resources across your environment.<br /> <br /> With this launch, the <a href="https://docs.aws.amazon.com/AmazonCloudWatch/latest/APIReference/API_PutDashboard.html" rel="noopener noreferrer" target="_blank">PutDashboard</a> API now accepts an optional Tags parameter, allowing you to assign up to 50 tags when creating a new dashboard. The TagResource, UntagResource, and ListTagsForResource APIs now support dashboard ARNs, enabling you to add, remove, and list tags on existing dashboards. You can also manage dashboard tags using AWS CloudFormation. This new capability allows you to group dashboards by team by team, project, or environment, implement attribute-based access control by scoping IAM permissions to dashboards with specific tag values, and filter dashboards by tag in AWS Resource Explorer.<br /> <br /> CloudWatch Dashboard tagging support is available at no additional cost in all <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/" target="_blank">AWS Regions</a> where Amazon CloudWatch is available.<br /> <br /> To learn more, see <a href="https://docs.aws.amazon.com/AmazonCloudWatch/latest/APIReference/API_TagResource.html" rel="noopener noreferrer" target="_blank">TagResource</a> in the Amazon CloudWatch API Reference. To get started with CloudWatch dashboards, see <a href="https://aws.amazon.com/cloudwatch/features/" rel="noopener noreferrer" target="_blank">Amazon CloudWatch features</a>.</p>
