# Amazon EC2 C9g instances are now available in additional regions

<p>Starting today, Amazon Elastic Compute Cloud (Amazon EC2) C9g instances are available in the Asia Pacific (Sydney), Europe (Ireland, Spain), and South America (São Paulo) regions. These instances are powered by AWS Graviton5 processors, the fifth generation of custom-designed CPUs, which deliver the best price performance for a broad range of workloads running on Amazon EC2.</p> 
<p><a href="https://aws.amazon.com/ec2/instance-types/c9g/">C9g instances</a> deliver up to 25% better compute performance than AWS Graviton4-based C8g instances. They are up to 30% faster for databases, up to 35% faster for web applications, and up to 35% faster for machine learning. These instances are built on the sixth-generation <a href="https://aws.amazon.com/ec2/nitro/">AWS Nitro System</a> and are the first to feature the <a href="https://aws.amazon.com/blogs/compute/aws-nitro-isolation-engine-formally-verifying-the-hypervisor-in-the-aws-nitro-system/">Nitro Isolation Engine</a>. The Isolation Engine uses formal verification to provide mathematical assurance that customer workloads are isolated from each other and from AWS operators, pioneering a new standard for mathematically proven cloud security.</p> 
<p>C9g instances are ideal for compute-intensive workloads such as high-performance computing (HPC), batch processing, gaming, video encoding, scientific modeling, distributed analytics, CPU-based machine learning (ML) inference, real-time analytics, and ad serving.</p> 
<p>C9g instances are available for purchase in these regions via Savings Plans, On-Demand, Spot Instances, Dedicated Instances, or Dedicated Hosts. <a href="https://aws.amazon.com/ec2/graviton/level-up-with-graviton/">Level up your compute with AWS Graviton</a> and <a href="https://aws.amazon.com/ec2/instance-types/c9g/">get started with C9g today</a>.</p>
