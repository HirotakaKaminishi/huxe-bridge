# Amazon OpenSearch Serverless is now available in the Africa (Cape Town) Region

<p>Starting today, the next generation of Amazon OpenSearch Serverless is available in the AWS Africa (Cape Town) Region. Customers can now use a fully managed search, vector and analytics engine that provisions resources in seconds, auto scales instantly to meet changing demand, and scales to zero when idle, so customers only pay for the compute they use.</p> 
<p>With this launch, customers in the Africa (Cape Town) Region can run agentic AI, search, and observability workloads without provisioning or managing clusters. Compute is fully separated from storage, which lets customers scale compute independently to reduce costs during low-traffic periods while remaining ready for traffic spikes. With scale-to-zero and pay-per-usage pricing, customers can save up to 60% compared to provisioning OpenSearch clusters for peak loads.</p> 
<p>To learn more, see the OpenSearch Serverless <a href="https://docs.aws.amazon.com/opensearch-service/latest/developerguide/serverless.html" rel="noopener noreferrer" target="_blank">documentation</a> and <a href="https://aws.amazon.com/opensearch-service/pricing/" rel="noopener noreferrer" target="_blank">pricing page</a>. For the full list of AWS Regions where OpenSearch Serverless is available, see the <a href="https://docs.aws.amazon.com/general/latest/gr/opensearch-service.html" rel="noopener noreferrer" target="_blank">Regional Services List.</a></p>
