# AWS License Manager now supports license type conversions for Ubuntu Pro purchased through AWS Marketplace

<p><a href="https://aws.amazon.com/license-manager/">AWS License Manager </a> now supports in-place upgrades for EC2 Ubuntu LTS (Long Term Support) instances to Ubuntu Pro available on AWS Marketplace. This allows customers to strengthen their security posture and meet compliance requirements without rebuilding their fleet or migrating workloads to a new instance or AMI. With an Ubuntu Pro subscription, customers receive security patches for up to 10 years — extendable to 15 years with the Legacy add-on. This coverage extends beyond the base OS to thousands of additional packages, including widely used open-source applications such as NGINX, PostgreSQL, MongoDB, and Redis. Ubuntu Pro also supports Kernel Livepatch, which applies critical kernel security fixes without rebooting to minimize downtime.</p>
<p>With this launch, customers, who have an existing Canonical Ubuntu Pro subscription through AWS Marketplace, can upgrade directly during the conversion workflow. Customers who do not yet have a subscription can subscribe to Canonical Ubuntu Pro from within the AWS License Manager console. The new feature is available in  <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">all commercial regions </a> where AWS License Manager is available.</p>
<p>To get started, navigate to the  <a href="https://us-east-1.console.aws.amazon.com/license-manager/home?region=us-east-1#/">AWS License Manager console </a> and the  <a href="https://docs.aws.amazon.com/license-manager/latest/userguide/license-asset-groups-overview.html">AWS License Manager User Guide </a>. </p>
