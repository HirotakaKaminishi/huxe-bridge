# Amazon MWAA Serverless now supports Amazon EventBridge notifications/

<p>Amazon Managed Workflows for Apache Airflow (MWAA) Serverless now supports workflow and task state change events to <a href="https://aws.amazon.com/eventbridge/">Amazon EventBridge</a>, enabling data engineering and platform teams to build event-driven automation for their Apache Airflow workflows. </p> 
<p>Previously, monitoring workflow execution required custom polling logic or manual observation. With this launch, MWAA Serverless can emit events when workflows transition between states, including started, running, succeeded, or failed, and when individual tasks change state, such as scheduled, succeeded, failed, or up for retry. With this feature, you can further automate your existing workflows - for example, using EventBridge notifications to trigger alerts when a production workflow fails, automatically restart dependent pipelines when an upstream workflow succeeds, or log state transitions to Amazon S3 for compliance and auditing.</p> 
<p><br /> This feature is available in all AWS Regions where <a href="https://aws.amazon.com/managed-workflows-for-apache-airflow/">Amazon MWAA Serverless</a> is available. For the complete list of supported Regions, see <a href="https://docs.aws.amazon.com/mwaa/latest/mwaa-serverless-userguide/what-is-mwaa-serverless.html#mwaa-serverless-regions">Regions</a> in the Amazon MWAA Serverless User Guide. For pricing details, see <a href="https://aws.amazon.com/eventbridge/pricing/">Amazon EventBridge pricing</a>.</p> 
<p><br /> To learn more, see <a href="https://docs.aws.amazon.com/mwaa/latest/mwaa-serverless-userguide/monitoring.html">Monitoring Amazon MWAA Serverless</a> in the Amazon MWAA Serverless User Guide and <a href="https://docs.aws.amazon.com/eventbridge/latest/ref/events-ref-airflow-serverless.html">Amazon MWAA Serverless events</a> in the Amazon EventBridge Events Reference.</p>
