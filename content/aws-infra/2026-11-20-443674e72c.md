# Amazon CloudFront simplifies domain moves and onboarding for SaaS Manager

<p>Amazon CloudFront now lets web development platforms and SaaS providers move a customer's domain to their platform in a single request with no downtime, and serve requests to the domain while the TLS certificate is being configured. The CloudFront multi-tenant distributions allow these platforms to serve many customer domains from one shared configuration. Together, these features help move existing AWS customers to multi-tenant distributions without impacting their traffic.</p> 
<p>Previously, moving a domain that was already in use required disabling the original distribution, using a wildcard workaround, or contacting AWS Support. Now you can bring customer domains onto your multi-tenant setup as part of creating or updating a tenant. With the new OnDomainTakeover option, CloudFront checks domain ownership through DNS records and then moves one or more domains in a single request. This works within an AWS account or across accounts. If you add a domain before its certificate is issued, CloudFront serves it over HTTP until you attach a certificate. That gives you time to validate the domain with AWS Certificate Manager (ACM) or another certificate authority and attach the certificate once it's issued.</p> 
<p>These features are available in all edge locations at no additional cost. To learn more, see <a href="https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/alternate-domain-names-move-options.html">Move domains</a> and <a href="https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/tenant-domains-without-certificate.html">Domains without a certificate</a> in the Amazon CloudFront Developer Guide.</p>
