# Amazon S3 Vectors is now available in AWS GovCloud (US) Regions

<p>Amazon S3 Vectors is now available in AWS GovCloud (US-East) and AWS GovCloud (US-West).</p> 
<p>Amazon S3 Vectors is purpose-built vector storage for AI agents, inference, Retrieval Augmented Generation (RAG), and semantic search at billion-vector scale. S3 Vectors is designed to provide the same elasticity, durability, and availability as Amazon S3, with a dedicated set of APIs that let you store, access, and query vectors without provisioning any infrastructure.</p> 
<p>For a full list of AWS Regions where Amazon S3 Vectors is available, see <a href="https://docs.aws.amazon.com/AmazonS3/latest/userguide/s3-vectors-regions-quotas.html" rel="noopener noreferrer" target="_blank">AWS Regions and endpoints</a>. To learn more, visit the <a href="https://aws.amazon.com/s3/features/vectors/" rel="noopener noreferrer" target="_blank">product page</a>, <a href="https://docs.aws.amazon.com/AmazonS3/latest/userguide/s3-vectors.html" rel="noopener noreferrer" target="_blank">documentation</a>, and the <a href="https://aws.amazon.com/s3/pricing/" rel="noopener noreferrer" target="_blank">Amazon S3 pricing page</a>.<br /> </p>
