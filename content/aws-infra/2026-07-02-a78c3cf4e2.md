# Amazon RDS announces Cross-Region Automated Backups in four additional AWS Regions

<p>Cross-Region Automated Backup replication for Amazon RDS is now available in four additional AWS Regions. This launch allows you to setup automated backup replication between Mexico (Central) and Europe (Ireland) or US West (N. California); between Asia Pacific (Taipei) and Asia Pacific (Singapore) or Asia Pacific (Tokyo); between Asia Pacific (New Zealand) and Asia Pacific (Singapore), Asia Pacific (Sydney), or Asia Pacific (Melbourne); and between Asia Pacific (Thailand) and Asia Pacific (Singapore) or Asia Pacific (Jakarta) Regions.</p> 
<p>Automated Backups enable recovery capability for mission-critical databases by providing you the ability to restore your database to a specific point in time within your backup retention period. With Cross-Region Automated Backup replication, RDS will replicate snapshots and transaction logs to the chosen destination AWS Region. In the event that your primary AWS Region becomes unavailable, you can restore the automated backup to a point in time in the secondary AWS Region and quickly resume operations. As transaction logs are uploaded to the target AWS Region frequently, you can achieve a Recovery Point Objective (RPO) of within the last few minutes.</p> 
<p>You can setup Cross-Region Automated Backup replication with just a few clicks on the <a href="https://console.aws.amazon.com/rds/home" rel="noopener noreferrer" target="_blank">Amazon RDS Management Console</a> or using the <a href="https://aws.amazon.com/tools/" rel="noopener noreferrer" target="_blank">AWS SDK</a> or <a href="https://docs.aws.amazon.com/cli/latest/reference/rds/" rel="noopener noreferrer" target="_blank">CLI</a>. Cross-Region Automated Backup replication is available on Amazon RDS for PostgreSQL, Amazon RDS for MariaDB, Amazon RDS for MySQL, Amazon RDS for Db2, Amazon RDS for Oracle, and Amazon RDS for Microsoft SQL Server. For more information, including instructions on getting started, read the <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/USER_ReplicateBackups.html" rel="noopener noreferrer" target="_blank">Amazon RDS documentation</a>.</p>
