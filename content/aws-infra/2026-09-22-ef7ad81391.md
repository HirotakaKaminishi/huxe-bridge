# AWS Security Hub AI Inventory adds Azure self-hosted instance support

<p>AWS Security Hub AI Inventory now supports discovering and cataloging AI assets running on self-hosted instances in Microsoft Azure. This expansion extends Security Hub's existing self-hosted discovery capabilities beyond AWS, enabling central security teams to gain a continuously updated, organization-wide view of AI assets and their security posture across multi-cloud environments.</p>
<p>Security Hub leverages the software bill of materials (SBOM) analysis from Amazon Inspector, which has been enhanced to identify inference endpoints, models, and AI agents installed on Azure virtual machines, including frameworks such as Ollama, vLLM, Hugging Face TGI, and others. Each discovered AI asset is mapped to its underlying infrastructure and correlated with security findings, enabling teams to filter, group, and query their AI inventory across both AWS and Azure environments.</p>
<p>This capability is included with Security Hub Essentials at no additional cost. It is available in all AWS commercial Regions where Security Hub is offered. To learn more, see the <a href="https://docs.aws.amazon.com/securityhub/latest/userguide/securityhub-v2-ai-inventory.html">AWS Security Hub User Guide</a> and the <a href="https://aws.amazon.com/security-hub/">AWS Security Hub product page</a>.</p>
