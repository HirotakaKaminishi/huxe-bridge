# AWS Batch on Amazon EKS adds Linux capabilities, seccomp, and pod-level settings

<p>AWS Batch now supports additional Kubernetes security context settings in Amazon EKS job definitions, including Linux capabilities, seccomp profiles, and pod-level settings. For EKS clusters that enforce the Kubernetes Pod Security Standards restricted profile, you can now run AWS Batch jobs with only the privileges and system calls they require.</p> 
<p>To get started, use the <i>RegisterJobDefinition</i> API to set <i>capabilities</i> and <i>seccompProfile</i> in a container's <i>securityContext</i>, or set <i>securityContext</i> in <i>podProperties</i> to define pod-wide settings such as <i>fsGroup</i>. Container-level settings override pod-level defaults. You can configure these settings through the AWS Management Console, AWS CLI, AWS SDKs, or AWS CloudFormation.</p> 
<p>The additional security context settings for AWS Batch on Amazon EKS are now supported in all <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/" rel="noopener noreferrer" target="_blank">AWS Regions</a> where AWS Batch is available. For more information, see the Amazon EKS properties section in the <a href="https://docs.aws.amazon.com/batch/latest/userguide/job_definition_parameters.html#job-definition-parameters-eks-properties" rel="noopener noreferrer" target="_blank">AWS Batch User Guide</a>.</p>
