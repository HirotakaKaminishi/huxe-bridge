# Grok 4.7 is now available on Amazon Bedrock in AWS GovCloud (US)

<p>Amazon Bedrock now supports SpaceXAI Grok 4.7, a frontier model built for coding, agentic tasks, and knowledge work in AWS GovCloud (US).</p>
<p>Grok 4.7 builds on Grok 4.6 with better mixed-document handling, more dependable repo-scale coding with planning and error recovery, and enhanced browser-use agents for form fills and portal navigation.  </p>
<p>Get started with Grok 4.7 in the<a href="https://console.amazonaws-us-gov.com/bedrock/"> Amazon Bedrock console</a> or programmatically through supported Amazon Bedrock APIs. For information about supported<a href="https://docs.aws.amazon.com/bedrock/latest/userguide/models-region-compatibility.html"> AWS Regions</a>, endpoints, APIs, features, inference profiles and pricing, see the <a href="https://docs.aws.amazon.com/bedrock/latest/userguide/model-card-xai-grok-4-7.html">Amazon Bedrock documentation</a>. To learn more, read the launch <a href="https://aws.amazon.com/blogs/machine-learning/grok-4-7-is-now-available-on-amazon-bedrock/">blog post</a>.</p>
