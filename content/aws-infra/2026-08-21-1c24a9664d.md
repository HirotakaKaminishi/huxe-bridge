# Amazon SES now supports open and click tracking override parameters

<p>Amazon Simple Email Service (SES) now supports open and click tracking override parameters in the SendEmail and SendBulkEmail APIs. Senders can enable or disable open tracking and click tracking on an individual API call, rather than managing tracking preferences through separate configuration sets.<br /> <br /> Previously, controlling tracking behavior required maintaining a distinct configuration set for each combination of open- and click-tracking settings. With this new capability, you specify the tracking preference directly in the send request, reducing configuration overhead and simplifying how you honor recipient-level tracking consent. This is useful for senders that must respect per-recipient consent choices to meet data protection requirements such as GDPR and CNIL guidance.<br /> <br /> The tracking overrides apply per request and take precedence over the tracking behavior defined in the associated configuration set, giving you fine-grained control without changing your existing configuration set structure. There is no additional cost to use this feature.<br /> <br /> This capability is available in all AWS Regions where Amazon SES is available.</p> 
<p>To learn more, see the documentation on open and click tracking in the <a href="https://docs.aws.amazon.com/ses/latest/APIReference-V2/API_SendEmail.html"><i>Amazon SES Developer Guide</i>. </a></p>
