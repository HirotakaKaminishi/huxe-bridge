# Amazon Aurora MySQL 8.4  is now generally available

<p>Amazon Aurora MySQL-Compatible Edition now supports MySQL 8.4, a community MySQL Long Term Support (LTS) major version. Aurora MySQL 8.4 launches with compatibility for community MySQL 8.4.7 and introduces aligned version numbering, so the version number you run on Aurora matches the community MySQL version it is compatible with. Aurora also manages the underlying patch on your behalf, simplifying day-to-day operations. Aurora MySQL now targets major versions within 12 months of community MySQL LTS releases, minor versions within 3 months of each community minor, and an Aurora LTS minor within 12 months of each major. For engine specific release objectives, see the <a href="https://aws.amazon.com/blogs/database/knowing-when-new-open-source-database-engine-versions-release-on-amazon-aurora-and-amazon-rds/" rel="noopener noreferrer" target="_blank">Aurora and RDS open source release calendar announcement</a>.<br /> <br /> Aurora MySQL 8.4 strengthens security defaults for new clusters. TLS is enforced by default with only TLS 1.2 and 1.3 supported, new accounts use the caching_sha2_password authentication plugin, and password validation policies are customizable through DB cluster parameter groups. Automated upgrade prechecks identify compatibility issues before your cluster goes offline, giving you confidence before you upgrade. To learn more about the Aurora MySQL 8.4 customer experience, refer to the <a href="https://aws.amazon.com/blogs/database/amazon-aurora-mysql-8-4-is-now-generally-available/" rel="noopener noreferrer" target="_blank">Aurora MySQL 8.4 launch announcement blog.</a><br /> <br /> You can upgrade your database using <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/blue-green-deployments.html" rel="noopener noreferrer" target="_blank">Amazon RDS Blue/Green Deployments</a>, in-place upgrade, or restore from a snapshot. Learn more about performing major version upgrades in the <a href="https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/AuroraMySQL.Updates.MajorVersionUpgrade.html" rel="noopener noreferrer" target="_blank">Amazon Aurora User Guide</a>. You can also migrate to Aurora MySQL 8.4 from external MySQL sources using <a href="https://aws.amazon.com/dms/" rel="noopener noreferrer" target="_blank">AWS Database Migration Service</a> or <a href="https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/AuroraMySQL.Migrating.ExtMySQL.S3.html" rel="noopener noreferrer" target="_blank">Percona XtraBackup</a>. Aurora MySQL 8.4 is available in <a href="https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/Concepts.RegionsAndAvailabilityZones.html#Aurora.Overview.Availability.MySQL" rel="noopener noreferrer" target="_blank">all AWS Regions</a> where Aurora MySQL is available.<br /> <br /> Amazon Aurora MySQL is designed for unparalleled high performance and availability at global scale with full MySQL compatibility. It provides scale-to-zero serverless compute, Aurora Global Database for Multi-Region resilience, Aurora I/O-Optimized for improved price performance on I/O-intensive workloads, and built-in security and continuous backups. To get started with Amazon Aurora, take a look at our <a href="https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/Aurora.AuroraMySQL.html" rel="noopener noreferrer" target="_blank">getting started page</a>.</p>
