# AWS IAM Identity Center now supports separate quotas for AWS accounts and applications

<p>AWS IAM Identity Center now supports separate quotas for the number of AWS accounts and applications that can be configured in an IAM Identity Center instance. By default, you can configure up to 7,000 AWS accounts and up to 7,000 applications independently, so that using more of one does not consume capacity from the other. Quotas can be further increased by submitting a quota increase request through AWS Service Quotas console.</p> 
<p>Customers with existing higher limits are automatically granted the same limit for both accounts and applications, with no action required. Organizations managing thousands of AWS accounts can now onboard applications without consuming account quota capacity.</p> 
<p>This update is available in all AWS Regions where IAM Identity Center is available.</p> 
<p>To learn more, see <a href="https://docs.aws.amazon.com/singlesignon/latest/userguide/limits.html" rel="noopener noreferrer" target="_blank">Quotas for IAM Identity Center</a>. Visit the <a href="https://aws.amazon.com/iam/identity-center/" rel="noopener noreferrer" target="_blank">IAM Identity Center product page</a> to get started.</p>
