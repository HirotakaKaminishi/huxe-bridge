# Amazon EVS VCF 9.0 and 9.1 support

<p>Today, we are announcing that Amazon Elastic VMware Service (EVS) now supports VMware Cloud Foundation (VCF) 9.0 and 9.1.</p> 
<p>Amazon EVS lets you run the latest VCF software directly within your Amazon Virtual Private Cloud (VPC) on EC2 bare-metal instances. With this latest announcement, you now have complete control of the installation, operations, and management of the VMware virtualization solution running the VCF 9.0 and recently released VCF 9.1 versions. You can continue to use the same tools, processes, and skills on Amazon EVS that you use in your data center today, managing your VCF environment yourself or with an experienced AWS partner. With this, we’re also launching the <a href="https://github.com/aws/solutions-for-amazon-evs">Solutions for EVS GitHub repository</a> with examples, templates, and infrastructure as code artifacts to help you get started.</p> 
<p>This release is available in all regions where Amazon EVS is offered.</p> 
<p>For more details, visit the <a href="https://aws.amazon.com/blogs/migration-and-modernization/vmware-cloud-foundation-vcf-9-0-and-9-1-on-amazon-evs/">launch blog</a>, the Amazon EVS <a href="https://aws.amazon.com/evs/">product detail page</a> and <a href="https://docs.aws.amazon.com/evs/latest/userguide/what-is-evs.html">user guide.</a> </p>
