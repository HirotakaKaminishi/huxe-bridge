# Amazon CloudWatch announces basic OpenTelemetry enrichment at no additional cost

<p>Amazon CloudWatch now offers basic OpenTelemetry enrichment for AWS service metrics at no additional cost. Basic enrichment turns the metrics that AWS services publish to CloudWatch into OpenTelemetry data points you can query with PromQL. It covers metrics that identify a resource, such as Amazon EC2 CPUUtilization with an InstanceId dimension. Enriched metrics get resource attributes for the Amazon Resource Name, cloud provider, Region, and account ID, plus an instrumentation scope naming the source service. Your original CloudWatch dimensions become data point attributes.</p> 
<p>To query AWS resource tags as PromQL labels, choose resource tag enrichment instead. It is charged as OTel Vended Metric Enrichment, and you can switch levels at any time. Your AWS service metrics stay available through existing CloudWatch APIs.</p> 
<p>When you set up CloudWatch Omni, basic enrichment is enabled by default, so you can query your AWS service metrics with PromQL right away. Any account can also enable it directly in the CloudWatch console, AWS Command Line Interface, or the AWS SDKs. Basic enrichment is available in all AWS Regions where CloudWatch OpenTelemetry metrics are supported. To learn more, see <a href="https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/CloudWatch-OTelEnrichment.html" title="AWS vended metrics in OpenTelemetry format with PromQL querying">AWS vended metrics in OpenTelemetry format</a>. For pricing, see <a href="https://aws.amazon.com/cloudwatch/pricing/" title="CloudWatch pricing">Amazon CloudWatch pricin</a>g.</p>
