# OpenAI GPT-5.4 generally available on Amazon Bedrock in AWS GovCloud (US-West)

<p>Amazon Bedrock now supports GPT‑5.4 from OpenAI in AWS GovCloud (US-West) — giving government and regulated industry customers access to OpenAI's most capable frontier model for professional work, backed by the enterprise-grade security and goverment compliance scope of AWS GovCloud (US). </p> 
<p>GPT‑5.4 supports native computer-use capabilities, and deep reasoning across coding, documents, and multi-step agentic tasks — all running on Bedrock's high-performance inference engine with isolated queues and durable state for fault-tolerant workloads. Your data stays in-partition and is never used to train models.</p> 
<p>For Regional availability of  GPT-5.4 see the <a href="https://docs.aws.amazon.com/bedrock/latest/userguide/models-region-compatibility.html">AWS Regions page</a>. Read <a href="https://aws.amazon.com/blogs/machine-learning/openai-models-and-codex-on-amazon-bedrock-are-now-generally-available">the launch blog</a> to learn more, for documentation and a step-by-step walkthrough, see the <a href="https://docs.aws.amazon.com/bedrock/latest/userguide/model-cards-openai.html">Amazon Bedrock docs</a> and the<a href="https://aws.amazon.com/blogs/aws/get-started-with-openai-gpt-5-5-gpt-5-4-models-and-codex-on-amazon-bedrock"> getting started blog</a>.</p>
