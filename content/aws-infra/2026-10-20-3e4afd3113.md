# AWS Clean Rooms now supports Databricks as a data source

<p>AWS Clean Rooms now supports <a href="https://docs.aws.amazon.com/clean-rooms/latest/userguide/prepare-data-databricks.html" target="_blank">Databricks as a data source</a>, so collaboration members and their partners can securely analyze data managed in Databricks without moving or revealing the source data. Members query a Databricks table shared through Delta Sharing directly in a collaboration. Databricks joins AWS Glue, Snowflake, and Amazon Athena as supported data sources in AWS Clean Rooms.</p>
<p>Previously, members with data in Databricks had to export or replicate it into Amazon S3 to use it as a table in a collaboration, which added pipeline work and an extra copy of the data to govern. Now members can register a Databricks table directly by providing the workspace URL, schema, and table along with a Delta Sharing share, and make it available to a collaboration. For example, a retailer that manages its customer data in Databricks can collaborate with a media partner on campaign measurement in AWS Clean Rooms, running approved analyses against its Databricks data without first building and maintaining an export to S3.</p>
<p>AWS Clean Rooms helps companies and their partners easily analyze and collaborate on their collective datasets without revealing or copying one another’s underlying data. For more information about the AWS Regions where AWS Clean Rooms is available, see the <a href="https://docs.aws.amazon.com/general/latest/gr/clean-rooms.html#clean-rooms_region" target="_blank">AWS Regions</a> table. To learn more about collaborating with AWS Clean Rooms, visit <a href="https://aws.amazon.com/clean-rooms/" target="_blank">AWS Clean Rooms</a>.</p>
