# AWS Transform for full-stack Windows modernization now supports Aurora PostgreSQL cross-region deployment in 7 more Regions

<p>Today, AWS Transform for full-stack Windows modernization adds support for cross-region deployment of converted Amazon Aurora PostgreSQL databases and is available in seven additional AWS Regions. Together these changes give customers more control over where their modernized databases are deployed after SQL Server modernization, supporting data residency, latency, and disaster recovery requirements.</p>
<p>Customers can upload SQL Server Database Design Language (DDL) files and set a target AWS Region in the transformation plan to convert the database and deploy the resulting Aurora PostgreSQL cluster to a different AWS Region. The same workflow makes dependent .NET applications PostgreSQL compatible, updating connection strings and <a href="http://ADO.NET" rel="noopener noreferrer" target="_blank">ADO.NET</a> and Entity Framework data-access calls.</p>
<p>With this expansion, AWS Transform for full-stack Windows modernization is now available in the following Regions:</p>
<p>US East (N. Virginia), Europe (Frankfurt), Europe (London), Asia Pacific (Mumbai), Asia Pacific (Seoul), Asia Pacific (Tokyo), Asia Pacific (Sydney), and Canada (Montreal).</p>
<p>To get started, you can go to <a href="https://aws.amazon.com/transform/windows/" rel="noopener noreferrer" target="_blank"><u>AWS Transform product page</u></a> or see <a href="https://docs.aws.amazon.com/transform/latest/userguide/windows-full-stack.html" rel="noopener noreferrer" target="_blank"><u>AWS Transform for full-stack Windows documentation</u></a>.</p>
