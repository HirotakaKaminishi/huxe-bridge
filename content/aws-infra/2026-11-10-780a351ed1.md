# AWS Glue adds 100 new native connectors for popular SaaS applications

<p>AWS Glue now supports 100 new native connectors that simplify access to data in popular SaaS and REST API-based applications. Previously, bringing data from SaaS applications into AWS required writing custom code. Now, teams can create a connection once in the AWS Glue Data Catalog and reuse it across ETL jobs with the same permissions model they already use for AWS Glue.</p> 
<p>The new connectors span generative AI, finance, payments, marketing, product analytics, human resources, engineering, IT operations, and collaboration tools. AI teams can bring usage and cost data from model providers such as Anthropic to track generative AI adoption and spend. Finance teams can consolidate transactions from applications such as Adyen, Square, and Xero for faster reporting. Product and marketing teams can combine billing, usage, and campaign data from tools such as Chargebee, Amplitude, and Klaviyo to understand customer lifetime value. HR teams can unify workforce data from systems such as BambooHR and Gusto for headcount planning. Engineering teams can join incident and deployment data from tools such as PagerDuty, Sentry, Jenkins, and Vercel to track reliability. You can load the integrated data into Amazon S3 or Amazon Redshift for analytics and reporting.</p> 
<p>The 100 new AWS Glue connectors are available in all AWS Commercial Regions on Glue versions 5.0 and above.</p> 
<p>To learn more, see the <a href="https://docs.aws.amazon.com/glue/latest/dg/available-connections.html">complete list of available connectors</a> and learn about <a href="https://docs.aws.amazon.com/glue/latest/dg/console-connections.html">connecting to individual connectors</a> in the AWS Glue documentation.</p>
