# Managed Prometheus collectors now support Amazon MSK consumer-group metrics

<p>Managed Prometheus collectors now support Amazon MSK consumer-group metrics for <a href="https://aws.amazon.com/prometheus/">Amazon Managed Service for Prometheus</a> and <a href="https://aws.amazon.com/cloudwatch/">Amazon CloudWatch</a>. The integration collects Kafka exporter metrics and consumer-group lag metrics from your Amazon MSK clusters.</p>
<p>Managed Prometheus collectors discover and collect Prometheus metrics from your workloads, so you don't run and operate collection agents yourself. You ingest the collected metrics into an Amazon Managed Service for Prometheus workspace or into Amazon CloudWatch, where you query and analyze them. You monitor Kafka stream health and consumer performance with consumer-group metrics. This helps you detect processing bottlenecks in your streaming applications.</p>
<p>This feature is available in all <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">AWS Regions</a> where managed Prometheus collectors are generally available. To learn more, see the documentation for <a href="https://docs.aws.amazon.com/prometheus/latest/userguide/prom-msk-kafka-exporter.html">Amazon Managed Service for Prometheus</a> and <a href="https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/managed-prometheus-collectors-msk-kafka-exporter.html">Amazon CloudWatch</a>.</p>
