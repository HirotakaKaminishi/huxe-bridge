# Amazon OpenSearch Memory is now generally available

<p>Today, AWS announced the general availability of Amazon OpenSearch Memory, a new serverless capability in Amazon OpenSearch Service for adding persistent memory to AI agents. OpenSearch Memory stores agent interactions as searchable events, derives useful memories, and retrieves relevant context across sessions, so agents can recall prior decisions, earlier interactions, and user preferences without replaying the full conversation history to the model. Customers can give agents long-term memory without provisioning infrastructure or building separate extraction, indexing, consolidation, and retrieval systems.</p> 
<p>OpenSearch Memory stores the original events verbatim, makes them searchable within seconds, and asynchronously derives structured memories. It manages the full memory lifecycle, including extraction, embedding, indexing, consolidation (adding, updating, or skipping memories as new information arrives), and retrieval using keyword, semantic, and hybrid search. Customers control access with AWS Identity and Access Management (IAM) for each memory store, with actor and session scoping, and can set expiration periods for events and memories. Because it is serverless, there are no clusters to provision, instance types to choose, or indexes to create, and capacity for extraction and search scales automatically.</p> 
<p>Amazon OpenSearch Memory is available today in US East (N. Virginia, Ohio), US West (Oregon), Europe (Frankfurt), and Asia Pacific (Tokyo) Regions. For pricing details about Amazon OpenSearch Memory, visit the <a href="https://aws.amazon.com/opensearch-service/pricing/">pricing page</a>.</p> 
<p>To learn more about Amazon OpenSearch Memory, see the <a href="https://docs.aws.amazon.com/opensearch-service/latest/developerguide/memory.html">technical documentation</a> and <a href="https://aws.amazon.com/blogs/big-data/introducing-amazon-opensearch-memory-persistent-memory-for-ai-agents/">launch blog</a>. You can get started by visiting the technical launch blog that details how to add persistent memory to your agents with Amazon OpenSearch Memory. </p>
