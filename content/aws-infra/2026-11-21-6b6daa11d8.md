# AWS Quick now supports group assignments for custom permissions and limit profiles

<p>AWS Quick now supports assignments for custom permissions and limit profiles to groups from your enterprise identity provider (IdP). Administrators can now apply feature restrictions and per-user resource limits to IdP groups, in addition to the existing user, role, and account assignments. Organizations can align governance with their enterprise identity structure without maintaining assignments for individual users.<br /> <br /> Administrators manage user, account or group assignments in the Quick administration console or through new policy assignment APIs. For example, an organization can assign its finance group a custom permissions profile that blocks members from creating agents, or apply Deny by Default so that, within selected feature categories, the group can use only capabilities an administrator explicitly allows. Administrators can also assign a limit profile to a group to set each member’s index capacity and agent hours. Quick enforces these limits automatically as users consume resources.<br /> <br /> When group-level assignments apply to a user who belongs to multiple groups, Quick resolves overlapping assignments as follows: for custom permissions, a capability denied by any group stays denied, and for limit profiles, the user receives the highest value for each limit type across those groups.<br /> <br /> Group assignments are available in Quick for Professional and Enterprise plans. For feature availability by AWS Region, see AWS <a href="https://docs.aws.amazon.com/quick/latest/userguide/regions.html#regions-qs" rel="noopener noreferrer" target="_blank">Quick Regions</a>. To learn more, see the <a href="https://docs.aws.amazon.com/quick/latest/userguide/custom-permissions.html" rel="noopener noreferrer" target="_blank">custom permissions</a> and <a href="https://docs.aws.amazon.com/quick/latest/userguide/limit-profiles.html" rel="noopener noreferrer" target="_blank">limit profiles</a> documentation.</p>
