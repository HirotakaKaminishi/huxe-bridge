# AWS Quick introduces enterprise guardrails (preview)

<p>AWS Quick now includes enterprise guardrails, giving administrators configurable content safety and sensitive-information controls for user prompts. Administrators can apply guardrail policies to individual users or enterprise identity provider (IdP) groups or set a policy as the account default. User-level policies take precedence over group policies and account defaults. When multiple group policies apply, Quick combines their content restrictions, using the stricter setting when controls overlap.<br /> <br /> Administrators create guardrail policies in the Quick administration console using content filters, denied topics, blocked words and phrases, prompt-attack detection, and controls for selected types of personally identifiable information (PII). For example, an administrator can create a policy that blocks prompts containing confidential project names and assign it to an IdP group.<br /> <br /> Detect-only mode lets administrators test prompt-filtering rules against real production traffic before enforcing them. In this mode, Quick evaluates user prompts and logs policy matches without blocking requests, so administrators can assess the impact on business workflows and refine policies. When administrators enable enforcement, Quick blocks matching prompts and displays a message to the user. Administrators can review detected and blocked events in Amazon CloudWatch Logs.<br /> <br /> Enterprise guardrails are available in preview for select Quick customers with Professional and Enterprise plans. For feature availability by AWS Region, see <a href="https://docs.aws.amazon.com/quick/latest/userguide/regions.html#regions-qs" target="_blank">AWS Quick Regions</a>. To learn more, see the <a href="https://docs.aws.amazon.com/quick/latest/userguide/guardrails.html" target="_blank">enterprise guardrails documentation</a>.</p>
