# Amazon ElastiCache Global Datastore now supports tagging and tag-based access control

<p>Amazon ElastiCache now supports resource tagging and tag-based access control (TBAC) for Global Datastore. Previously, ElastiCache supported tagging on all resources except Global Datastore, which prevented customers from applying a single, consistent permission and cost-allocation model across their ElastiCache fleet.</p>
<p>With this launch, you can use AddTagsToResource, RemoveTagsFromResource, and ListTagsForResource on a Global Datastore, and reference those tags as conditions in IAM policies and Service Control Policies (SCPs) to grant permissions based on tag attributes rather than enumerating individual resources. Tag changes on a Global Datastore propagate automatically to every Region it spans, so access-control and cost-allocation policies stay consistent without per-Region operations.</p>
<p>There is no additional cost for this feature, and no change to how you create or manage Global Datastores. This feature is available in all AWS Regions where ElastiCache Global Datastore is available. To learn more, see <a href="https://docs.aws.amazon.com/AmazonElastiCache/latest/dg/Tagging-Resources.html" rel="noopener noreferrer" target="_blank">Tagging your ElastiCache resources</a> and <a href="https://docs.aws.amazon.com/AmazonElastiCache/latest/dg/IAM.ConditionKeys.html" rel="noopener noreferrer" target="_blank">Using condition keys with ElastiCache</a>. </p>
