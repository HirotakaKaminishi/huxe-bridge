# Amazon MWAA now supports fine-grained access control with IAM Identity Center and multi-team environments

<p>Amazon Managed Workflows for Apache Airflow (Amazon MWAA) now supports fine-grained access control, giving administrators precise control over who can access which workflows and resources in an Apache Airflow environment. Fine-grained access control is delivered through two new capabilities: IAM Identity Center integration and multi-team environments.</p>
<p>With IAM Identity Center integration, users sign in to the Apache Airflow UI with their corporate identity provider. Authorization is evaluated per request using IAM policies attached to IAM Identity Center Permission Sets, with condition keys that scope access by resource type (DAGs, connections, variables, pools, and more), action, and specific resource ID.</p>
<p>With multi-team environments, several teams can share a single MWAA environment. Each team gets its own DAG folder in Amazon S3, and users see only shared DAGs plus their own teams' DAGs based on IAM Identity Center group membership. Teams reduce cost through shared infrastructure and simplify management by configuring environment settings once. Multi-team environments are based on the Apache Airflow multi-team feature, which is currently in preview.</p>
<p>These features are available in all <a href="https://docs.aws.amazon.com/mwaa/latest/userguide/get-started.html#regions" target="_blank">AWS Regions</a> where Amazon MWAA is available.</p>
<p>To learn more, visit the <a href="https://docs.aws.amazon.com/mwaa/latest/userguide/identity-center-integration.html" target="_blank">IAM Identity Center integration documentation</a> and the <a href="https://docs.aws.amazon.com/mwaa/latest/userguide/multi-team-environments.html" target="_blank">multi-team environments documentation</a>.</p>
