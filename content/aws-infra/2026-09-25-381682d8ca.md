# Amazon RDS for MySQL announces Extended Support minor versions 5.7.44-rds.20260902 and 8.0.46-rds.20260908

<p><a href="https://aws.amazon.com/rds/mysql/" rel="noopener noreferrer" target="_blank">Amazon Relational Database Service (RDS) for MySQL</a> announces Amazon RDS Extended Support minor versions 5.7.44-rds.20260902 and 8.0.46-rds.20260908.</p>
<p><a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/extended-support.html" rel="noopener noreferrer" target="_blank">Amazon RDS Extended Support</a> provides up to three additional years of fixes for critical Common Vulnerabilities and Exposures (CVE) and bugs beyond a major version's end of standard support date, giving you more time to upgrade to a new major version.
 <br />
 <br />
 You can upgrade your database using <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/blue-green-deployments.html" rel="noopener noreferrer" target="_blank">Amazon RDS Blue/Green Deployments</a>, in-place upgrade, or restore from a snapshot. Learn more about performing version upgrades in the <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/USER_UpgradeDBInstance.MySQL.html" rel="noopener noreferrer" target="_blank">Amazon RDS for MySQL User Guide</a>. You can also migrate to MySQL 8.4 from external MySQL sources using <a href="https://aws.amazon.com/dms/" rel="noopener noreferrer" target="_blank">AWS Database Migration Service</a>. Learn more about pricing details and regional availability at <a href="https://aws.amazon.com/rds/mysql/pricing/" rel="noopener noreferrer" target="_blank">Amazon RDS for MySQL</a>.</p>
<p>Amazon RDS for MySQL makes it simple to set up, operate, and scale MySQL deployments in the cloud. Create or update a fully managed Amazon RDS database in the <a href="https://console.aws.amazon.com/rds/" rel="noopener noreferrer" target="_blank">Amazon RDS Management Console</a> or by using the AWS Command Line Interface (AWS CLI).</p>
