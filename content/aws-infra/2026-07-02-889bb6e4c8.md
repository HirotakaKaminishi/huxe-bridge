# Amazon Bedrock AgentCore increases default runtime quota limits

<p>Amazon Bedrock AgentCore has increased the default runtime quota limits, giving customers greater capacity to scale their agent-based workloads. AgentCore is the platform for developers to build, connect, and optimize AI agents.</p> 
<p>The new default limits support up to 5,000 active concurrent sessions in US East (N. Virginia) and US West (Oregon), and 2,500 in all other supported Regions. All <a href="https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/agentcore-regions.html">AWS Regions where AgentCore</a> is available now support 200 agent interactions per second and 25 new sessions created per second. This means customers can run more AI agents simultaneously while handling high-throughput workloads out of the box.</p> 
<p>To learn more, visit the <a href="https://aws.amazon.com/bedrock/agentcore/">AgentCore product page</a> or see the <a href="https://docs.aws.amazon.com/bedrock-agentcore/">AgentCore Developer Guide</a>. For all quota limits, see the <a href="https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/bedrock-agentcore-limits.html">AgentCore Quotas documentation</a>.</p>
