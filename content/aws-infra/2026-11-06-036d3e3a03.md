# Announcing Web Answer on Amazon Bedrock AgentCore

<p>Today, we are announcing the general availability of Web Answer on Amazon Bedrock AgentCore. Web Answer is a managed tool that returns a synthesized, grounded, cited answer to a natural-language question in a single call, so agent builders can attach it to an agent and get back a finished answer grounded in current web sources, without building and maintaining their own search, retrieve, synthesis, and citation pipeline. </p> 
<p>Web Answer builds on Web Search on Amazon Bedrock AgentCore, which launched in June, extending it from "find the web content" to "return the finished answer," a capability customers have been asking for. With Web Answer, your agent sends a question and receives a synthesized cited answer in one tool call. Web Answer works like an agent; it plans its own searches, runs several in parallel, and decides when it has gathered enough evidence to answer. You stay in control of the boundaries, with domain include, deny lists and publish-date filters that scope where it looks. It attaches as a target on an AgentCore Gateway and is called over MCP, authenticated with IAM, with zero data egress. </p> 
<p>Web Answer is available in the US East (N. Virginia) Region, with per-tool call pricing. </p> 
<p>To learn more about Web Answer on Amazon Bedrock AgentCore, see Web Answer’s documentation <a href="https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/gateway-target-connector-web-answer-tool.html">page</a> and Web Answer’s <a href="http://aws.amazon.com/bedrock/grounding/web-answer/">website</a>. For Region availability, see the AWS Region <a href="https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/agentcore-regions.html">table</a>. </p>
