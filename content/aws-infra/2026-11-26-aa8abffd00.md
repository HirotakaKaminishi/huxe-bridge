# Amazon EC2 M9g instances now available in additional regions

<p>Starting today, Amazon Elastic Compute Cloud (Amazon EC2) M9g instances, powered by AWS Graviton5 processors, are available in US West (N. California), Canada (Central), South America (São Paulo), and Asia Pacific (Seoul) regions. AWS Graviton5 processors are the fifth generation of custom-designed CPUs, delivering the best price performance for memory-intensive workloads running on Amazon EC2.</p> 
<p><a href="https://aws.amazon.com/ec2/instance-types/m9g/">M9g instances</a> deliver up to 25% better performance compared to AWS Graviton4-based M8g instances. They are up to 30% faster for databases. These instances are built on the sixth-generation <a href="https://aws.amazon.com/ec2/nitro/">AWS Nitro System</a> and are the first to feature the <a href="https://aws.amazon.com/blogs/compute/aws-nitro-isolation-engine-formally-verifying-the-hypervisor-in-the-aws-nitro-system/">Nitro Isolation Engine</a>, harnessing formal verification to provide mathematical assurance that customer workloads are isolated from each other and AWS operators, pioneering a new standard for mathematically proven cloud security.</p> 
<p>M9g instances are ideal for workloads such as open-source databases, in-memory caches, big data analytics, and memory-intensive applications.</p> 
<p>M9g instances are available for purchase in these four regions via Savings Plans, On-Demand, Spot instances, Dedicated instances, or Dedicated hosts. <a href="https://aws.amazon.com/ec2/graviton/level-up-with-graviton/">Level up your compute with AWS Graviton</a> and <a href="https://aws.amazon.com/ec2/instance-types/m9g/">get started today.</a></p>
