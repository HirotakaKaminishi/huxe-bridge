# Amazon Bedrock AgentCore now offers a Web Search API

<p>Today, AWS announces the general availability of the Web Search API on Amazon Bedrock AgentCore, which lets you search the web with a single API call. Web Search on AgentCore has been available as an MCP tool through AgentCore Gateway. The new InvokeWebSearch API gives applications, custom agent loops, and data pipelines search results with no resources to create.</p> 
<p>The API returns ranked results from the Amazon-operated web index behind Web Search on AgentCore. Each result includes a text extract and, when available, the page title, URL, and publication time. You can filter each request by domain and publication time, for example to find recent product announcements or check a claim against trusted domains.</p> 
<p>You call the API with the AWS SDKs or the AWS Command Line Interface (AWS CLI) and authorize calls with AWS Identity and Access Management (IAM). You can call it from your virtual private cloud (VPC) through AWS PrivateLink and log requests as AWS CloudTrail data events. Web Search API queries are billed at $7 per 1,000 queries, the same rate as Web Search through AgentCore Gateway, with no gateway charges.</p> 
<p>The Web Search API is available in US East (N. Virginia), US East (Ohio), US West (Oregon), Asia Pacific (Sydney), Asia Pacific (Tokyo), and Europe (Ireland). To learn more, see <a href="https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/web-search-api.html">Search the web with the InvokeWebSearch API</a> in the AgentCore Developer Guide, the <a href="https://aws.amazon.com/bedrock/grounding/web-search/">Web Search </a> page, and <a href="https://aws.amazon.com/bedrock/agentcore/pricing/">AgentCore pricing </a>.</p>
