# AWS Transform for migrations is now available in Asia Pacific (Singapore)

<p>AWS Transform for migrations is now available in the Asia Pacific (Singapore) Region, giving customers data residency within the region and lower latency to local source infrastructure as they migrate. <a href="https://aws.amazon.com/transform/">AWS Transform</a> is a collaborative enterprise IT transformation service powered by agentic AI that accelerates cloud migration, application modernization, and continuous tech debt reduction.
 <br />
 <br />
 With AWS Transform for migrations, enterprise IT teams can automate the entire migration lifecycle, from discovery and wave planning through network conversion and launching test and cutover instances, using purpose-built AI agents. The service supports infrastructure migration for workloads from virtually any source, including VMware, Hyper-V, KVM, bare metal, and hybrid environments, unifying teams, tools, and workflows in a single collaborative workbench.
 <br />
 <br />
 To get started, see the AWS Transform <a href="https://docs.aws.amazon.com/transform/latest/userguide/">documentation</a> or visit the AWS Transform <a href="https://aws.amazon.com/transform/">product page</a>.</p>
