# SageMaker Notebook Instances now support G6e instance types

<p>We are pleased to announce general availability of Amazon EC2 G6e instances on SageMaker notebook instances.</p> 
<p><a href="https://aws.amazon.com/ec2/instance-types/g6e/"><u>Amazon EC2 G6e instances</u></a> are powered by up to 8 NVIDIA L40s Tensor Core GPUs with 48 GB of memory per GPU and third generation AMD EPYC processors. G6e instances deliver up to 2.5x better performance compared to EC2 G5 instances. Customers can use G6e instances to interactively test model deployment and for interactive model training use cases such as generative AI fine-tuning. You can use G6e instances to deploy large language models (LLMs) with up to 13B parameters and diffusion models for generating images, video, and audio.</p> 
<p>Amazon EC2 G6e instances are available on SageMaker notebook instances in the AWS US East (N. Virginia and Ohio), US West (Oregon), Asia Pacific (Tokyo), Middle East (Dubai) and Europe (Frankfurt, Sweden, Spain) regions.</p> 
<p>Visit developer guides for instructions on setting up and using <a href="https://docs.aws.amazon.com/sagemaker/latest/dg/studio-updated-jl.html"><u>JupyterLab</u></a> and <a href="https://docs.aws.amazon.com/sagemaker/latest/dg/code-editor.html"><u>CodeEditor</u></a> applications on <a href="https://docs.aws.amazon.com/sagemaker/latest/dg/studio-updated.html"><u>SageMaker Studio</u></a> and <a href="https://docs.aws.amazon.com/sagemaker/latest/dg/nbi.html"><u>SageMaker notebook instances</u></a>.</p>
