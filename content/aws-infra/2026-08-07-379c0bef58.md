# AWS Lambda console extends console-to-IDE integration to Kiro and Cursor

<p>AWS Lambda console now extends its console-to-IDE integration to support Kiro and Cursor IDEs. This expansion builds on the existing console-to-IDE transition for Visual Studio Code (VS Code), providing a seamless transition between cloud and local development environments for serverless developers using these popular IDEs.</p> 
<p>With the expanded console-to-IDE integration, developers can start from the Lambda console and follow a guided setup to begin local development in Kiro or Cursor while preserving their existing code and configurations. This capability also enables developers to easily convert their applications to an <a href="https://docs.aws.amazon.com/serverless-application-model/latest/developerguide/what-is-sam.html" rel="noopener noreferrer" target="_blank">AWS Serverless Application Model</a> (AWS SAM) template using Kiro and Cursor, simplifying their <a href="https://aws.amazon.com/what-is/iac/" rel="noopener noreferrer" target="_blank">Infrastructure as Code</a> (IaC) practices and CI/CD pipeline integration.</p> 
<p>This feature is available in all commercial <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/?refid=2abe6167-e3db-40c4-a9fa-b283e7b4d7c8" rel="noopener noreferrer" target="_blank">AWS Regions where Lambda is available,</a> at no additional cost.</p> 
<p>To get started, click the "Open in Kiro" or "Open in Cursor" button in the Lambda console's Code tab or in the Getting Started popup when creating a new function. This will automatically open your function in the selected IDE on your local device. To learn more about this experience, visit the <a href="https://docs.aws.amazon.com/lambda/latest/dg/foundation-iac-local-development.html?refid=2abe6167-e3db-40c4-a9fa-b283e7b4d7c8" rel="noopener noreferrer" target="_blank">Lambda developer guide.</a></p>
