# AWS Console Home now supports the Cost and Usage widget in the AWS European Sovereign Cloud (Germany) Region

<p>AWS Console Home now supports the Cost and Usage widget in the AWS European Sovereign Cloud (Germany) Region, allowing customers to surface insights from Cost Explorer and Cost Optimization Hub on their Console Home dashboard.</p> 
<p>With the Cost and Usage widget, customers can track month-to-date and forecasted costs, identify savings opportunities, and see how their spend breaks down by service over time.</p> 
<p>To get started, sign in to the <a href="https://console.amazonaws-eusc.eu/">AWS Management Console</a>, select Add widgets, and drag the Cost and Usage widget onto your Console Home dashboard. To learn more, see <a href="https://docs.aws.eu/awsconsolehelpdocs/latest/gsg/work-with-widgets.html">Working with widgets in AWS Console Home documentation</a>.</p>
