# Quick now supports smart approvals for agentic actions

<p>Amazon Quick now supports smart approvals, a review layer that reduces unnecessary approval prompts while preserving human oversight of the actions that matter most. As agents take more actions on a user's behalf, such as sending email, updating records, and creating tickets, asking a person to approve every step leads to approval fatigue and weaker oversight over time. With smart approvals, a separate review model called the classifier evaluates each eligible action against the user's request. It approves routine actions automatically and refers consequential actions to the user for review.</p> 
<p>Your existing policies always come first. Smart approvals only reviews actions where the user's setting is "ask" each time. Denied actions stay denied, and smart approvals never grants new access. The classifier sends higher-impact actions to the user for review. These include sending content outside the organization, changing permissions, deleting content, making payments, and actions that go beyond what the user asked for. Each automatic approval covers only the exact action that was reviewed. If a review fails or times out, the action goes to the user.</p> 
<p>Smart approvals is on for all users by default. Administrators control who can use it with custom permissions, and users can turn it off for their conversations and scheduled runs in chat options. AWS CloudTrail records each action review made through smart approvals and each change to a user's smart approvals setting.</p> 
<p>Smart approvals is available in Amazon Quick in all AWS Regions where Amazon Quick agentic capabilities are supported. For more information, see the <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/" rel="noopener noreferrer" target="_blank">AWS Region table</a>.</p> 
<p>To learn more about smart approvals, see <a href="https://docs.aws.amazon.com/quick/latest/userguide/smart-approvals.html" rel="noopener noreferrer" target="_blank">smart approvals</a> in the Amazon Quick User Guide. For more information about Amazon Quick, see the <a href="https://aws.amazon.com/quick/" rel="noopener noreferrer" target="_blank">Amazon Quick product page</a>.</p>
