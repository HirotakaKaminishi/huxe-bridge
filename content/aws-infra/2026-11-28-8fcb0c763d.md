# Amazon Neptune introduces Neptune Graph Sessions, smaller graphs designed for agents that scale to zero and resume automatically

<p><a href="https://aws.amazon.com/neptune/">Amazon Neptune</a> now supports Neptune Graph Sessions, a compute mode designed for agents that scales memory and CPU automatically and scales to zero when idle. You can give each agent, user or task its own graph without paying for the 16 m-NCU minimum of a provisioned graph. You choose a starting size of 4 s-NCU (sessions Neptune capacity units) or 8 s-NCU of working memory when you create a graph.</p> 
<p>Applications such as GraphRAG assistants, AI agents and per-user analytics improve accuracy when using a graph. These use cases often need a separate graph for each conversation or task, and the size of that graph is hard to predict. Each Graph Sessions graph starts at the size you choose and includes memory headroom up to twice that size for the data you load and the queries you run (a 4 s-NCU graph has up to 8 s-NCU of memory, and an 8 s-NCU graph has up to 16 s-NCU), so the starting size does not have to cover your largest graph. You are billed for the memory your graph uses, so a graph that fits in the smaller size is billed at the smaller size.</p> 
<p>When a graph is idle, Graph Sessions scales to zero automatically after 15 minutes, and the graph resumes in seconds when the next query arrives. Your graph and its data are kept, so you do not reload data for each session and pay for the running price.</p> 
<p>You can create a Neptune Graph Sessions graph using the AWS Management Console, AWS CLI, or AWS SDKs, and query it with openCypher like any other Neptune Analytics graph. For more information, see the <a href="https://docs.aws.amazon.com/neptune-analytics/latest/userguide/gettingStarted.html">Neptune Analytics User Guide</a> and the <a href="https://aws.amazon.com/neptune/pricing/">Amazon Neptune pricing page</a>.</p>
