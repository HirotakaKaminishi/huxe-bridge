# Amazon CloudWatch extends the PromQL query window to 30 days

<p>Amazon CloudWatch now supports a 30-day query window for PromQL queries against OpenTelemetry metrics, up from 7 days. You can query a month of data in a single request, chart month-over-month and week-over-week trends on one dashboard, and alarm on a 30-day baseline.</p> 
<p>Teams typically define service level objectives (SLOs) over a 30-day rolling window, longer than a 7-day query can measure. You can now calculate availability and remaining error budget for a full SLO period in one query, and alarm when a service is on track to exhaust its budget. A month of history also makes capacity forecasts more reliable, because a 7-day baseline skews to a single busy weekend.</p> 
<p>This feature is available at no additional cost in all AWS Regions where PromQL queries against OpenTelemetry metrics in Amazon CloudWatch are available.</p> 
<p>To get started, see Query OpenTelemetry metrics with PromQL in the Amazon CloudWatch <a href="https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/CloudWatch-PromQL.html" title="CloudWatch PromQL queries">User Guide</a>.</p>
