# AWS Batch now supports customer-ordered instance allocation strategies

<p>AWS Batch now offers the Best Fit Progressive Ordered (BFPO) and Spot Capacity Optimized Prioritized (SCOP) allocation strategies, giving you more control over instance type prioritization in your compute environments. BFPO and SCOP enable you to manually define instance type ordering based on your workload-specific performance characteristics.<br /> <br /> To use these features in AWS Batch, specify BEST_FIT_PROGRESSIVE_ORDERED allocation strategy for your on-demand compute environments or SPOT_CAPACITY_OPTIMIZED_PRIORITIZED for your Amazon EC2 Spot compute environments and provide an ordered list of instance types or families. These features are available via the AWS Batch API (<i>CreateComputeEnvironment </i>or <i>UpdateComputeEnvironment</i>) or the AWS Batch Management Console.<br /> <br /> BFPO and SCOP allocation strategies are supported today in all <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">AWS Regions</a> where AWS Batch is available. For more information, see the <a href="https://docs.aws.amazon.com/batch/latest/userguide/allocation-strategies.html">AWS Batch User Guide</a>.</p>
