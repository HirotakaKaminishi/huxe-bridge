# Amazon RDS for Oracle no longer requires automatic minor version upgrades for JVM, Spatial, Locator, and OLAP options

<p><a href="https://aws.amazon.com/rds/oracle/">Amazon Relational Database Service (Amazon RDS) for Oracle</a> now lets you turn off automatic minor version upgrades on new and existing DB instances that use the JVM, Spatial, Locator, or OLAP option. Previously, these options required automatic minor version upgrades to be enabled.</p> 
<p>With this change, you decide when to apply minor version upgrades to DB instances using these options. If you turn off automatic minor version upgrades, we recommend that you apply new minor versions regularly so your DB instances keep the latest Oracle security fixes. To keep automatic minor version upgrades turned on and still control the order in which your environments are upgraded, you can use <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/RDS.Maintenance.AMVU.UpgradeRollout.html">AWS Organizations upgrade rollout policy</a>.</p> 
<p>This change is available in <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">all commercial AWS Regions and the AWS GovCloud (US) Regions</a> where Amazon RDS for Oracle is available. To learn more about options available in Amazon RDS for Oracle, see <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/Appendix.Oracle.Options.html">Adding options to Oracle DB instances</a> in the Amazon RDS User Guide.</p>
