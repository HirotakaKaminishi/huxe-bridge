# AWS WAF announces automated discovery and protection for LLM, MCP, and A2A endpoints using Amazon Bedrock Guardrails

<p>Automated AI endpoint discovery and protection are now generally available, enabling you to discover language model (LLM), Model Context Protocol (MCP), and Agent2Agent (A2A) endpoints behind Amazon API Gateway, Application Load Balancers, and Amazon CloudFront across your AWS Organization and protect them using AWS WAF.</p> 
<p>Discovery is available through the new API Gateway API Portal, which recognizes the AI endpoints among the APIs it discovers automatically from traffic logs and service configuration records, with no agents to deploy or logs to forward. An undocumented, public-facing MCP server appears as a shadow API. For unprotected AI endpoints, customers can enable protection using WAF.</p> 
<p>Protection is available through the new AWS WAF AI Security managed rule group, which protects your AI endpoints. AWS WAF implements protocol recognition and compliance checks to block malformed MCP and A2A messages. When you enable content inspection, the rule group calls Amazon Bedrock Guardrails InvokeGuardrailsCheck API to detect prompt injection, jailbreak attempts, harmful content in requests, and sensitive information in responses. You can use AI Security alongside other AWS Managed Rules or your own custom rules to protect your applications. Additional fees apply, and Amazon Bedrock charges separately for content inspection calls.</p> 
<p>Together, API Portal and AI Security provide you a complete solution from discovery of all AI endpoints in your AWS environment to protecting them, without having to write any custom rules.</p> 
<p>API Portal is available in 32 AWS Regions. See the <a href="https://aws.amazon.com/api-gateway/faqs/">Amazon API Gateway FAQ</a> for the list. AI Security is available in the following AWS Regions: US East (N. Virginia), US East (Ohio), US West (Oregon), Europe (London), Europe (Stockholm), Asia Pacific (Tokyo), and Asia Pacific (Sydney).</p>
