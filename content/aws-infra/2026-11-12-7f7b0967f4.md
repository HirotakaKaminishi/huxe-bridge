# AWS Quick enhances granular governance with the ability to restrict structured data sources

<p>Today, AWS Quick is announcing the general availability of structured data connector restrictions through custom permissions. This capability gives administrators granular control over which types of data sources users can create, update, or share, helping organizations enforce data governance requirements while enabling self-service analytics.<br /> <br /> With this feature, administrators can configure <a href="https://docs.aws.amazon.com/quick/latest/userguide/custom-permissions.html">custom permissions profiles</a> in Enterprise edition through the Quick UI, APIs, or AWS Command Line Interface. For example, an organization can allow users to create Amazon Redshift data sources while restricting the creation of file-upload data sources. Administrators can also prevent users from sharing data sources for a particular connector. Create, update, and share restrictions can be configured independently, providing more precise controls than restrictions that apply to all data source types.<br /> <br /> This feature is now available in all supported AWS Quick Regions listed <a href="https://docs.aws.amazon.com/quick/latest/userguide/regions.html">here</a>. To learn more, check our documentation <a href="https://docs.aws.amazon.com/quick/latest/userguide/custom-permissions.html">here</a>.</p>
