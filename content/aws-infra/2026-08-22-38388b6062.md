# AWS Glue 6.0 delivers 30% price reduction and Iceberg v3 support

<p>AWS Glue 6.0 is now generally available, delivering a 30% price reduction and introducing full support for Apache Iceberg v3, newer versions of Apache Hudi and Delta Lake, and new capabilities to improve developer productivity. AWS Glue 6.0 also upgrades runtime to Apache Spark 4.1, Python 3.13, and Scala 2.13.</p> 
<p>With Apache Iceberg v3, AWS Glue 6.0 adds the VARIANT data type with automatic shredding for faster reads on semi-structured data, deletion vectors for high-performance row-level updates, geometry and geography data types for spatial processing, and flexible schema evolution through UNKNOWN data type and DEFAULT column values. Glue 6.0 also introduces features that boost developer productivity and performance, such as Spark Declarative Pipelines that eliminate repetitive orchestration code, Real-Time Mode streaming for sub-second latencies, and Arrow-native Python UDFs for improved PySpark performance. These capabilities help you implement large-scale ETL, recurring batch workloads, streaming analytics, and AI application development using AWS Glue.</p> 
<p>AWS Glue 6.0 is available in all AWS Commercial, AWS GovCloud (US), and AWS China regions.</p> 
<p>To get started, select Glue 6.0 from the version dropdown in the AWS Glue console or SageMaker Unified Studio when creating a new job, or migrate existing jobs using the <a href="https://docs.aws.amazon.com/glue/latest/dg/upgrade-analysis.html">Spark Upgrade Agent</a>. To learn more, visit the <a href="https://docs.aws.amazon.com/glue/latest/dg/migrating-version-60.html">AWS Glue documentation</a> and <a href="https://aws.amazon.com/glue/pricing/">AWS Glue pricing</a>.</p>
