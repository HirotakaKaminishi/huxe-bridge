# Amazon RDS Proxy now supports SQL Server 2022

<p><a href="https://aws.amazon.com/rds/proxy/" rel="noopener noreferrer" target="_blank">Amazon RDS Proxy</a>, a fully managed, highly available database proxy for <a href="https://aws.amazon.com/rds/" rel="noopener noreferrer" target="_blank">Amazon Relational Database Service (RDS)</a>, now supports <a href="https://aws.amazon.com/rds/sqlserver/" rel="noopener noreferrer" target="_blank">Amazon RDS for SQL Server</a> instances running major version 2022.
 <br />
 <br />
 Amazon RDS Proxy sits between your application and the database to pool and share established database connections, improving database efficiency and application scalability. For Amazon RDS for SQL Server Multi-AZ databases, RDS Proxy automatically connects to the standby database instance during a failure, preserves application connections, and helps reduce failover times by up to 83%. RDS Proxy supports standard IAM authentication for SQL Server, where your applications authenticate to the proxy using AWS Identity and Access Management (IAM) and RDS Proxy manages database connections using credentials stored in AWS Secrets Manager.
 <br />
 <br />
 You can enable Amazon RDS Proxy for your SQL Server 2022 database in a few steps on the Amazon RDS console, then connect by pointing your application to the RDS Proxy endpoint. To get started, see our <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/rds-proxy.html" rel="noopener noreferrer" target="_blank">documentation</a>.</p>
