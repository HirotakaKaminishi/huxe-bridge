# AWS announces Data Hub in AWS Billing and Cost Management (preview)

<p>Today, AWS announces the preview of Data Hub in AWS Billing and Cost Management, a managed data layer that enables AWS FinOps Agent to query cost and usage data with SQL. In preview, Data Hub is available to AWS FinOps Agent, so the agent can identify the individual resources behind a cost change, break down spend by team or cost allocation tag, and show how a resource's cost and usage change hour by hour. With AWS FinOps Agent and Data Hub, customers get these answers without setting up a data export or building and maintaining a cost data pipeline.</p> 
<p>Data Hub provides 13 months of hourly, resource-level cost and usage data in the published CUR 2.0 schema, including resource identifiers and cost allocation tags. AWS provisions the data, refreshes data daily, and maintains the schema as new services, commitments, and charge types are added. When set up from the management account, Data Hub covers cost and usage data across the accounts in your organization.</p> 
<p>Data Hub (preview) is available in the US East (N. Virginia) Region and covers cost and usage data across regions. There is no charge for Data Hub during preview.</p> 
<p>To learn more about Data Hub, see the <a href="https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/data-hub.html" rel="noopener noreferrer" target="_blank">AWS Billing and Cost Management User Guide</a> and the <a href="https://aws.amazon.com/blogs/aws-cloud-financial-management/ask-aws-finops-agent-resource-level-cost-questions-with-aws-billing-and-cost-management-data-hub-preview" rel="noopener noreferrer" target="_blank">launch blog</a>. You can get started from the <a href="https://us-east-1.console.aws.amazon.com/costmanagement/home?region=us-east-1" rel="noopener noreferrer" target="_blank">Data Hub page</a> in the AWS Billing and Cost Management console or from the <a href="https://aws.amazon.com/finops-agent/" rel="noopener noreferrer" target="_blank">AWS FinOps Agent</a> console.</p>
