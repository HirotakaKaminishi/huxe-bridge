# AWS Transform for mainframe improves the reimagine modernization workflow

<p>AWS Transform for mainframe now discovers business functions with field-level precision and generates a new requirements coverage report in the assess and reimagine workflow. Previously, business functions that used the same table or file were grouped together, and you had to build your own traceability reporting from AWS Transform artifacts. With this launch, you can start modernizing z/OS COBOL and PL/I workloads from a more accurate catalog of business functions and verify requirements coverage before you build.</p>
<p>Business functions are now grouped only when they affect the same data fields. They also include screens and queues and carry clearer names and descriptions. The new requirements coverage report shows how every part of your application is accounted for in the generated requirements. Every line of source code is classified by how it was handled, every business rule links to the exact lines it came from, and every requirement is backed by the business rules that support it. You can review coverage from the full portfolio down to a single line before moving into forward engineering in Kiro and other IDEs.</p>
<p>These capabilities are available in all AWS Regions where AWS Transform for mainframe is available. For more information, see the <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">AWS Region table</a>. To learn more, visit <a href="https://aws.amazon.com/transform/mainframe/">AWS Transform for mainframe</a> or see the <a href="https://docs.aws.amazon.com/transform/">AWS Transform for mainframe documentation</a>.</p>
