# Amazon Redshift streaming can now ingest 10MiB records from Amazon Kinesis Data Streams

<p><a href="https://aws.amazon.com/redshift/">Amazon Redshift </a> now supports Amazon Kinesis Data Streams (KDS) record sizes up to 10 MiB—a 10x increase from the previous 1 MiB limit—fully matching the expanded maximum record size in Amazon KDS. This means you can stream significantly larger payloads directly into Amazon Redshift without splitting records, simplifying your ingestion pipelines and unlocking new use cases for high-volume, large-record workloads.</p> 
<p>Amazon Redshift support for 10MiB record size in Amazon KDS streams is now available in all commercial AWS regions where Amazon Redshift is available. For more information on direct streaming ingestion into Amazon Redshift, see the <a href="https://docs.aws.amazon.com/redshift/latest/dg/materialized-view-streaming-ingestion.html">Amazon Redshift streaming documentation</a>. For more information on 10MiB record support in Amazon KDS, see the <a href="https://docs.aws.amazon.com/streams/latest/dev/large-records.html">Amazon KDS documentation</a>.  </p>
