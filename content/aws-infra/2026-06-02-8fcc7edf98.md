# AWS Cost and Usage Report 2.0 now supports Athena and Redshift integration

<p>AWS today announced that AWS Cost and Usage Report 2.0 (CUR 2.0) provides new integration options with AWS Athena and AWS Redshift. This capability allows customers to analyze the data from their AWS CUR 2.0 in Amazon Simple Storage Service (Amazon S3) using standard SQL without building custom data warehouse solutions, bringing feature parity with CUR 1.0 integration options. <br /> <br /> With this launch, when customers select Athena or Redshift integration, CUR 2.0 exports are automatically delivered in the optimal format (Parquet, GZIP) for the chosen query engine. Each export includes the supporting metadata and automation resources needed to get started quickly, such as infrastructure templates, table definitions, and data loading instructions, so customers can begin querying their cost data without manual configuration. As CUR 2.0 data refreshes periodically, updates are automatically reflected in the Athena or Redshift tables with no additional ETL required.<br /> <br /> This feature is available in all commercial AWS Regions, except the AWS GovCloud (US) Regions and the China Regions.<br /> <br /> To learn more about this feature, see AWS Data Exports and <a href="https://docs.aws.amazon.com/cur/latest/userguide/what-is-data-exports.html">AWS Billing and Cost Management</a> in the <i>AWS Cost Management User Guide</i>.</p>
