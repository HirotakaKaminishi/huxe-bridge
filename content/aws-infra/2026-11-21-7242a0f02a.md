# Build more capable automations through chat with Flows in AWS Quick

<p>Flows in AWS Quick now lets users build, run, and refine automations for themselves and their teams, all through conversation. Users describe a process in chat, and Quick builds the flow, with no coding needed.</p> 
<p>Flows can now orchestrate agents, skills, and tools, with access to structured data, knowledge, and apps. A flow can pull answers from the business data a team already reports on, produce ready-to-share documents, spreadsheets, and presentations, and save the results to a team space. Flows also support longer-running workflows and larger volumes of data.</p> 
<p>New deterministic steps help keep results consistent, and validations check each step's output against rules the user sets, such as requiring a summary table in a report, before the flow continues. For example, an accounts payable team can build a flow that uses agents to read invoices and match them to purchase orders, and deterministic steps to check totals and catch duplicates.</p> 
<p>Users can now run flows wherever they work, across desktop, web, and mobile. In the desktop app, flows can work with local files and complete tasks in the browser. In the mobile app, users can start flows and check on them on the go.</p> 
<p>These updates are available in all AWS Regions where AWS Quick is available.</p> 
<p>To learn more, see <a href="https://docs.aws.amazon.com/quick/latest/userguide/using-amazon-quick-flows.html">Flows in AWS Quick</a> in the <a href="https://docs.aws.amazon.com/quick/latest/userguide/" target="_blank">AWS Quick User Guide</a> and the <a href="https://aws.amazon.com/quick/">AWS Quick</a> product page.</p>
