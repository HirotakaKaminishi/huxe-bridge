# Amazon Redshift integrates with Agent Toolkit for AWS for AI-assisted data warehouse management

<p><a href="https://aws.amazon.com/redshift/">Amazon Redshift</a> now integrates with the <a href="https://aws.amazon.com/products/developer-tools/agent-toolkit-for-aws/">Agent Toolkit for AWS</a>, enabling you to build, query, troubleshoot, and migrate to Amazon Redshift data warehouses and date lakes directly from AI agents such as Claude Code, Kiro, and Cursor. The integration pairs the <a href="https://docs.aws.amazon.com/agent-toolkit/latest/userguide/mcp-server.html">AWS MCP (Model Context Protocol) server</a>, which provides authenticated AWS API execution on your behalf — with <a href="https://github.com/aws/agent-toolkit-for-aws/tree/main/skills/specialized-skills/analytics-skills/redshift-guide">Redshift skills</a>: curated packages of tested procedures and reference material that help AI agents complete Redshift tasks more effectively.</p> 
<p>The <a href="https://github.com/aws/agent-toolkit-for-aws/tree/1799aae50f30a8e97bab4faf38f2eadbd665028b/skills/specialized-skills/analytics-skills/redshift-guide">Redshift skills</a> cover SQL syntax references to reduce query generation errors, metadata discovery to explore schemas and data without writing SQL by hand, data loading patterns, materialized view best practices, function and data type guidance, and extensions such as Qualify, Pivot, and Super. It also guides end-to-end data warehouse migrations to Amazon Redshift, including discovery, schema and SQL conversion, data movement, validation, and performance comparison. We will continue to expand these skills with additional capabilities over time.</p> 
<p>The skills work with provisioned clusters and <a href="https://aws.amazon.com/redshift/redshift-serverless/">Serverless</a> workgroups, require no changes to existing infrastructure, and are available at no additional charge in all AWS Regions where Amazon Redshift and the AWS MCP Server are offered.</p> 
<p>To get started, install the <a href="https://github.com/aws/agent-toolkit-for-aws/tree/1799aae50f30a8e97bab4faf38f2eadbd665028b/plugins/aws-data-analytics">aws-data-analytics plugin</a> in your agent, which bundles the MCP Server configuration and Redshift skills in a single step. Agents with MCP Server access can also discover and load skills at runtime without pre-installation. For setup instructions, see the <a href="https://docs.aws.amazon.com/agent-toolkit/latest/userguide/quick-start.html">Agent Toolkit documentation</a> or the <a href="https://docs.aws.amazon.com/redshift/latest/mgmt/agent-skills.html">Amazon Redshift skills documentation</a>.</p>
