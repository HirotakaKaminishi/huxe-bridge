# Amazon SageMaker HyperPod now supports managed observability and user management extensions for Slurm clusters

<p>Amazon SageMaker HyperPod now supports managed cluster extensions for Slurm clusters. You can install, configure, update, and remove managed features through the SageMaker AI console or API. The first two extensions cover observability and user management. Earlier, every observability or user management change for HyperPod Slurm clusters meant editing lifecycle scripts and then replacing or rerunning nodes. Now, HyperPod manages these features for you, and you keep lifecycle scripts and custom AMIs for your organization's own software.</p> 
<p>For each extension, you declare a configuration. HyperPod validates it and applies it to every node, including nodes you add later. It then reports the extension's status and the health of each node. The observability extension collects node, GPU, Elastic Fabric Adapter (EFA), Slurm job, and Slurm cluster metrics. It sends them to Amazon CloudWatch or Amazon Managed Service for Prometheus, and you can add Amazon Managed Grafana dashboards. The user management extension creates users and groups with the same IDs on every node. It also controls who can sign in with SSH and use sudo on each node type, with local users, Active Directory, or both.</p> 
<p>Cluster extensions are available at no additional charge in all AWS Regions where Amazon SageMaker HyperPod is available. You pay only for the AWS resources you use. To learn more, see <a href="https://docs.aws.amazon.com/sagemaker/latest/dg/sagemaker-hyperpod-slurm-extensions.html" target="_blank">Cluster extensions</a> in the Amazon SageMaker AI Developer Guide, read the <a href="https://aws.amazon.com/blogs/machine-learning/introducing-managed-cluster-extensions-for-observability-and-user-management-in-amazon-sagemaker-hyperpod-slurm/" target="_blank">launch blog</a>, or visit the <a href="https://aws.amazon.com/sagemaker/ai/hyperpod/" target="_blank">Amazon SageMaker HyperPod product page</a>.</p>
