# Amazon SNS now supports sending SMS in the Asia Pacific (Seoul) Region

<p>Customers that use <a href="https://aws.amazon.com/sns/" rel="noopener noreferrer" target="_blank">Amazon Simple Notification Service (Amazon SNS)</a> in the Asia Pacific (Seoul) Region can now send text messages (SMS) to subscribers in more than 200 countries and territories.</p> 
<p>Amazon SNS is a fully managed pub/sub messaging service that enables message delivery to multiple endpoints including AWS Lambda, Amazon SQS, Amazon Data Firehose, mobile devices, and email. With this launch, customers using SNS in the Asia Pacific (Seoul) Region can subscribe phone numbers to SNS topics and broadcast SMS messages via <a href="https://aws.amazon.com/end-user-messaging/" rel="noopener noreferrer" target="_blank">AWS End User Messaging</a>. </p> 
<p>To learn more about sending SMS messages with SNS, visit <a href="https://docs.aws.amazon.com/sns/latest/dg/sns-mobile-phone-number-as-subscriber.html">Mobile text messaging with Amazon SNS</a>. For the list of supported countries and regions, visit <a href="https://docs.aws.amazon.com/sns/latest/dg/sns-supported-regions-countries.html">Supported countries and regions</a>.</p>
