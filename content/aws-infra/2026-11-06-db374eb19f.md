# Amazon Simple Email Service is now available in six new AWS Regions

<p><a href="https://aws.amazon.com/ses/">Amazon Simple Email Service (Amazon SES) </a> is now available in the Asia Pacific (New Zealand, Melbourne, Taipei, Thailand), Mexico (Central), EU (Spain). Customers can now use these new Regions to leverage Amazon SES to send emails and, if needed, to help manage data requirements.</p> 
<p>Amazon SES is a scalable, cost-effective, and flexible cloud-based email service that allows digital marketers and application developers to send marketing, notification, and transactional emails from within any application. To learn more about Amazon SES, visit this <a href="https://aws.amazon.com/ses/">page </a>.</p> 
<p>With this launch, Amazon SES is available in 35 AWS Regions globally: US East (N. Virginia, Ohio), US West (N. California, Oregon), AWS GovCloud (US-West, US-East), Asia Pacific (Osaka, Mumbai, Hyderabad, Sydney, Singapore, Seoul, Tokyo, Jakarta, Malaysia, New Zealand, Melbourne, Taipei, Thailand), Canada (Central, Calgary), EU (Ireland, Frankfurt, London, Paris, Stockholm, Milan, Zurich,Spain), Middle East (Bahrain, UAE), Israel (Tel Aviv), South America (Sao Paulo), Mexico (Central) and Africa (Cape Town).</p> 
<p>For a complete list of all of the regional endpoints for Amazon SES, see  <a href="https://docs.aws.amazon.com/general/latest/gr/ses.html">AWS Service Endpoints </a> in the AWS General Reference.</p>
