# AWS Deadline Cloud now supports persistent storage for Service Managed Fleets

<p>AWS Deadline Cloud now supports persistent storage for Service-Managed Fleets (SMF), allowing you to maintain data across worker lifecycle events. AWS Deadline Cloud is a fully managed service that makes it easy for teams to run compute-intensive workloads in the cloud for visual effects, animation, product design, simulation, and gaming.<br /> <br /> Previously, Deadline Cloud SMF workers relied only on ephemeral storage, requiring software and assets to be reinstalled each time a worker was recycled or replaced. Now, Deadline Cloud attaches persistent Amazon Elastic Block Store (Amazon EBS) volumes to SMF workers, preserving Conda environments, Perforce workspaces, shader caches, and asset collections across worker lifecycle events. This reduces worker startup time and helps you complete jobs faster. You can configure the number of persistent volumes per worker and set a time-to-live (TTL) to control how long volumes are retained, giving you flexibility to balance storage costs with startup performance. <br /> <br /> Persistent storage for SMF is available in all AWS Regions where Deadline Cloud is offered. Persistent volumes are priced the same as existing Service-Managed Fleets EBS pricing. See the <a href="https://aws.amazon.com/deadline-cloud/pricing/">Deadline Cloud pricing page</a> for details. To learn more, visit the <a href="https://aws.amazon.com/deadline-cloud/">AWS Deadline Cloud product page</a> or our <a href="https://docs.aws.amazon.com/deadline-cloud/latest/userguide/volumes.html">user guide</a>.</p>
