# AWS Lambda Durable Execution SDK for Go is now generally available

<p>Today, AWS announces the general availability of the AWS Lambda Durable Execution SDK for Go, enabling Go developers to build resilient, long-running workflows using Lambda durable functions. With this SDK, developers can create multi-step applications like infrastructure automation, deployment rollouts with approval gates, and pipelines that call AI models and pause for human review directly in their Go code without implementing custom progress tracking.</p>
<p>Lambda durable functions extend Lambda's event-driven programming model with operations that checkpoint progress automatically and pause execution for up to an year when waiting on external events. The AWS Lambda Durable Execution SDK for Go provides a native Go experience for building with Lambda durable functions. It includes steps for progress tracking, callback integration for human and agent-in-the-loop workflows, durable invocation for reliable function chaining, and waits for efficient suspension.</p>
<p>The SDK works with the Go tools developers already use. Developers add it to a Go module with go get and deploy their function as a single static binary on the provided.al2023 runtime, like any other Go function on Lambda. Before deploying, they can locally test complete workflows on their own machine with the durabletest package, without requiring network access or AWS credentials, and use the durablelint analyzer to catch code that could break a workflow when it resumes.</p>
<p>To get started, see the Lambda durable functions <a href="https://docs.aws.amazon.com/lambda/latest/dg/durable-functions.html">developer guide</a> and the <a href="https://github.com/aws/aws-durable-execution-sdk-go">AWS Lambda Durable Execution SDK for Go on GitHub</a>. For Regional availability and pricing details for Lambda durable functions, see the AWS Capabilities by Region <a href="https://builder.aws.com/build/capabilities?refid=2abe6167-e3db-40c4-a9fa-b283e7b4d7c8">page</a> and AWS Lambda <a href="https://aws.amazon.com/lambda/pricing/">Pricing</a>.</p>
