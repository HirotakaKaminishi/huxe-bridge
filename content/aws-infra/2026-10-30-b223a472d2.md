# Amazon RDS for Oracle and SQL Server now support storage autoscaling on additional storage volumes

<p><a href="https://aws.amazon.com/rds/sqlserver/" target="_blank"><u>Amazon RDS for SQL Server</u></a> and <a href="https://aws.amazon.com/rds/oracle/" target="_blank"><u>Amazon RDS for Oracle</u></a> now support RDS storage autoscaling on <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/USER_PIOPS.ModifyingExisting.AdditionalVolumes.html" target="_blank">additional storage volumes</a>. RDS storage autoscaling automatically scales storage capacity in response to growing database workloads, with zero downtime.</p> 
<p>Additional storage volumes allow you to add up to three additional volumes to increase your storage capacity up to 256 TiB. Previously, you had to manually provision storage capacity on the additional storage volumes based on anticipated application capacity demands while autoscaling could be enabled on the primary storage volume. Under-provisioning could result in application downtime, and over-provisioning could result in under-utilized resources and higher costs. With RDS storage autoscaling, you simply set your desired maximum storage limit for each additional storage volume, and autoscaling takes care of the rest.</p> 
<p>RDS storage autoscaling continuously monitors actual storage consumption, and scales capacity up automatically when actual utilization approaches provisioned storage capacity. Autoscaling works with new and existing database instances. Autoscaling has no additional charges and you only pay for the provisioned storage resources. You can enable it by using the AWS Management Console, AWS CLI, or Amazon RDS API.</p> 
<p>RDS storage autoscaling for additional storage volumes is available for Amazon RDS for SQL Server and Amazon RDS for Oracle in all commercial AWS Regions and the AWS GovCloud (US) Regions. To learn more, please visit the <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/USER_PIOPS.Autoscaling.html">Amazon RDS storage autoscaling</a> documentation. </p>
