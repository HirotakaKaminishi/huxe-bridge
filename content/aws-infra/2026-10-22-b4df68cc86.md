# AWS Transform adds storage migration assessments for Amazon S3, EBS, EFS, and FSx

<p><a href="https://docs.aws.amazon.com/transform/latest/userguide/transform-app-assessments.html" target="_blank">Migration assessments in AWS Transform</a> now evaluate on-premises storage for migration to AWS. Instead of manually analyzing thousands of volumes across protocols, capacity, and performance, you upload a storage inventory and AWS Transform does the mapping for you. It matches each workload to the best-fit service, sizes the recommendation, and projects costs to produce a total cost of ownership business case. Bring NAS shares, SAN LUNs, direct-attached disks, or backup repositories via a NetApp Digital Advisor export, RVTools file, or other inventory. AWS Transform routes workloads across Amazon S3, Amazon EBS, Amazon EFS, and Amazon FSx (NetApp ONTAP, Windows File Server, OpenZFS, Lustre). Run what-if scenarios to compare deployment options such as Single-AZ vs. Multi-AZ or cost-optimized vs. performance-optimized, then ask follow-up questions about any result in chat.</p> 
<p>Storage migration assessments are available in all AWS Regions where AWS Transform is available. To learn more, see the <a href="https://docs.aws.amazon.com/transform/latest/userguide/transform-app-assessments.html" target="_blank">AWS Transform User Guide</a>.</p>
