# Amazon Aurora and RDS now support AMD-based R8a instances

<p>Amazon Aurora and Amazon RDS now support R8a database instances powered by 5th generation AMD EPYC processors, expanding the choice available for your database workloads. Each vCPU in R8a database instances corresponds to a physical CPU core, which delivers consistent per-core performance. For workloads with high I/O requirements, R8a instances provide up to 75 Gbps of network bandwidth and 60 Gbps of Amazon EBS bandwidth. All R8a instances are built on the AWS Nitro System using sixth-generation Nitro Cards.</p>
<p>R8a database instances are supported for Amazon Aurora PostgreSQL-Compatible Edition, Amazon Aurora MySQL-Compatible Edition, RDS for PostgreSQL, MySQL and MariaDB. R8a database instances are available in US East (N. Virginia, Ohio), US West (Oregon), Canada (Central), Asia Pacific (Tokyo, Taipei) and Europe (Ireland, Frankfurt, Spain) regions. </p>
<p>You can get started with R8a database instances through the <a href="https://console.aws.amazon.com/rds/home?refid=35100cff-4aaa-46ac-bc1d-71576bef47be" rel="noopener noreferrer" target="_blank"><u>Amazon RDS Management Console</u></a> or by using the <a href="https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/Aurora.CreateInstance.html?refid=35100cff-4aaa-46ac-bc1d-71576bef47be#Aurora.CreateInstance.Creating" rel="noopener noreferrer" target="_blank"><u>AWS Command Line Interface</u></a> (CLI). For the specific engine versions that support these instance classes, see the <a href="https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/Concepts.DBInstanceClass.SupportAurora.html?refid=35100cff-4aaa-46ac-bc1d-71576bef47be" rel="noopener noreferrer" target="_blank"><u>Aurora</u></a> and <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/Concepts.DBInstanceClass.Support.html?refid=35100cff-4aaa-46ac-bc1d-71576bef47be" rel="noopener noreferrer" target="_blank"><u>RDS</u></a> documentation. For pricing, see the <a href="https://aws.amazon.com/rds/aurora/pricing/" rel="noopener noreferrer" target="_blank"><u>Amazon Aurora pricing page</u></a>  and the <a href="https://aws.amazon.com/rds/pricing/" rel="noopener noreferrer" target="_blank"><u>Amazon RDS pricing page</u></a>.</p>
