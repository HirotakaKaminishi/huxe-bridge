# AWS CloudFormation makes resource coverage comprehensive with 206 new types

<p>AWS CloudFormation now supports 206 additional resource types across 88 services, including Amazon SageMaker Hub, Amazon Bedrock AgentCore PolicyEngine, and Amazon EC2 Snapshot. This closes key gaps in CloudFormation coverage and helps customers to standardize on safe and scalable infrastructure management workflows. The launch utilized a new AI-driven internal framework to collapse the costs of onboarding resource types to CloudFormation, setting up CloudFormation for continued coverage expansion. AWS Cloud Control API supports all new resource types that CloudFormation supports. Additionally, Cloud Control API now supports 224 read-only resource types across 99 services, making it easier to find and inspect existing AWS resources.</p> 
<p><br /> CloudFormation resource coverage is available across all AWS Regions where the underlying service is available.</p> 
<p><br /> To learn more, visit the <a href="https://docs.aws.amazon.com/AWSCloudFormation/latest/TemplateReference/aws-template-resource-type-ref.html">AWS resource and property types reference</a>, the <a href="https://docs.aws.amazon.com/cloudcontrolapi/latest/userguide/supported-resources.html">Cloud Control API resource list</a>, and the <a href="https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/Welcome.html">AWS CloudFormation User Guide</a>.</p>
