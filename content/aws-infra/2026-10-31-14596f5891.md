# Web Search now available on Kiro in AWS GovCloud (US)

<p>Kiro web search gives the agent real-time access to current information on the internet, so its answers draw on up-to-date search results and page content. The agent uses web search automatically when a question involves recent changes or topics beyond the model's training data. Answers that use web results include citations.</p> 
<p>Kiro enterprise administrators can turn off web search and web fetch for their organization from the Kiro console under Settings. Teams can also remove web tools from individual custom agents, or block them with capability-based permission rules.</p> 
<p>For more details, visit the <a href="https://docs.aws.amazon.com/govcloud-us/latest/UserGuide/govcloud-kiro.html">AWS GovCloud (US) documentation</a>, the <a href="https://kiro.dev/docs/enterprise/monitor-and-track/">monitoring and tracking guide</a>, or contact your AWS account team. To learn more about Kiro, visit the <a href="https://kiro.dev/">Kiro product page</a>.</p>
