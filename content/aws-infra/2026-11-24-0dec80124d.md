# AWS WAF introduces simplified pricing

<p>AWS WAF now offers simplified pricing that follows what you protect instead of how you configure it. Previously, you paid separate charges for each web ACL, rule, rule group subscription, and capacity tier, making every security decision a billing calculation. Now, your bill follows three dimensions: the resources you protect, the traffic AWS WAF inspects, and the level of protection you apply. This makes the cost-benefit trade-off easy to understand, and adding or changing rules no longer changes your rate.</p> 
<p>The new model makes protection costs predictable before you deploy. Each web ACL now includes up to 2,500 WCU at no extra charge, up from 1,500, and you can add rules such as Bot Control common protections or the Anti-DDoS rule group without additional fees. You pay a resource fee for each protected resource, a base request fee for every request AWS WAF inspects, and a premium request fee only for traffic evaluated by advanced protections like Bot Control targeted protections, Fraud Control, API Security, and AI Security.</p> 
<p>AWS WAF's new pricing is available today in all AWS commercial Regions, including Cape Town, Hong Kong, Hyderabad, Jakarta, Malaysia, Melbourne, Mumbai, New Zealand, Osaka, Seoul, Singapore, Sydney, Taipei, Thailand, Tokyo, Calgary, Frankfurt, Ireland, London, Milan, Paris, Spain, Stockholm, Zurich, Tel Aviv, Sao Paulo, N. Virginia, Ohio, N. California, Oregon, as well as in AWS GovCloud, China Regions, and AWS Isolated Regions.</p> 
<p>To learn more, visit the <a href="https://aws.amazon.com/waf/pricing/">AWS WAF pricing page</a> and review the <a href="https://docs.aws.amazon.com/waf/">AWS WAF Developer Guide</a> as well as the blog post <a href="https://aws.amazon.com/blogs/security/introducing-aws-waf-simplified-pricing/" rel="noopener noreferrer" target="_blank">AWS WAF pricing now follows what you protect, not how you configure it</a>.</p>
