# Amazon RDS for Oracle now supports M8i and R8i instances with Oracle SE2 License Included

<p><a href="https://aws.amazon.com/rds/oracle/">Amazon RDS for Oracle </a>now offers M8i and R8i instances with Oracle Database Standard Edition 2 (SE2) with the License Included (LI). M8i and R8i instances are powered by custom Intel Xeon 6 processors, available only on AWS, delivering the highest performance and fastest memory bandwidth among comparable Intel processors in the cloud. The new instances offer up to 15% better price-performance, and 2.5x more memory bandwidth compared to previous generation Intel-based instances.<br /> <br /> With RDS for Oracle SE2 LI, customers don’t have to separately purchase Oracle license and support. Amazon RDS for Oracle SE2 LI offers subscription based pay-per-use pricing inclusive of software license, support, compute resources, and a managed database service. To use RDS for Oracle SE2 LI, customers can create database instances from the <a href="https://console.aws.amazon.com/rds/home">AWS Management Console</a> or using the <a href="https://docs.aws.amazon.com/cli/latest/reference/rds/create-db-instance.html">AWS CLI</a>. and specify the LI option. For more details about how you can lower cost and simplify operations of running Oracle databases, refer to the AWS blog <a href="https://aws.amazon.com/blogs/database/rethink-oracle-standard-edition-two-on-amazon-rds-for-oracle/">Rethink Oracle Standard Edition Two on Amazon RDS for Oracle</a>.<br /> <br /> Configuration details for available instance types can be found on the <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/Concepts.DBInstanceClass.Support.html">Amazon RDS for Oracle Instance Types</a> page. Review the AWS blog <a href="https://aws.amazon.com/blogs/database/rethink-oracle-standard-edition-two-on-amazon-rds-for-oracle/">Rethink Oracle Standard Edition Two on Amazon RDS for Oracle</a> to explore how you can lower cost and simplify operations by using Amazon RDS Oracle SE2 License Included instances for your Oracle databases.<br /> <br /> For pricing and AWS Region availability, see <a href="https://aws.amazon.com/rds/oracle/pricing/">Amazon RDS for Oracle Pricing</a>.</p>
