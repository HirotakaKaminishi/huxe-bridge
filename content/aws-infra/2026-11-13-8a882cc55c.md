# Grok 4.7 now available on Kiro in AWS GovCloud (US)

<p>A new model is now available in the Kiro IDE and CLI for the AWS GovCloud (US) Regions.</p> 
<p>Grok 4.7 is SpaceXSI's most capable model for coding and knowledge work. It's built to stay focused through hard tasks that run for hours, and it checks its work before moving on. Compared with Grok 4.6, it plans and recovers from errors more reliably in repo-scale coding work. Grok 4.7 is available with experimental support and a 500K context window. Requests up to 200K tokens use a 2.7x credit multiplier, and requests over 200K tokens are billed at 5.4x.</p> 
<p>Kiro administrators control which models are available to their users, so organizations can align model access with their internal policies.</p> 
<p>Ensure your IDE or CLI is updated to the latest version, then restart it to access the new model from the model selector. For more details, visit the <a href="https://docs.aws.amazon.com/govcloud-us/latest/UserGuide/govcloud-kiro.html">GovCloud documentation</a>, the <a href="https://kiro.dev/docs/enterprise/monitor-and-track/">monitoring and tracking guide</a>, or contact your AWS account team. To learn more about Kiro, visit the <a href="https://kiro.dev/">Kiro product page</a>.</p>
