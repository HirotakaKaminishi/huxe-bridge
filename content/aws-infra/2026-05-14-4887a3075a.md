# Amazon FSx for OpenZFS now supports creating Multi-AZ file systems in shared VPCs

<p>Amazon FSx for OpenZFS now allows you to create Multi-AZ file systems in shared VPCs within your AWS organization, making it easier for you to decentralize network and storage administration.</p> 
<p><a href="https://docs.aws.amazon.com/vpc/latest/userguide/vpc-sharing.html">VPC sharing</a> is a feature that allows resource owners ("owner accounts") to share one or more VPC subnets with other accounts ("participant accounts") in their AWS organization. Participant accounts can then view, create, modify, delete, and manage their application resources in the subnets shared with them. Previously, participant accounts could create Single-AZ OpenZFS file systems in VPCs shared with them, but could only create Multi-AZ file systems in VPCs they owned. Starting today, participant accounts can create any FSx for OpenZFS file system in a shared VPC, allowing organizations to run highly available file systems with centralized network management.</p> 
<p>You can create Multi-AZ FSx for OpenZFS file systems from shared VPC participant accounts in <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/?refid=bc0b1108-3dde-4bd6-8c6b-5bc65141884a">all AWS Regions where Amazon FSx for OpenZFS is available</a>. To learn more, visit the FSx for <a href="https://docs.aws.amazon.com/fsx/latest/OpenZFSGuide/what-is-fsx.html">OpenZFS documentation</a> and the <a href="https://aws.amazon.com/fsx/openzfs/">FSx for OpenZFS product page</a>.</p>
