# Kimi K3.1 Pro (Highspeed) now available on Amazon Bedrock

<p>Today, Kimi K3.1 Pro from Moonshot AI is available on Amazon Bedrock, expanding our open weight model portfolio with the security and governance that customers rely on. Customers using Amazon Bedrock can now run agentic use cases such as coding and document processing on Kimi K3.1 Pro (Highspeed), which delivers high output tokens per second (OTPS) for faster, more responsive results.</p> 
<p>According to Moonshot AI, Kimi K3.1 Pro is an open-weight, natively multimodal agentic model with a 1-million-token context window, and its most capable 3-trillion-parameter-class model to date. Moonshot AI reports improvements in coding, 3D creation, financial research, and other agentic work. On Amazon Bedrock, it runs within the same security boundary as proprietary models and supports <a href="https://docs.aws.amazon.com/bedrock/latest/userguide/prompt-caching.html">explicit prompt caching</a> to reduce latency and input costs.</p> 
<p>Kimi K3.1 Pro is available in all <a href="https://docs.aws.amazon.com/bedrock/latest/userguide/models-region-compatibility.html">AWS Regions</a> where Amazon Bedrock is available through cross-Region inference. To get started, visit the <a href="https://console.aws.amazon.com/bedrock/">Amazon Bedrock console</a>. To learn more, see the <a href="https://docs.aws.amazon.com/bedrock/latest/userguide/model-card-moonshot-ai-kimi-k3-1-highspeed.html">Amazon Bedrock documentation</a>.</p>
