# Amazon RDS for MariaDB now supports MariaDB 12.3

<p>Starting today, Amazon RDS for MariaDB supports MariaDB major version 12.3, the latest Long-Term Support release from the MariaDB community. This release supports MariaDB 12.3.2 minor version.  <br /> <br /> MariaDB 12.3 includes Oracle TO_DATE() function compatibility, reducing the code changes needed when migrating applications from Oracle to MariaDB. It adds an IS JSON predicate, so you can validate JSON documents natively in the database rather than in application code. The query optimizer now handles reorderable LEFT JOIN statements and ordered scans over RANGE partitions more efficiently, improving performance for these queries without application changes. For more details, refer to the <a href="https://mariadb.com/docs/release-notes/community-server/12.3" rel="noopener noreferrer" target="_blank">MariaDB 12.3 release notes</a> and <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/MariaDB.Concepts.VersionMgmt.html" rel="noopener noreferrer" target="_blank">RDS MariaDB release notes</a>.<br /> <br /> You can upgrade your database using <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/blue-green-deployments.html" rel="noopener noreferrer" target="_blank">Amazon RDS Blue/Green Deployments</a>, in-place upgrade, or restore from a snapshot. Learn more about performing major version upgrades in the <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/USER_UpgradeDBInstance.MariaDB.html" rel="noopener noreferrer" target="_blank">Amazon RDS User Guide</a>. You can also migrate to RDS for MariaDB 12.3 from external MariaDB sources using <a href="https://aws.amazon.com/dms/" rel="noopener noreferrer" target="_blank">AWS Database Migration Service</a>.  <br /> <br /> Amazon RDS for MariaDB makes it simple to set up, operate, and scale MariaDB deployments in the cloud. Learn more about pricing details and regional availability at <a href="https://aws.amazon.com/rds/mariadb/pricing/" rel="noopener noreferrer" target="_blank">Amazon RDS for MariaDB</a>. Create or update a fully managed Amazon RDS for MariaDB database in the <a href="https://console.aws.amazon.com/rds/home" rel="noopener noreferrer" target="_blank">Amazon RDS Management Console</a>.</p>
