# Amazon DocumentDB (with MongoDB compatibility) is now available in the Asia Pacific (Taipei) and Asia Pacific (New Zealand) Regions

<p>Amazon DocumentDB (with MongoDB compatibility) is now available in the Asia Pacific (Taipei) and Asia Pacific (New Zealand) Regions, adding to the <a>list of </a><a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">available Regions</a> where you can use Amazon DocumentDB.</p> 
<p>Amazon DocumentDB is a fully managed, native JSON database that makes it simple and cost-effective to operate critical document workloads at virtually any scale without managing infrastructure. Amazon DocumentDB is designed to give you the scalability and durability you need when operating mission-critical MongoDB workloads. Storage scales automatically up to 128 TiB without any impact to your application. In addition, Amazon DocumentDB natively integrates with Amazon CloudWatch, AWS CloudTrail, AWS Lambda, AWS Backup, and more. Amazon DocumentDB supports millions of requests per second and can be scaled out to 15 low-latency read replicas in minutes with no application downtime.</p> 
<p>To learn more about Amazon DocumentDB, please visit the <a>Amazon DocumentDB </a><a href="https://aws.amazon.com/documentdb/">product page</a> and <a></a><a href="https://aws.amazon.com/documentdb/pricing/">pricing page</a>. You can create an Amazon DocumentDB cluster from the <a></a><a href="https://aws.amazon.com/about-aws/whats-new/2026/02/amazon-documentdb-mongodb-compatibility-asia-pacific-melbourne-region/#:~:text=AWS%20Management%20console">AWS Management Console</a>, <a></a><a href="https://aws.amazon.com/about-aws/whats-new/2026/02/amazon-documentdb-mongodb-compatibility-asia-pacific-melbourne-region/#:~:text=AWS%20Command%20Line%20Interface%20(CLI)">AWS Command Line Interface (CLI)</a>, or AWS SDKs.</p>
