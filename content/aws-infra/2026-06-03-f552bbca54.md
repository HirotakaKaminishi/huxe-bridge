# Amazon RDS for Db2 launches support for IBM Db2 v12.1 and Db2 Community Edition

<p><a href="https://aws.amazon.com/rds/db2/" rel="noopener noreferrer" target="_blank">Amazon RDS for Db2</a> now supports IBM Db2 v12.1. With Db2 v12.1, RDS now supports Db2 Standard, Db2 Advanced, and Db2 Community Edition. Db2 Community Edition provides all the features available in Standard and Advanced Editions, with no commercial software licensing charges for development and test applications. This allows you to easily start developing and testing Db2 applications with a managed database service without worrying about software licensing.<br /> <br /> To use Db2 Community Edition, get a free IBM Customer ID from the <a href="https://www.ibm.com/account/reg/us-en/signup?formid=urx-54367" rel="noopener noreferrer" target="_blank">IBM website</a> and create your database instances using the the <a href="https://console.aws.amazon.com/rds/" rel="noopener noreferrer" target="_blank">Amazon RDS console</a>. For details, see <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/CHAP_Db2.html" rel="noopener noreferrer" target="_blank">Amazon RDS for Db2 documentation</a>. For information about new features included in Db2 12.1, visit<a href="https://www.ibm.com/docs/en/db2/12.1.x?topic=121-highlights-db2" rel="noopener noreferrer" target="_blank"> IBM documentation.</a><br /> <br /> Amazon RDS for Db2 12.1 with support for Db2 Community Edition is available in all the AWS Regions where Amazon RDS for Db2 is currently available.</p>
