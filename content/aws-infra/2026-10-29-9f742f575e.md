# AWS Lambda supports Seekable OCI (SOCI) lazy loading for Lambda Managed Instances

<p>AWS Lambda now supports <a href="https://github.com/awslabs/soci-snapshotter">Seekable OCI (SOCI)</a> for lazy loading <a href="https://aws.amazon.com/lambda/lambda-functions/">Event Functions</a> packaged as Open Container Initiative (OCI) images running on <a href="https://aws.amazon.com/lambda/lambda-managed-instances/">Lambda Managed Instances</a>. With SOCI support, Lambda fetches only the files needed at each stage of the execution environment startup rather than downloading the entire image upfront, reducing container startup times by up to 70%.</p> 
<p>Customers building compute-intensive applications such as data processing pipelines, high-throughput API backends, and batch computation workloads require substantial memory and CPU resources to process large datasets, serve low-latency responses at scale, and run complex computations efficiently. Container images for these workloads can reach several gigabytes, and downloading and preparing the full image can take several minutes when provisioning new execution environments. SOCI support on Lambda Managed Instances eliminates this bottleneck by streaming only the required files at each stage of the execution environment startup, so your functions start faster as you scale.</p> 
<p>To get started, create a <a href="https://docs.aws.amazon.com/lambda/latest/dg/lambda-managed-instances-seekable-oci.html#lambda-managed-instances-seekable-oci-create-index">SOCI index</a> (a table of contents for the files in your image layers) for your container image and push it to <a href="https://aws.amazon.com/ecr/">Amazon ECR</a>. When creating or updating your function, set the image URI to the SOCI-indexed tag in Amazon ECR (for example, my-function:v1-soci) and publish a function version. Lambda automatically detects the SOCI index and enables lazy loading with no additional configuration. If you use a coding assistant such as Kiro, Claude Code, or Codex, install the Lambda Managed Instances skill from the <a href="https://docs.aws.amazon.com/lambda/latest/dg/agent-setup-guide.html">Agent Toolkit for AWS</a> to configure and deploy functions through your agent.</p> 
<p>The feature is available in all <a href="https://builder.aws.com/build/capabilities">AWS commercial Regions</a> where Lambda Managed Instances is available. To learn more, visit the <a href="https://docs.aws.amazon.com/lambda/latest/dg/lambda-managed-instances-seekable-oci.html">AWS Lambda Managed Instances developer guide</a>. </p>
