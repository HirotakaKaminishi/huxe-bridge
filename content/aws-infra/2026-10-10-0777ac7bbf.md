# AWS Security Hub now exports findings to S3 in CSV or JSON format

<p>Today, AWS Security Hub announces support for exporting findings to Amazon S3 in CSV or JSON (OCSF) format. Security teams that need findings outside the console for use cases such as compliance reporting and audit evidence can now export findings from every findings page in the Security Hub console, including Threats, Exposure, Vulnerabilities, Posture Management, Sensitive Data, and All Findings, without building and maintaining their own extraction pipelines.</p>
<p>With this launch, you can start an export on demand from the findings page you are viewing and have Security Hub deliver the results to an S3 bucket in your account. You can choose CSV when you want to review or share findings in a spreadsheet or export in JSON if you need these findings in Open Cybersecurity Schema Framework (OCSF) format.</p>
<p>Findings export is available in all AWS Regions where AWS Security Hub is available. To learn more, visit the AWS Security Hub User Guide at <a href="https://docs.aws.amazon.com/securityhub/latest/userguide/securityhub-v2-findings-export.html">https://docs.aws.amazon.com/securityhub/latest/userguide/securityhub-v2-findings-export.html</a>.</p>
