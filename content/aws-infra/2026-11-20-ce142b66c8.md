# Amazon Aurora DSQL now delivers up to 50% higher write throughput

<p>With upgrades to its storage layer, <a href="https://aws.amazon.com/rds/aurora/dsql/">Amazon Aurora DSQL</a> now delivers up to 50% higher write throughput for many transactional workloads. Data loads finish sooner, and tables whose primary key always increases, such as tables keyed by a timestamp, an identity column, or a time-ordered ID like ULID or UUIDv7, see even greater benefits.</p> 
<p>Applications such as audit logs, ledgers, and event feeds are read in time order, and keying them by time keeps those reads fast. You can now use that design for write-heavy tables too. In our tests, an audit log table keyed by event time accepted up to 200% more inserts per second.</p> 
<p>The improvement is available in all <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">AWS Regions</a> where Aurora DSQL is available, for new and existing clusters, at no additional cost. To learn more, see the <a href="https://docs.aws.amazon.com/aurora-dsql/latest/userguide/what-is-aurora-dsql.html">Aurora DSQL User Guide</a>.</p>
