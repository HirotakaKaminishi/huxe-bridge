# Amazon CloudFront Announces WebSocket and gRPC Support for Origin Mutual TLS

<p>Amazon CloudFront (CF) now supports WebSocket and gRPC traffic to application origins in AWS regions, with mutual TLS authentication between CF and the application origin (origin mTLS). Customers can now use TLS certificates to authenticate requests from CloudFront while setting up WebSocket or gRPC connections to their origins. Origin mTLS protects internet facing applications that need persistent, bidirectional or streaming connections, such as chat platforms, collaborative editing tools or live dashboards from unauthenticated requests.</p> 
<p>Previously, customers serving WebSocket or gRPC traffic through CloudFront had to use shared secrets or IP allow-lists to identify requests originating from CloudFront. This was operationally complex and did not provide strong authentication. With Origin mTLS, customers can use one TLS based authentication for HTTP, WebSocket and gRPC traffic to an application origin. This works with application origins within AWS such as Application Load Balancer and API Gateway, on-premises origins, and origins hosted outside AWS.</p> 
<p>There is no additional charge for origin mTLS, and it is available with pay-as-you-go pricing and in the Business and Premium flat-rate pricing plans. To learn more, visit the CloudFront <a href="https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/origin-mtls-authentication.html">origin mutual TLS documentation</a>.</p>
