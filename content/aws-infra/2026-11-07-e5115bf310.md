# Amazon Redshift expands SUPER data type to store strings up to 16 million bytes

<p><a href="https://aws.amazon.com/redshift/">Amazon Redshift</a> now supports individual strings up to 16 million bytes within <a href="https://docs.aws.amazon.com/redshift/latest/dg/r_SUPER_type.html">SUPER data types</a>. Once you opt in through a database parameter, this enhancement applies when ingesting structured or semi-structured data from JSON, PARQUET, TEXT, and CSV source files, and when transforming data through extract load and transform (ELT) processes. Previously, individual strings within SUPER data types were limited to 65,535 bytes.</p> 
<p>Storing large individual strings in the SUPER data type helps avoid complex pre-loading transformations needed to store the source data in Amazon Redshift. You can now directly ingest large individual strings greater than 65,535 bytes without extra processing (for example, lengthy documents like terms and conditions and contracts), making them queryable using SQL. Once the data is in Amazon Redshift, you can use the flexibility of PartiQL language to explore and navigate through the data or use string functions to transform the data. Functions such as <a href="https://docs.aws.amazon.com/redshift/latest/dg/JSON_PARSE.html">JSON_PARSE</a>, <a href="https://docs.aws.amazon.com/redshift/latest/dg/r_CONCAT.html">CONCAT</a>, and <a href="https://docs.aws.amazon.com/redshift/latest/dg/r_LISTAGG.html">LISTAGG</a> can now take input strings and return output strings up to 16 million bytes in length.</p> 
<p>This enhancement is available in all AWS Regions, including the AWS GovCloud (US) Regions, where Amazon Redshift is available. See the <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/" style="background-color: rgb(255,255,255);">AWS Region Table</a> for more details. To learn more, please visit our <a href="https://docs.aws.amazon.com/redshift/latest/dg/r_enable_large_strings_opt_in.html" style="background-color: rgb(255,255,255);">documentation</a> or <a href="http://aws.amazon.com/blogs/big-data/store-and-process-large-strings-in-amazon-redshift-super-columns">blog</a>.  </p>
