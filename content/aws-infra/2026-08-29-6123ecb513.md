# Amazon Aurora MySQL 3.13 (compatible with MySQL 8.0.45) is generally available

<p>Starting today, Amazon Aurora MySQL-Compatible Edition 3 (compatible with MySQL 8.0) supports MySQL 8.0.45, which includes community MySQL fixes and Aurora-specific improvements. For detailed information on this release, refer to <a href="https://docs.aws.amazon.com/AmazonRDS/latest/AuroraMySQLReleaseNotes/AuroraMySQL.Updates.30Updates.html" rel="noopener noreferrer" target="_blank">Aurora MySQL 3</a> and <a href="https://dev.mysql.com/doc/relnotes/mysql/8.0/en/news-8-0-45.html" rel="noopener noreferrer" target="_blank">MySQL 8.0.45</a> release notes.<br /> <br /> You can upgrade your databases during scheduled maintenance windows using automatic minor version upgrades. To simplify operations at scale, enable <a href="https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/AuroraMySQL.Updates.AMVU.html" rel="noopener noreferrer" target="_blank">automatic minor version upgrades</a> and use the AWS Organizations <a href="https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/Aurora.Maintenance.AMVU.UpgradeRollout.html" rel="noopener noreferrer" target="_blank">Upgrade Rollout Policy</a> to orchestrate upgrades across your clusters in phases. You can perform minor version upgrades in-place or via snapshot restore. This release is supported in all <a href="https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/Concepts.RegionsAndAvailabilityZones.html#Aurora.Overview.Availability.MySQL" rel="noopener noreferrer" target="_blank">AWS Regions</a> where Aurora MySQL is available.<br /> <br /> <a href="https://aws.amazon.com/rds/aurora/" rel="noopener noreferrer" target="_blank">Amazon Aurora</a> is designed for high performance and availability at global scale with full MySQL compatibility. It provides scale-to-zero serverless compute, Aurora Global Database for multi-Region resilience, Aurora I/O-Optimized for improved price performance on I/O-intensive workloads, and built-in security and continuous backups. To get started, take a look at Aurora’s <a href="https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/CHAP_AuroraOverview.html" rel="noopener noreferrer" target="_blank">getting started page</a>. </p>
