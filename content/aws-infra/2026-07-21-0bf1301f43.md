# Amazon RDS now supports the latest CU and GDR updates for Microsoft SQL Server

<p><a href="https://aws.amazon.com/rds/sqlserver/" rel="noopener noreferrer" target="_blank">Amazon Relational Database Service (Amazon RDS) for SQL Server </a>now supports the latest Cumulative Updates (CU) and General Distribution Release (GDR) updates for Microsoft SQL Server. This release includes support for Microsoft SQL Server 2016 SP3+GDR <a href="https://support.microsoft.com/help/5089271" rel="noopener noreferrer" target="_blank">KB5089271</a> (RDS version 13.00.6490.1.v1), SQL Server 2017 CU31+GDR <a href="https://support.microsoft.com/help/5090354" rel="noopener noreferrer" target="_blank">KB5090354</a> (RDS version 14.00.3530.2.v1), SQL Server 2019 CU32+GDR <a href="https://support.microsoft.com/help/5090407" rel="noopener noreferrer" target="_blank">KB5090407</a> (RDS version 15.00.4470.1.v1) and SQL Server 2022 CU25 <a href="https://learn.microsoft.com/en-us/troubleshoot/sql/releases/sqlserver-2022/cumulativeupdate25" rel="noopener noreferrer" target="_blank">KB5081477</a> (RDS version 16.00.4255.1.v1).<br /> <br /> The GDR updates address vulnerabilities described in CVE-2026-40370. For additional information on the improvements and fixes included in these updates, see Microsoft documentation for KB5089271, KB5090354, KB5090407 and KB5081477. We recommend that you upgrade your Amazon RDS for SQL Server instances to apply these updates using Amazon RDS Management Console, or by using the AWS SDK or CLI. You can learn more about upgrading your database instance in the <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/USER_UpgradeDBInstance.SQLServer.html" rel="noopener noreferrer" target="_blank">Amazon RDS SQL Server User Guide for upgrading your RDS Microsoft SQL Server DB engine</a>.</p>
