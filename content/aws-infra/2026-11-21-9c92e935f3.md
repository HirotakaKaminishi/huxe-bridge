# Amazon CloudWatch Omni now supports Microsoft Azure platform logs, metrics and traces

<p>Amazon CloudWatch Omni now supports collecting Azure resource logs, Azure Monitor platform metrics, virtual network (VNet) flow logs, and traces from Application Insights. Teams that run workloads on both AWS and Azure no longer need separate monitoring tools or custom pipelines to see their whole environment. Central operations, DevOps, and site reliability engineering (SRE) teams can now view Azure telemetry alongside their AWS telemetry in one place.</p> 
<p>To get started, connect a Microsoft Entra ID tenant to your AWS account and Region. You can choose the telemetry types, subscriptions, Azure regions, resource types, and tags to collect. Azure telemetry lands in Amazon CloudWatch, and Omni spaces can monitor applications and infrastructure across cloud providers. For example, during an incident you can trace a slow request from an Azure-hosted service to its AWS dependencies without switching consoles. You can set up the connectors in the Amazon CloudWatch Omni console or with the AWS CLI.</p> 
<p>Azure telemetry collection is available in all Azure Public Regions and can be ingested to all regions where CloudWatch Omni is available. To get started, visit the  <a href="https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/omni-send-platform-telemetry-from-microsoft-azure.html">CloudWatch Omni User Guide </a> and for pricing visit <a href="https://aws.amazon.com/cognito/pricing/">pricing page.</a></p>
