# Amazon RDS for MariaDB now supports community MariaDB minor versions 10.6.28, 10.11.19, 11.4.13, 11.8.9, and 12.3.3

<p>Starting today, <a href="https://aws.amazon.com/rds/mariadb/" rel="noopener noreferrer" target="_blank">Amazon Relational Database Service (Amazon RDS) for MariaDB</a> now supports MariaDB minor versions 10.6.28, 10.11.19, 11.4.13, 11.8.9, and 12.3.3, the latest minors released by community MariaDB. In addition to operational improvements, these minor versions introduce support for post-quantum TLS (PQ-TLS) key exchange, providing you with post-quantum cryptography options for encrypting your data in-transit. We recommend upgrading to the newer minor versions to accept fixes for Common Vulnerabilities and Exposures (CVEs) in prior versions of MariaDB and to benefit from bug fixes, performance improvements, and new functionality added by the MariaDB community. Learn more about the enhancements in RDS for MariaDB in the <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/MariaDB.Concepts.VersionMgmt.html" rel="noopener noreferrer" target="_blank">RDS MariaDB release notes.</a>​</p> 
<p>You can upgrade your database using <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/blue-green-deployments.html" rel="noopener noreferrer" target="_blank">Amazon RDS Blue/Green Deployments</a>, in-place upgrade, or restore from a snapshot. To simplify operations at scale, enable <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/USER_UpgradeDBInstance.MariaDB.Minor.html" rel="noopener noreferrer" target="_blank">automatic minor version upgrades</a> and use the AWS Organizations <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/RDS.Maintenance.AMVU.UpgradeRollout.html" rel="noopener noreferrer" target="_blank">Upgrade Rollout Policy</a> to orchestrate upgrades across your clusters in phases. Learn more about performing version upgrades in the <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/USER_UpgradeDBInstance.MariaDB.html" rel="noopener noreferrer" target="_blank">Amazon RDS User Guide</a>. You can also migrate to RDS for MariaDB from external MariaDB sources using <a href="https://aws.amazon.com/dms/" rel="noopener noreferrer" target="_blank">AWS Database Migration Service</a>. Learn more about pricing details and regional availability at <a href="https://aws.amazon.com/rds/mariadb/pricing/" rel="noopener noreferrer" target="_blank">Amazon RDS for MariaDB</a>. </p> 
<p>Amazon RDS for MariaDB makes it simple to set up, operate, and scale MariaDB deployments in the cloud. Create or update a fully managed Amazon RDS for MariaDB database in the <a href="https://console.aws.amazon.com/rds/home" rel="noopener noreferrer" target="_blank">Amazon RDS Management Console</a>.</p>
