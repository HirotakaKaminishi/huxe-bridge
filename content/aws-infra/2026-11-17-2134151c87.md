# AWS DevOps Agent is now available in AWS GovCloud (US-West)

<p>Now available in AWS GovCloud (US-West), AWS DevOps Agent is your always-available operations teammate that resolves and proactively prevents incidents, optimizes application reliability and performance, and handles on-demand SRE tasks across AWS, multicloud, and on-prem environments.</p> 
<p>DevOps Agent investigates incidents and identifies operational improvements as an experienced teammate would: by learning your applications and their relationships, working with your observability tools, runbooks, code repositories, and CI/CD pipelines, and correlating telemetry, code, and deployment data. It autonomously triages incidents and guides teams to rapid resolution, reducing mean time to resolution (MTTR) from hours to minutes, while analyzing patterns across historical incidents to deliver actionable recommendations that prevent future outages.<br /> <br /> For the full list of AWS Regions where AWS DevOps Agent is available, visit the <a href="https://docs.aws.amazon.com/devopsagent/latest/userguide/about-aws-devops-agent-supported-regions.html">Regions</a> list. Pricing details are available on the AWS DevOps Agent<a href="https://aws.amazon.com/devops-agent/pricing"> pricing page</a>. AWS Support customers receive monthly DevOps Agent credits based on the prior month's AWS Support charge: 100% for Unified Operations, 75% for Enterprise Support, or 30% for Business Support+. For many customers, this significantly reduces or eliminates DevOps Agent costs. For details, visit the <a href="https://aws.amazon.com/premiumsupport/plans/">support compare page</a>.<br /> <br /> To learn more, read the <a href="https://aws.amazon.com/blogs/mt/announcing-general-availability-of-aws-devops-agent/">launch blog</a> and see<a href="https://docs.aws.amazon.com/devopsagent/latest/userguide/"> getting started</a>.</p>
